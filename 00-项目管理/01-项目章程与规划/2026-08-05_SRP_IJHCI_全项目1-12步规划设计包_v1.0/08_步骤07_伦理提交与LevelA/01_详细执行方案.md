# 第7步执行方案：机构模板适配、伦理正式提交与Level A

## 1. 输入

- 第5步伦理材料包；
- 第6步路由确认记录；
- 机构正式模板；
- 场景原型视频与双环对照；
- 设备型号与实验场地；
- 导师负责人与跨学院成员信息。

## 2. 模板适配

建立“机构字段映射表”：

| 机构字段 | 项目来源 |
|---|---|
| 研究目的 | 第1步主张 |
| 研究方法 | 第2–3步 |
| 风险与中止 | 第3、5步 |
| 软件和数据 | 第4步 |
| 招募与同意 | 第5步 |
| 项目负责人 | 第6步确认 |
| 设备与场地 | 技术/学院确认 |

所有附件统一：

- 标题；
- 人数；
-补偿；
- 保存期限；
- 联系方式；
- 设备；
- 版本号。

## 3. Level A

8名专家完成：

- SCCI条目相关性与清晰度；
- 两条件等信息量；
- 四模块映射；
- 非劣界值；
- 风险与安全；
- Go/Revise/No-Go。

## 4. 修订规则

- SCCI `I-CVI ≥ 0.78`；
- `S-CVI/Ave ≥ 0.90`；
- 至少6/8专家认为无关键混杂；
- 专家可要求非劣界值收紧，不得放宽；
- 重大修改回到伦理修订，不在Level B现场改。

## 5. 输出

- 正式受理编号；
- 提交版本校验和；
- 委员会问题和逐条回复；
- Level A报告；
- 获批版本只读归档；
- Level B启动授权。
