## 0. 总体规则（所有表通用）

1. **占位规则**：所有数值位置一律使用 `[占位]`；结论位置一律使用"待观测"。禁止预填方向、虚构数值、根据设计推断效应。
2. **分析集**：`all_randomized` 与 `complete_four_module` 两集均须报告（protocol_authority `functional_guard.analysis_sets`）；Gate 1 两集都须通过才可主张原生替代。
3. **门控顺序**：样本流 → 实现与混杂 → Gate 1 → SCCI → 四层理解 → 心智努力 → 联合 Gate 2 → 次要家族 → 独立重建 → 四场景知识 → 序列扩展（条件）→ 敏感性。
4. **Gate 判定**：`COMPLIANT` / `NONCOMPLIANT` / `TECH_UNOBSERVABLE` 三态；Gate 2 必须明确通过或失败，不允许补偿。
5. **统计口径**：主结果模型 `NA_post ~ cue_mode + centered_NA_pre + randomization_strata`，HC3；非劣界 `0.075`（`INHERITED_REQUIRES_JUSTIFICATION`，须冻结论证）；双侧 `alpha=0.05`；缺失 100 次插补；次要家族冻结后 FDR。
6. **功效与样本**：Level C 锚点 48；阶段一旧完整目标 192（每方案 96）、旧招募上限 240；主功效目标候选 0.9；`formal_randomized_n` / `formal_recruitment_cap` / `stopping_rule` 在盲态参数（方差、缺失、上限效应、联合通过率）Monte Carlo 后冻结。
7. **条件命名**：`scene_native`（原生）、`abstract_pacer`（抽象双环）。分析用 `native_minus_abstract` 方向。
8. **占位符规范**：`[占位]`（数值/文本）、`[待冻结]`（界值/参数）、`[待观测]`（结论方向）、`[N/A]`（不适用，如条件式扩展未触发时）。禁止用 `-`、`NaN`、`0` 等占位；缺失测量用空值与原因码（`mock_forbidden=true`）。
