# U12-03 两方案公平教学与形成性比较合同

## 交付范围

这是可制作、可审查的教学合同候选，不是已完成的真人教学或正式研究冻结。两条件比较完整提示方案的收益、代价与适用边界，不预设哪组胜出。任务达到IN_REVIEW后仍需真实第二人签收。

- [机器合同](contract.json)：候选预算、顺序、边界。
- [教学脚本与两臂匹配矩阵](teaching.md)：给Unity、Q-01/Q-02制作和检查。
- [形成性过程与交接](formative.md)：材料修改、实际记录和研究冻结出口。
- [记录模板](observation.template.json)：空白字段不是实际观察。
- [来源与冲突](sources.md)：明确现有输入的适用范围。
- `validate.py`：只检查合同一致性、配置适配及模板。
- `build_evidence.py --check`：复算来源与交付文本哈希。
- `test_contract.py`：包含不等预算、旧时序、隐藏操纵、无限训练和假正式许可负例。

候选预算180秒是项目试做选择，不是文献证明的最佳时长。正式预算仍为null。共同设备准备和前后量表不计入180秒；800秒核心体验保持原样，其中每模块25秒demo不重复加在总时长外。
