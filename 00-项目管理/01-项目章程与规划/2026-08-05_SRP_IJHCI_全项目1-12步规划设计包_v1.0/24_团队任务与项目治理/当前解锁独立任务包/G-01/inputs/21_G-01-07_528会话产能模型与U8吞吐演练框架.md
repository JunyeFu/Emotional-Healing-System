## 1. 模型目标与约束

### 1.1 目标
建立可执行的产能预测与资源调度模型，确保在**528会话上限**（Level C 48 + 阶段一 240 + 阶段三 240）下，研究能在合理周期内完成，并为U8硬门提供判断基准。

### 1.2 硬性约束（来自v1.1权威）
| 约束项 | 数值 | 来源 |
| :--- | :--- | :--- |
| 总会话上限 | **528次** | protocol_authority_v1.1.json |
| 单次工位占用 | **55 ~ 70分钟** | 13号裁定 §12 / capacity字段 |
| 每工位每日稳定完成量 | **≤ 6次**（含缓冲） | 由55~70分钟推导，含设备清理、记录、紧急处理 |
| 两周演练要求 | **必须提交真实数据** | 13号裁定 §12 / U8门 |
| 样本上限不足时 | **NO_GO 或重审资源** | 13号裁定 §12 |

### 1.3 关键推导（修正后）

| 参数 | 保守估算 | 乐观估算 | 说明 |
| :--- | :--- | :--- | :--- |
| 单次工位占用 | **70分钟** | **55分钟** | 含设备准备、标准化训练、PANAS、800s核心体验、问卷、过渡 |
| 每日有效测试时间 | **6小时** | **7小时** | 扣除设备校准、实验员交接、异常处理、午休 |
| 单工位日产能 | **5次** | **7次** | 6×60÷70≈5.14 → 取5；7×60÷55≈7.6 → 取7 |
| 两周（14天）单工位产能 | **70次** | **98次** | 保守/乐观区间 |
| 达到528次所需工位数 | **8个** | **6个** | 528÷70≈7.54 → 8；528÷98≈5.39 → 6 |
| 可用工位上限 | **≤ 4个**（初始假设） | — | 若4工位，则保守产能为 4×70=**280次/两周**，远不足528 |

> **结论**：在4工位、55~70分钟/次的真实条件下，**两周内无法完成528次**。这正是U8演练需要揭示并裁决的核心风险。

## 3. 两周吞吐演练方案

### 3.1 演练目的
在真实条件下测试全流程（招募→预约→设备准备→核心体验→数据回收→清理），验证实际产能是否支撑正式阶段启动（U8门）。

### 3.2 演练规模
- **窗口**：连续 14 个自然日（D1~D14），其中 D6~D12 为 7 天执行期（与 `G-01-08` 第 2 节里程碑一致）；
- **计划演练产能**：4 工位 × 5 次/工位/日（保守）× 7 执行日 = **140 次**；
- **最低要求**：完成 **≥ 112 次** 完整会话（计划演练产能的 80%，含所有模块及问卷）；
- **预约目标**：按到场率 85%、到场完整率 80% 反推，确认预约 **≥ 165 人**（112 ÷ 0.85 ÷ 0.80 ≈ 164.7，向上取整）；
- **覆盖变量**：不同时段（上午/下午）、不同实验员组合、设备轮换、故障模拟。

### 3.3 演练记录字段（必须报告）
每场会话记录以下字段（参见偏离模板`G-01-06`）：

| 字段 | 定义 |
| :--- | :--- |
| 日期/时段 | 精确到上午/下午 |
| 工位编号 | 1~4 |
| 参与者状态 | 预约 / 到场 / 完成 / 爽约 / 中止 |
| 核心体验完成度 | 4模块全完成 / X模块中断 |
| 实际工位占用时长 | 从设备准备到数据存储完毕 |
| 技术故障代码 | 引用偏离模板第3节（T-UNI、T-BRE等） |
| 数据状态 | Complete / Tech-Incomplete / Aborted / Invalid |
| 主实验员签名 | — |

## 4. U8产能硬门判定逻辑

根据`13_IJHCI独立审稿攻击与升级裁定_v1.1.md` §11—§12，**U8未通过前不得启动正式阶段**。

### 4.1 演练报告必须包含的数据
| 指标 | 定义 | 目标参考值 |
| :--- | :--- | :--- |
| 触达人数 | 招募广告/渠道触达的潜在人数 | — |
| 筛选通过人数 | 通过安全筛查和纳入标准的人数 | — |
| 预约人数 | 确认具体场次的人数 | — |
| 到场人数 | 按时到达工位的人数 | — |
| 完整会话数 | 完成全部4模块+前后测+问卷 | ≥ 计划演练产能的80%（≥112次） |
| 爽约率 | 1 - 到场/预约 | < 15% |
| 非完整率 | 1 - 完整会话/到场 | < 20% |
| 技术故障致会话中断率 | 中断会话数 / 到场数 | < 10% |
| 实际平均工位占用时长 | — | 55~70分钟 |

### 4.2 判断规则（U8通过 / NO-GO）

| 条件 | 结论 | 后续行动 |
| :--- | :--- | :--- |
| **通过**：完整会话数 ≥ 计划演练产能的80%（4工位×5次/日×7执行日=140次，80%即**112次**）且爽约率<15%、非完整率<20%、故障率<10%、平均占用≤70分钟 | **U8 通过** | 启动正式阶段；持续监测产能 |
| **NO-GO**：任一项未达标 | **U8 阻断** | 按裁定顺序处置：①延长周期；②增加工位；③取消阶段三；④重审范围与资源；**不得压缩样本或并行使用同一批参与者** |

## 5. 产能缺口缓冲策略（若4工位不满足528次总时限）

若两周演练显示实际产能无法在可接受周期内完成528次，按以下顺序决策：

| 优先级 | 措施 | 可执行性 | 代价 |
| :---: | :--- | :--- | :--- |
| 1 | **延长运行日历天数**（从4周增至6~8周） | 高 | 时间成本上升；人员/场地延续费用 |
| 2 | **增加工位至6个** | 中 | 设备、场地、人员翻倍；招募压力增大 |
| 3 | **取消阶段三**（仅保留阶段一主贡献） | 低（学术价值折损） | 论文贡献层级降级；需返回审稿裁定重新评估 |
| 4 | **NO_GO 终止项目** | 最低 | — |

> **绝对禁止**：压缩单次工位占用时长低于55分钟、合并Level C与阶段一样本、减少模块数量或降低问卷完整性以换取产能。
