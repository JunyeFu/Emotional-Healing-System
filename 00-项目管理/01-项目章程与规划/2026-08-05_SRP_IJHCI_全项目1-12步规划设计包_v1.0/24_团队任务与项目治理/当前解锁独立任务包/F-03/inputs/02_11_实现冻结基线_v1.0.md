## 1. 单篇论文和三阶段证据链

只写一篇IJHCI目标论文，两项贡献按主次进入同一条有序证据链：

1. 阶段一主贡献：比较 `scene_native` 与 `abstract_pacer`；
2. 阶段一同时为序列研究提供 `scene_native` 的24顺序均衡随机发现数据；
3. 阶段二：只用阶段一 `scene_native` 数据学习、审计并冻结可解释策略，不新增参与者；
4. 阶段三次贡献：用全新参与者比较冻结策略与 `scene_native` 均衡随机基准。

每位参与者只参加一个阶段、一个条件、一次核心体验。阶段一和阶段三样本不得重叠。

## 2. 核心体验冻结

每个天气—呼吸复合模块采用：

| 段 | 目标值 | 技术预试允许区间 | 正式语义 |
|---|---:|---:|---|
| `demo` | 25秒 | 24至30秒 | 只呈现目标结构 |
| `closed_loop` | 150秒 | 140至160秒 | 真实呼吸驱动实际反馈与累计状态 |
| `lock_transition` | 25秒 | 20至30秒 | 锁定闭环末状态并自动转场 |

推荐核心体验总长13分20秒。技术预试可在区间内选择一次；同一正式阶段的两个条件必须使用完全相同的冻结时长，且不得按个体状态改变模块时长。

参与者在核心体验内平坐观看并跟随提示，不进行手部操作。参与前后量表和体验后问卷位于核心体验之外。

## 3. 三重有序证据门

### Gate 1：呼吸执行质量非劣

```text
D1 = mean(PF_scene_native) - mean(PF_abstract_pacer)
Delta_NI = 0.075
H0: D1 <= -0.075
H1: D1 > -0.075
```

参与者级 `protocol_fidelity` 先按四个模块分别计算，再以每模块25%等权聚合。完整分析集和完整四模块集的双侧95%置信区间下界都必须严格大于 `-0.075`；任一未通过或无法稳定估计，Gate 1失败。

### Gate 2：场景—提示语义一致性优效

仅在Gate 1通过后进行确认性解释：

```text
D2 = mean(SCCI_scene_native) - mean(SCCI_abstract_pacer)
H0: D2 <= 0
H1: D2 > 0
```

SCCI是体验后一次填写的5条、7点评分工具，结果为五条均值。它只测量提示运动与天气表达之间的相关性、可理解性和整体一致，不混入喜欢度、舒适度或短时负面情绪。

SCCI在正式阶段前必须通过适用性门：

- 8名跨设计、HCI和测量方法专家；每条 `I-CVI >= 0.78`，`S-CVI/Ave >= 0.90`；
- 12至16名目标用户认知预试；所有关键误解完成修订并复核；
- 48名技术预试对象，两个提示条件各24名；`omega >= 0.70`、校正条目总分相关均不低于0.30、总分地板或天花板比例均低于20%；
- 任一门未过，先修订并重复对应预试；不得让未通过的SCCI承担Gate 2。

### Gate 3：冻结序列策略优效

仅在Gate 1和Gate 2通过、阶段二策略完成冻结后启动阶段三确认性招募：

```text
D3 = adjusted_mean(NA_post_policy) - adjusted_mean(NA_post_random)
H0: D3 >= 0
H1: D3 < 0
```

主要量表结果是中文版20项PANAS负性维度的体验后得分，以体验前得分作协变量。Gate 3使用双侧95%置信区间；上界严格小于0时通过。若前序门未通过，后续结果只作探索，不越级支撑论文主张。

## 4. 量表和真实设备数据的职责

- PANAS前后数据回答完整体验的短时变化、阶段三策略相对随机顺序的增量作用，以及阶段一顺序发现分析；
- 呼吸数据回答各天气—呼吸复合模块的执行质量与过程轨迹；
- Polar H10数据只作预设过程特征、差异解释和策略候选输入，不替代Gate 1或PANAS；
- 固定天气—呼吸映射只能解释复合模块，不能拆成天气单独作用或呼吸流程单独作用；
- 没有无项目条件，不声称观察到的全部前后变化都由项目本身造成。

## 5. Gate 1分析与缺失结果

### 分析集

- 完整分析集：保留全部随机分配对象及原条件，是Gate 1主要分析；
- 完整四模块集：仅包含四模块均达到盲态技术可评估门的对象，是支持性分析；
- 有效记录但执行不符合的周期始终计为失败，不得据此排除对象；
- 两个分析都过 `-0.075` 才能通过Gate 1。点估计方向不一致时执行预注册偏差审计，但不事后改变成功标准。

### 缺失方法

完整分析集采用100次有界多重插补：

1. 插补模型至少包含提示条件、PANAS前测、24顺序、可用模块PF、各模块信号覆盖率、断流时长、设备/构建版本和预注册分层变量；
2. 使用预测均值匹配，插补值截断在 `[0,1]`，按Rubin规则合并；
3. 主要非劣分析采用总不利偏移 `delta=0.075`：`scene_native`插补值减0.0375，`abstract_pacer`插补值加0.0375，再截断到 `[0,1]`；
4. 敏感性网格使用总偏移 `0, 0.025, 0.05, 0.075, 0.10, 0.15`；
5. tipping-point报告给出结论首次失败的总偏移；
6. 禁止单值均值填补、长期断流插值和用完整记录分析冒充完整分析集。

该方案把主要插补假设明确推向不利方向。技术预试只估计缺失机制和模型稳定性，不使用条件效果方向调节偏移。

## 6. Gate 1与Gate 2模型

Gate 1以参与者级四模块等权PF为结果，主模型为带HC3稳健标准误的线性调整模型：

```text
PF_participant ~ cue_mode + sequence_24 + centered_NA_pre
```

报告调整后绝对比例差及95%置信区间。预设敏感性包括未调整差、分层bootstrap和有界结果模型；不得把周期级模型替代已确认的参与者级主要结果。

Gate 2主模型：

```text
SCCI_mean ~ cue_mode + sequence_24 + centered_NA_pre
```

使用HC3稳健标准误，报告调整均值差、标准化差和95%置信区间。喜欢度、UES-SF、舒适度和心智努力均为次要结果。

## 7. 阶段一样本量门

样本量由Gate 1与Gate 2中要求较大的结果决定，目标功效90%，确认性显著性对应双侧95%置信区间。

- Gate 1规划锚点：真实差为0、`SD(PF_participant) <= 0.15`、`Delta_NI=0.075`时约需每组85个完整四模块结果；
- Gate 2最小关注效应冻结为参与者级SCCI均值的标准化差 `d=0.50`。小于该幅度不足以证明复杂场景原生提示值得替代更简单的抽象提示；约需每组85个可分析结果；
- 24顺序在每个提示条件内严格平衡，因此完整结果目标向上取整为每组96、阶段一共192；
- 招募按完整48人随机化块追加。以不超过20%的非完整率规划，初始招募上限为240人；
- Level C后只允许使用盲态方差、可靠性和非完整率重算，不得用观察到的条件差缩小样本；
- 若重算需要超过阶段一336人，或任一提示条件无法保持24顺序平衡，则阶段一正式研究为 `NO_GO`，必须重审范围或资源，不能带不足功效启动。

正态近似规划锚点可由 `22_离线处理与科研分析/08_sample_size_anchors.py` 重建；正式人数仍须由Level C盲态参数进入模拟后冻结。

## 8. 阶段二策略冻结

阶段二只使用阶段一 `scene_native` 数据。策略目标为降低预测的体验后PANAS负性得分；PF、SQI和降级比例作为约束，不与PANAS合成单一奖励。

候选状态只包括：PANAS前测、当前位置、已完成模块、上一模块、最近模块PF、最近模块信号质量、累计降级时长和剩余合法模块。禁止使用身份字段或体验后信息。

策略实现冻结为可解释随机策略：

1. 用带岭惩罚的线性状态—动作价值模型预测终点PANAS负性得分；
2. 特征由预注册主效应、位置、相邻转换和 `PANAS_pre`/最近PF与候选动作的交互组成；
3. 正则强度和softmax温度只在阶段一数据的嵌套交叉验证内选择；
4. 选择概率为 `0.20 / |A| + 0.80 * softmax(-Q(a,s)/tau)`，保证每个合法动作保留正概率；
5. 缺失状态或质量不足时退回剩余模块均匀随机；
6. 冻结特征、系数、缩放器、温度、随机种子规则、版本和回退条件；
7. 每次选择记录状态快照、候选集合、各动作概率、抽样值、结果和理由码，保证重放。

不增加“候选较优固定顺序”第三组。该组会增加招募和多重比较，但不增加论文两项核心贡献的必要识别能力。

## 9. 阶段三样本量与模型

阶段三按1:1随机进入冻结策略或24顺序均衡随机基准。随机基准组内24顺序严格平衡。

- 主要模型：`NA_post ~ assignment + centered_NA_pre + preregistered_strata`；
- 最小关注效应：标准化调整差 `d=0.50`；功效90%；
- 完整结果目标每组96、共192；以不超过20%的非完整率规划，初始招募上限240；
- 按48人块追加；Level C式盲态参数复核可增加但不得基于策略效果缩小；
- 需要超过336人则阶段三为 `NO_GO`；
- 完整分析集采用有界多重插补和向策略组不利的偏移敏感性分析，完整会话集作为支持性分析。

## 10. 技术预试必须产出的数值

以下不是开发前的用户确认门，而是Level C必须按冻结算法产出的配置：

- 每模块有效同步呼吸信号覆盖率；实现起点80%；
- 每模块最低可分析周期数；实现起点为冻结目标时长内理论周期数的70%向上取整；
- 四模块结构硬门与阶段时长/总周期容差；实现起点分别为25%和20%；
- 呼吸事件检测相对双人盲态标注的F1、阶段边界MAE和分歧率；目标为周期F1不低于0.85、边界MAE不高于0.50秒；
- 在线—离线PF绝对差；目标中位数不高于0.03、95%分位不高于0.075；
- 时钟偏差和端到端反馈延迟；目标偏差不高于50毫秒、延迟P95不高于200毫秒；
- 30分钟设备稳定性、丢包、断流和重连结果。

任何目标未过先修复并重做Level C。正式数据可见后不得放宽。

## 11. 方法依据与适用边界

- [FDA非劣方法指南](https://www.fda.gov/media/78504/download)：非劣界值、置信区间、研究质量和分析集风险；
- [ICH E9(R1)估计目标与敏感性分析](https://www.fda.gov/media/108698/download)：先定义问题、事件处理、主要估计与针对同一问题的敏感性分析；
- [COSMIN内容效度方法](https://pmc.ncbi.nlm.nih.gov/articles/PMC5891557/)：相关性、完整性和可理解性证据；
- [Polar H10官方能力说明](https://github.com/polarofficial/polar-ble-sdk/blob/master/documentation/products/PolarH10.md)：130Hz ECG与RR能力；
- [PLUX respiBAN BLE说明](https://support.pluxbiosignals.com/knowledge-base/respiban-ble-getting-started/)：固定400Hz呼吸与运动数据能力。

这些来源用于方法和设备能力判断，不构成本项目结果证据。SCCI阈值、样本量关注效应和策略形式均为本项目预注册设计选择，必须如实表述。
