# 第9步执行方案：Level C、参数冻结与预注册 v1.1

## 1. 分配

48名新参与者按1:1进入`scene_native`或`abstract_pacer`，每人只完成一次四模块核心体验。分配使用独立清单、隐藏分配、可变块和清单哈希；完成结果不用于定向补人。

## 2. 技术冻结对象

- 真实呼吸与心电设备、采样率、序列号和固件；
- 单调时钟、四时间戳交换、漂移模型和同步不确定度；
- 呼吸事件、机会时间线、SQI、降级和中止；
- 推荐25/150/25秒模块时序及允许小区间；
- 两个完整提示表示方案和混杂审计区间；
- SCCI、四层理解、心智努力及次要家族；
- Unity/Python/TD构建、QC、原因码和缺失规则。

## 3. 冻结门

| 指标 | 要求 |
|---|---|
| 日志完整率 | 不低于99% |
| Python/Unity时间偏差 | 不高于50毫秒，并记录不确定度 |
| 外部测量反馈延迟P95 | 不高于200毫秒 |
| 吸呼事件F1 | 不低于0.90 |
| 停顿与补吸事件F1 | 不低于0.80 |
| SCCI | 可靠性、项目分布和条件间项目功能差异可接受 |
| 四层理解与心智努力 | 工具可执行，非劣界可在盲态下冻结 |
| 完整流程 | 无TD、无Mock、四模块恰好各一次 |

## 4. 样本模拟

只使用盲态干扰参数：有界结果分布、上限效应、方差、非完整率、机会不可观测、两个分析集同时通过率、工具可靠性和协变量相关。不得使用观察到的条件效果方向缩小样本。

## 5. 预注册必须锁定

- Gate 1至3的估计目标和有序规则；
- Gate 2的三组件、非劣界和反证模式；
- 机会分母PF、分析集、原因码、缺失和敏感性；
- 随机化单位、分层、可变块、生成/保管角色、揭示时点和清单哈希；
- 次要结果家族FDR与模块描述规则；
- 阶段二参与者分组交叉拟合、行为概率、离线策略价值、有效样本量和均匀回退；
- 版本、构建、设备和数据可用性声明。

## 6. 正式发布

生成`FORMAL-1.1.0`候选构建、校验和、Schema、随机化清单、现场SOP、只读预注册和外部批准记录。任一门未过时不得生成正式招募授权。
