## 一句话主线

本项目构建一套由 Unity 独立运行的、无手部操作的天气—呼吸闭环体验，将四种结构不同的呼吸协议转译为场景原生视觉提示，由真实生理设备驱动实时反馈；TouchDesigner承担实验员监控，Python承担设备、时钟、协议、记录与离线处理。包内建议第一篇 IJHCI 目标论文比较场景原生提示与统一抽象提示，并把24种顺序探索与可解释自适应编排保留为后续研究；该论文分阶段方案仍待用户确认。

## 关键边界

- Unity 制品必须脱离 TouchDesigner 完成完整参与者体验。
- TouchDesigner不提供参与者侧必要画面，只做实验员监控。
- 正式实验使用真实设备；Mock只用于开发、联调和故障注入。
- 四天气与四呼吸流程固定配对，只能解释复合模块，不能分别归因天气或呼吸法。
- “第一篇聚焦场景原生提示对照、序列编排后置”是当前推荐方案，尚未获得用户确认。
- 24种顺序、自适应策略和独立确认作为已确认的长期研究方向保留。
- 未获伦理批准前，不招募Level B、Level C或正式参与者。
- 不作个体健康判断、个体干预或效果承诺。
