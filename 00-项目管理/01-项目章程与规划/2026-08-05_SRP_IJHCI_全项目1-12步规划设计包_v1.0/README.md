## 一句话主线

本项目构建一套由Unity独立运行、无手部操作的天气—呼吸闭环体验，将四种结构不同的呼吸协议转译为场景原生视觉提示，由真实设备记录驱动实时反馈；TouchDesigner承担实验员监控，Python承担设备、时钟、协议、交互状态估计、记录与离线处理。单篇IJHCI目标论文以完整提示表示方案为主贡献，以可解释序列编排为条件式部署扩展。三阶段方案已经冻结为设计权威，但全部研究结果仍是拟验证状态。

## 关键边界

- Unity 制品必须脱离 TouchDesigner 完成完整参与者体验。
- TouchDesigner不提供参与者侧必要画面，只做实验员监控。
- 正式实验使用真实设备；Mock只用于开发、联调和故障注入。
- 四天气与四呼吸流程固定配对，只能解释复合模块，不能分别归因天气或呼吸法。
- 只写一篇论文；完整提示表示方案是唯一主贡献，序列编排仅为条件式部署扩展。
- SCCI只作操纵检查；Gate 2还必须通过条件中性的四层理解和心智努力门。
- 24种顺序用于均衡分配与低容量策略发现，不用于声称某条固定顺序普遍最佳。
- 未获伦理批准前，不招募Level B、Level C或正式参与者。
- 不作个体健康判断、个体干预或效果承诺。
