# 完整研究方案摘要

## 1. 研究问题

与统一抽象呼吸提示相比，场景原生呼吸引导能否：

1. 在呼吸协议执行质量上达到非劣；
2. 在功能底线成立后，提高提示—场景语义一致性。

## 2. 条件

### 场景原生提示

目标呼吸、真实反馈和累计恢复由保护罩、冷却气流、路径显现、色彩扩散等场景机制表达。

### 抽象提示

外环表达目标呼吸，内环表达真实呼吸；累计恢复仍由天气场景表达。

### 保持一致

- 场景；
- 呼吸协议；
- 音频；
- 时长；
- 真实设备；
- 累计恢复；
- 模块顺序；
- 说明和量表；
- 数据质量规则。

## 3. 四个复合模块

| 模块 | 协议 | 场景机制 |
|---|---|---|
| 风暴 | 3-3-3-3四阶段 | 保护罩与风雨 |
| 炙烤 | 4-6长呼气 | 冷却气流与热浪 |
| 暴雪 | 5-5等时 | 路径、脚印与雪雾 |
| 褪色 | 循环叹息 | 色彩汇聚与扩散 |

循环叹息的精确时间包络仍需Level C冻结。

## 4. 主要结果

```text
protocol_fidelity
= 符合预注册结构和时序容差的周期数
  / 可分析周期数
```

主要非劣界值为10个百分点，正式实验前只能收紧，不能放宽。

## 5. 第二结果

SCCI-5测量提示、实际反馈和环境变化是否构成统一、合理的体验。其条目需经专家CVI、认知访谈和可靠性验证。

## 6. 研究流程

```text
Level A专家审查
→ 伦理批准
→ Level B 12人
→ 修改
→ Level C 24人双访视
→ 更新干扰参数
→ 预注册
→ 正式104人
→ 数据锁库
→ 盲态分析
→ IJHCI投稿
```

## 7. 样本量

- 计划104人；
- 目标88个有效配对样本；
- 8个平衡分配单元，每单元13人；
- 必要时替补，总招募不超过120人。

## 8. 结论边界

不能声称：

- 缓解焦虑或长期低落状态；
- 单独天气或单独呼吸法有效；
- 项目导致全部前后情绪变化；
- HRV等同于情绪改善；
- 第一篇已经证明自适应顺序优于随机顺序。
