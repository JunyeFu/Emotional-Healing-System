# Level C 真实设备技术预试SOP

> **SUPERSEDED / NOT_FOR_RECRUITMENT / NOT_FOR_SUBMISSION**
> 本v1.0材料仅作迁移与审计证据；它仍含旧流程和待关闭字段。必须完成G-01、双人逐字段复核及外部门禁后，才能使用新的v1.1材料。


## 一、目的

Level C使用24名新参与者完成正式双访视流程，用于验证：

- 设备和时间同步；
- 呼吸事件检测；
- 三层视觉反馈；
- SCCI可靠性；
- 数据缺失和退出；
- 功效模拟干扰参数；
- 实验员执行一致性。

Level C不用于确认主要研究效应。

## 二、分配

```text
24人
= 2种条件顺序
× 4种Williams序列
× 每单元3人
```

## 三、访视前

1. 检查伦理批准覆盖Level C；
2. 使用冻结招募广告；
3. 完成知情同意和敏感信息单独同意；
4. 使用安全筛查表；
5. 分配编号，不在运行目录保存姓名；
6. 确认版本和设备。

## 四、每次访视

1. 健康状态确认；
2. PANAS前测；
3. 设备佩戴；
4. 5分钟自然呼吸基线；
5. 防过度通气说明；
6. 四协议理解检查；
7. 8分钟主体验；
8. PANAS后测；
9. SCCI、UES-SF、心智努力、舒适度和操纵检查；
10. 设备解除；
11. 不适确认；
12. 数据包校验。

## 五、技术指标

| 指标 | 门 |
|---|---:|
| 原始日志完整率 | ≥99% |
| Unity/Python关键事件偏差 | ≤50 ms |
| 反馈延迟P95 | ≤200 ms |
| 模块主要窗口可用数据中位比例 | ≥95% |
| 吸/呼事件F1 | ≥0.90 |
| 停顿/双吸结构F1 | ≥0.80 |
| 普通事件时间MAE | ≤250 ms |
| 停顿/补吸MAE | ≤400 ms |
| SCCI McDonald’s ω | ≥0.70 |
| 双访视完成率 | ≥85% |
| 呼吸不适退出率 | <10% |
| 严重不良事件 | 0 |

## 六、正式效应隔离

Level C完成前，分析团队只使用中性条件标签X/Y。

Level C允许估计：

- 基础执行比例；
- 周期数；
- 方差；
- 参与者内相关；
- 缺失率；
- 量表可靠性。

禁止使用观察到的X/Y效应大小降低正式样本量。

## 七、人工标注

- 两名盲态标注员；
- 每人每模块随机至少3个周期；
- 所有降级、检测不确定和结构错误周期全部标注；
- 分歧由第三人处理；
- 报告F1、MAE和一致性；
- 不只报告相关系数。

## 八、暂停

出现：

- 严重不良事件；
- 两名以上相似中度不适；
- 呼吸相关退出达到10%；
- 数据泄露；
- 版本错误；
- 设备系统性失效；

立即暂停新增参与者。

## 九、Level C后

1. 关闭条件标签；
2. 生成自动QC；
3. 完成人工标注；
4. 冻结算法参数；
5. 更新干扰参数；
6. 重新运行样本量模拟；
7. 确认正式104人或提交修订；
8. 完成预注册；
9. 生成正式构建和校验和。
