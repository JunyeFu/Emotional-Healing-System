# 材料字段字典

> **SUPERSEDED / NOT_FOR_RECRUITMENT / NOT_FOR_SUBMISSION**
> 本v1.0材料仅作迁移与审计证据；它仍含旧流程和待关闭字段。必须完成G-01、双人逐字段复核及外部门禁后，才能使用新的v1.1材料。


| 占位字段 | 来源/责任人 | 必须一致出现的文件 |
|---|---|---|
| 项目负责人 | 导师、学院、伦理机构确认 | 申请书、同意书、招募 |
| 伦理委员会 | 学院科研秘书确认 | 同意书、投诉、申请书 |
| 伦理编号 | 批准后填写 | 所有参与者文件 |
| 研究地点 | 项目负责人 | 申请书、招募、SOP |
| 紧急流程 | 学校/场地 | 同意书、SOP、结束说明 |
| 呼吸设备 | 技术负责人 | 申请书、SOP、CRF |
| ECG设备 | 技术负责人 | 申请书、SOP、CRF |
| 补偿金额 | 经费负责人、伦理批准 | 同意书、招募 |
| 数据保存期限 | 机构政策、伦理批准 | 同意书、敏感同意、申请书 |
| PANAS版本 | 测量负责人 | 申请书、问卷、预注册 |
| 研究联系人 | 项目负责人 | 同意书、招募、结束说明 |
| 投诉联系人 | 伦理机构 | 同意书、结束说明 |
| 经费来源 | 项目负责人 | 申请书 |
| 研究起止时间 | 项目负责人 | 申请书、伦理系统 |
