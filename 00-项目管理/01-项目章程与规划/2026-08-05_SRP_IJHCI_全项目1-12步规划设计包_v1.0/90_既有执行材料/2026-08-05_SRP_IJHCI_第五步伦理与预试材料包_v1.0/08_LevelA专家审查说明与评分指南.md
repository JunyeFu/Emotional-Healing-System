# Level A 专家审查说明与评分指南

## 一、目标

Level A不是请专家判断项目“好不好”，而是审查：

1. 研究问题是否可识别；
2. 两个条件是否只改变提示载体；
3. 四模块映射是否清楚；
4. SCCI是否测量语义一致性；
5. 非劣界值是否具有实际意义；
6. 风险和中止规则是否充分；
7. 是否存在设计、软件或生理层面的致命缺陷。

## 二、专家构成

计划8人：

- HCI/交互研究2人；
- 视觉/数字媒体设计2人；
- 软件/实时系统/可穿戴2人；
- 心理测量/呼吸生理/伦理2人。

## 三、审查材料

- 第一至第五步主文档；
- 两条件视频或可运行原型；
- 四模块映射表；
- SCCI条目；
- 风险SOP；
- 数据契约和版本说明；
- 专家评分表。

## 四、评分方式

### SCCI条目

相关性和清晰度均使用4级：

1. 不相关/不清楚
2. 需要重大修改
3. 相关/清楚，但需小修改
4. 高度相关/非常清楚

CVI中3或4记为“内容有效”。

### 两条件比较

每项使用：

- 0：存在关键混杂；
- 1：需要重大修改；
- 2：可接受但需小修改；
- 3：满足要求。

## 五、通过门

- 每个SCCI条目 `I-CVI ≥ 0.78`；
- `S-CVI/Ave ≥ 0.90`；
- 至少6/8专家认为无关键条件混杂；
- 至少6/8接受10个百分点非劣界值或要求更严格；
- 无未解决的重大安全反对；
- 设计、软件和测量三方均有可执行路径。

## 六、利益冲突

专家需说明是否：

- 直接参与系统开发；
- 是论文作者候选；
- 与项目负责人有直接考核关系；
- 对某条件有明显利益或立场。

存在利益冲突者可以提供咨询意见，但内容效度评分应单独报告敏感性结果。

## 七、审查输出

每名专家提交：

1. SCCI评分；
2. 两条件等信息量评分；
3. 非劣界值意见；
4. 风险意见；
5. 必须修改项；
6. 可选建议；
7. Go / Revise / No-Go判断。
