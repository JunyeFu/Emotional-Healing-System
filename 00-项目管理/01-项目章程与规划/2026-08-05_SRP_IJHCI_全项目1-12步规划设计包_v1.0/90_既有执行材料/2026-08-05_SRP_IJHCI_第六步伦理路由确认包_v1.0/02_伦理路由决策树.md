│  ├─ 寻找具备资格且愿意承担责任的校内导师
│  └─ 未解决前停止参与者研究

   ↓
联系软件学院科研秘书陈秋余（020-81182603）
   ↓
学院确认是否有当前校内常规人体伦理受理渠道？
├─ 有
│  ├─ 获取系统、模板、负责人资格和审查周期
│  └─ 进入该渠道

   ↓
学院确认是否需由附属第二医院或其他受委托委员会受理？
├─ 附属第二医院接受
│  ├─ 获取账号和模板
│  ├─ 确认非医院场地、非医院就诊人群研究是否受理
│  └─ 提交
├─ 合作医院受理
│  ├─ 必须有真实合作关系
│  ├─ 明确数据采集地点和责任
│  └─ 签署合作文件
├─ 学校其他委员会受理
│  └─ 按其模板提交
└─ 无机构受理
   ├─ 不得招募参与者
   ├─ 向科研院申请书面指导
   └─ 调整项目时间表或建立合规合作

## 关键分支说明

### 1. 不能为了获得批件虚构医院合作

若不在医院采集、没有医院研究人员参与，不得把医院写为合作单位。

### 2. 不能先采数据后补伦理

IJHCI和一般研究伦理都要求在研究开始前获得批准。后补批件通常不能使既有数据自动合规。

### 3. Level A的处理

Level A专家可能只是提供内容咨询，也可能被纳入系统性研究数据。必须向伦理机构确认：

- 作为项目咨询是否可在批准前开展；
- 如果计算CVI并写入论文，是否属于研究参与者数据；
- 是否需要专家知情同意。

在未确认前，按需要伦理覆盖处理更稳妥。
