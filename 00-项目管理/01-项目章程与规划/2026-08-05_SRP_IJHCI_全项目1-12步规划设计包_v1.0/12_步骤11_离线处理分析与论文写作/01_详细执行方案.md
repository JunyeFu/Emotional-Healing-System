# 第11步执行方案：离线处理、锁库、分析和论文

## 1. 数据处理顺序

```text
L0 原始数据
→ L1 同步和SQI
→ L2 呼吸事件与周期
→ L3 模块/会话摘要
→ FAS/PPS
→ L4 锁定分析集
→ L5 模型、图表、论文表格
```

## 2. 盲态锁库

- 条件使用X/Y；
- 人工标注员不知真实条件；
- 排除和事件算法先冻结；
- 生成校验和；
- 项目负责人签署锁库；
- 揭盲后不改主要规则。

## 3. 确认性分析

### Gate 1

周期级Binomial GLMM，估计：

```text
PF_scene_native - PF_abstract
```

单侧97.5%下限大于-0.10才支持非劣；FAS和PPS都需支持。

### Gate 2

Gate 1通过后比较SCCI。

## 4. 次要分析

- PANAS-NA基线校正；
- UES-SF；
- 心智努力；
- 舒适性；
- 模块交互；
- HR/lnRMSSD等过程特征；
- 数据质量和降级。

## 5. 定性综合

主题重点：

- 如何识别目标；
- 如何识别实际反馈；
- 如何理解累计变化；
- 哪些映射自然；
- 哪些映射失败；
- 原生与抽象提示的注意分配差异。

## 6. 设计原则

原则必须由跨模块证据支持，至少包含：

- 周期与累计时间尺度分离；
- 目标与实际必须可区分；
- 不同呼吸结构不能机械复用同一动画；
- 场景语义不能牺牲相位边界；
- 数据不足时不伪造闭环；
- 场景原生提示并非在所有结构中都优于抽象提示。

## 7. 论文写作顺序

1. 方法和分析计划；
2. 系统与设计框架；
3. 结果表和图；
4. 定性结果；
5. 讨论与原则；
6. 引言和摘要；
7. 限制、伦理和数据声明。
