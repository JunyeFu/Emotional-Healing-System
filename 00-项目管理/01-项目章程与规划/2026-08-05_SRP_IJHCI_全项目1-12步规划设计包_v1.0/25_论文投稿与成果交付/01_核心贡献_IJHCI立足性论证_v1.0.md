# 核心贡献 IJHCI 立足性论证 v1.0

> 日期：2026-08-06
>
> 决定：`CONDITIONAL_GO`
>
> 适用对象：单篇 *International Journal of Human-Computer Interaction* 目标论文
>
> 性质：投稿设计审计，不是录用概率承诺

## 1. 结论先行

当前设计**符合 IJHCI 的选题范围，主贡献具备立足可能，但尚不能仅凭“四种天气、四种呼吸结构、真实设备和前后量表”宣称贡献成立**。

能够承担论文中心的主贡献是：

> **场景原生呼吸引导是一种跨异质呼吸结构的交互表示方法。它把目标节律、实际执行、累计环境变化和数据降级分层映射到场景自身机制，并在相同内容、设备、时长和反馈信息量下，相对统一抽象提示验证其功能底线与设计增益。**

可解释序列编排只有在阶段二完成冻结、阶段三使用全新参与者取得独立比较证据后，才适合作为同篇论文的次贡献：

> **在四个固定复合模块均需完成的约束下，使用可审计的交互状态估计进行概率化序列编排，并证明它相对均衡随机顺序产生增量价值。**

因此，论文应采用“**表示层主贡献 + 编排层次贡献**”的严格层级。主贡献即使成立，也不能自动证明次贡献；次贡献失败时，主贡献仍应能够独立形成完整论文。

## 2. IJHCI 范围匹配

IJHCI 官方范围覆盖交互计算中的认知、创造、社会、健康相关与工效问题，并接收 HCI 理论和应用的实证、定量与定性研究。项目研究的是呼吸数据如何成为无手部交互输入、不同视觉表示如何影响执行与体验、系统如何根据交互状态编排内容，属于明确的 HCI 问题，而不是只汇报一个软件制品。

范围匹配结论：`PASS`。

但范围匹配只解决“期刊是否接收这类问题”，不解决“工作是否足够新”。IJHCI 已发表 HRV 增强呼吸引导、游戏化呼吸系统和自适应界面研究；相邻 HCI 工作也已实现虚拟自然环境中的呼吸反馈、天气隐喻和呼吸驱动自然场景。因此，下列元素都只能算实现材料，不能单独列为原创贡献：

- 天气隐喻；
- 呼吸驱动画面；
- 虚拟自然场景；
- 真实呼吸或心电数据接入；
- 前后量表；
- Unity、Python 或 TouchDesigner 工程；
- 从24种顺序中寻找效果较好的顺序。

## 3. 与最接近工作的差异

| 既有方向 | 已经解决的问题 | 本项目必须提供的新增知识 |
|---|---|---|
| ViBreathe | 用 HRV 数据增强响应式或自适应呼吸引导 | 同一视觉环境中严格比较场景原生表示与抽象表示，并处理多种非同构呼吸结构 |
| 虚拟自然环境 HRV 反馈 | 环境式实现可保持反馈表现并改善部分体验结果 | 消除显示设备与场景内容混杂，验证目标、实际、累计和降级四层表示语法 |
| Respireal 等呼吸驱动自然场景 | 呼吸可以直接改变虚拟自然对象 | 从单一作品推进为跨四种结构、可证伪、可迁移的设计框架 |
| 自适应 GUI 研究 | 数据驱动的界面适配可以改善效率、效果和体验 | 在固定模块集合、真实过程数据、概率下限和完整决策日志约束下验证序列编排 |

真正的新颖性不在“有没有环境反馈”，而在以下四项是否同时成立：

1. **跨结构**：箱式、非对称吸呼、等时慢呼吸和双吸长呼气确实提出不同的相位表达问题；
2. **统一语法**：四个场景共享目标、实际、累计、降级四层规则，而不是四套互不相关的动画；
3. **严格对照**：`scene_native` 与 `abstract_pacer` 只改变提示表示，其他信息和流程保持匹配；
4. **可迁移知识**：结果产出适用条件、失败模式和选择规则，而不只产出“本项目画面更受欢迎”。

## 4. 两项贡献的立足性

### 4.1 主贡献：场景原生呼吸引导框架

| 评价维度 | 当前判断 | 原因 |
|---|---|---|
| HCI问题 | 强 | 直接研究表示方式、可理解性、注意分配、执行与体验的权衡 |
| 新颖性 | 中等、条件式 | 环境式反馈已有大量先例，跨结构语法和同场景等信息量对照才是增量 |
| 可证伪性 | 强 | Gate 1非劣、Gate 2优效、模块交互和失败模式均可能推翻主张 |
| 因果识别 | 强、待实现 | 平行随机分配和提示载体单变量操纵合理，但必须通过匹配审计 |
| 可迁移性 | 中等、待产出 | 当前已有框架骨架，尚需把结果转换为设计规则和适用边界 |

主贡献判断：`CONDITIONAL_PASS`。

Gate 1 与 Gate 2 的有序设计是正确的。它回答的不是“场景是否更漂亮”，而是一个有价值的 HCI 权衡：**把提示嵌入场景后，能否保留抽象控件的功能清晰度，同时获得表示一致性和体验连续性。**

主贡献仍有一个薄弱点：SCCI 只证明主观语义一致性，尚不足以单独解释“为什么场景原生提示值得采用”。正式论文还必须联合报告：

- 协议执行质量和错误类型；
- 可理解性与阶段可辨识性；
- 心智努力或认知负荷；
- 投入感或注意连续性；
- 参与者对目标、实际、累计三层信息的区分；
- 不同呼吸结构的成功与失败映射。

这些结果不必都成为确认性主终点，但必须形成一致的机制证据链。

### 4.2 次贡献：可解释序列编排

| 评价维度 | 当前判断 | 原因 |
|---|---|---|
| HCI问题 | 中强 | 属于生理交互中的上下文适配与智能界面编排 |
| 新颖性 | 中等 | 自适应界面和个体化顺序并不新，约束式、可重放的实现可形成增量 |
| 可证伪性 | 强 | 阶段三可直接比较冻结策略与均衡随机基准 |
| 数据充分性 | 高风险 | 阶段一场景原生组约96个完整结果，对终点奖励的状态—动作估计仍可能不稳定 |
| 论文一致性 | 中等 | 若强调算法，会像第二篇论文；必须服务于同一场景原生框架 |

次贡献判断：`REVISE_REQUIRED`，达到 Gate 3 后可升级为 `PASS`。

它不能写成“找到最佳天气顺序”，因为每名参与者都完成全部四个固定复合模块，且24个完整顺序的单元样本稀疏。正确表述是“**在受约束的短时多模块交互中，状态感知编排是否优于均衡随机编排**”。

不明显增加参与者工作量的必要增强包括：

1. 离线报告移除状态特征、移除转换特征和仅使用前量表的消融结果；
2. 报告动作覆盖率、策略熵、回退比例、概率校准和跨折稳定性；
3. 固定模型复杂度上限，禁止把阶段一稀疏数据包装成高容量个体化模型；
4. 阶段三只比较冻结策略与均衡随机，不增加第三组；
5. 把策略决策日志、概率和理由码作为可解释性证据，而不只报告最终量表差异。

## 5. 单篇论文的统一理论主线

两项工作可用“**生理交互的两个时间尺度**”统一：

- **模块内表示**：如何把目标节律和实时执行嵌入场景自身机制；
- **模块间编排**：如何根据已观察到的交互状态决定下一个复合模块。

统一后的论文问题不是“哪种天气或哪种呼吸更好”，而是：

> **如何在不要求手部操作的生理交互中，同时设计可理解的场景内反馈与可审计的跨模块自适应，并分别验证表示质量和编排增益？**

该主线可以容纳三阶段研究，但摘要和标题仍应首先突出场景原生表示。序列编排放在副标题、第二研究问题和次贡献位置，不能反客为主。

## 6. 投稿前不可妥协的贡献门

| 门禁 | 通过条件 | 失败后处理 |
|---|---|---|
| C1 框架门 | 四层语法、跨结构约束、设计原则和失败模式均有正式定义 | 不能把四个场景并列展示当作框架 |
| C2 对照门 | 两条件在显示、场景、时长、目标、实际反馈量和奖励上完成匹配审计 | 不进行提示载体因果解释 |
| C3 功能门 | Gate 1两个分析集均通过冻结非劣界 | Gate 2降为探索，主贡献不成立 |
| C4 表示增益门 | SCCI通过适用性门且Gate 2优效，并有负荷、理解和定性证据支撑 | 只能报告功能可行，不能声称设计增益 |
| C5 可迁移门 | 至少输出映射选择规则、失败模式和适用边界 | 降级为单一系统评估 |
| C6 编排门 | 冻结策略在全新参与者中通过Gate 3，且审计指标稳定 | 删除次贡献确认性表述，不影响主贡献论文 |
| C7 开放科学门 | 预注册、版本锁、分析代码、数据字典和允许公开的复现材料一致 | 不声称研究可复现 |

## 8. 最终裁定

1. **主贡献能立，但立足点必须是交互表示框架及其严格对照证据，不是项目整体短时变化。**
2. **次贡献目前不能独立立足；它必须通过阶段三外部样本验证，并提供策略审计和低成本消融。**
3. **单篇 IJHCI 可以容纳两者，前提是用模块内表示与模块间编排的双时间尺度统一，保持明确主次。**
4. **当前不需要增加新的参与者组，但必须补强构念、匹配审计、过程证据和可迁移设计原则。**

## 9. 核心依据

- [IJHCI 官方范围](https://www.tandfonline.com/journals/hihc20)：接收交互计算的人因、体验及理论和应用实证研究。
- [ViBreathe, IJHCI](https://doi.org/10.1080/10447318.2021.1898827)：HRV增强的响应式和自适应呼吸引导已经存在。
- [Blum et al., 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6763967/)：虚拟自然环境反馈与标准实现可取得相近反馈表现，并在部分体验结果上产生差异。
- [Respireal, DIS 2025](https://doi.org/10.1145/3715668.3736338)：呼吸驱动虚拟自然对象和人—自然连接已经进入HCI设计研究。
- [Adaptive GUI Customizations, IJHCI](https://doi.org/10.1080/10447318.2026.2623542)：数据驱动、透明、以用户为中心的界面适配需要通过效率、效果和体验进行实证验证。
