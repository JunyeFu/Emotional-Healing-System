# 离线处理总设计

## 目标

离线系统不是“实验后再写几个脚本”，而是项目的正式制品之一。它必须保证：

- 原始数据不可变；
- 所有派生结果可重建；
- 在线与离线算法可比较；
- 人工标注可审计；
- FAS/PPS可重现；
- 图表和论文表格自动生成；
- 负面和异常结果不被隐藏。

## 数据层

```text
L0 Raw
→ L1 Synced + SQI
→ L2 Events + Cycles
→ L3 Module/Session Summary
→ L4 Locked Analysis Dataset
→ L5 Models/Figures/Tables
```

## 主要流水线

1. 验证manifest和校验和；
2. 读取原始呼吸、ECG、事件和问卷；
3. 统一时间轴；
4. 计算SQI与有效窗口；
5. 重新检测呼吸事件；
6. 合并人工标注；
7. 生成周期；
8. 计算protocol_fidelity；
9. 计算ECG过程特征；
10. 量表计分；
11. 生成模块和会话摘要；
12. 构建FAS、PPS和Safety Set；
13. 锁定L4；
14. 运行确认性和次要模型；
15. 生成图表、表格和复现报告。

## 重建原则

- L1–L5都可从L0和代码重建；
- 手工修正作为标注文件，不覆盖L0；
- 每个结果记录输入哈希和代码提交；
- 所有随机过程固定种子；
- 所有排除有原因码。
