# 第2步：构念、比较条件与测量 v1.1

> 当前状态：**F-02候选材料完成，待Level A/B/C证据**

## 目标

把完整提示表示方案转换为不循环论证的构念、测量和反证规则。

## 比较条件

- `scene_native`与`abstract_pacer`保持目标结构、模块时长、真实反馈、累计函数、降级语义、量表和数据处理一致；
- 两条件是完整表示方案差异，不声称只改变单一机制；
- 正式前量化运动能量、平均亮度、视觉复杂度、空间偏心、遮挡和事件显著度，并冻结允许区间。

## Gate 2测量角色

- SCCI只作场景融合操纵检查；
- 条件中性的四层理解得分检验目标、实际、累计和降级信息是否可区分；
- 条件中性的心智努力承担第二个功能底线；
- 阶段错误、注意连续性、喜欢度和舒适度进入一个预设次要家族并控制FDR。

## 量表时序

```text
设备准备与标准化训练
-> PANAS前测
-> 四模块核心体验
-> PANAS后测
-> SCCI、四层理解、心智努力及其他体验问卷
-> 研究目的与条件猜测
```

## 完成门

- SCCI逐题完成两条件认知访谈和项目功能差异检查；
- 四层理解题不出现天气融合措辞；
- 工具筛选规则在查看条件效果前冻结；
- SCCI提高但理解、心智努力或客观阶段错误恶化时，Gate 2必须失败。
