# 四场景实现总规范

## 统一四层

每个场景必须实现：

1. `TargetCue`：目标协议；
2. `ActualFeedback`：真实呼吸；
3. `RecoveryState`：累计恢复；
4. `FallbackState`：信号质量不足。

## 统一接口

```text
SetTargetPhase(phase, progress)
SetActualPhase(phase, progress, quality)
SetRecovery(value)
SetFallback(active, reason)
LockAtClosedLoopEnd()
ResetForSession()
```

## 统一时间线

- 0–15秒：demo；
- 15–105秒：closed_loop；
- 105–120秒：lock_transition。

## 视觉公平

场景原生与抽象条件：

- 使用相同场景、音频和累计恢复；
- 原生条件由场景表达目标/实际；
- 抽象条件由外环/内环表达目标/实际；
- 抽象条件的场景不能泄露周期；
- 原生条件不能额外获得更强奖励。

## 性能

- 稳定目标帧率；
- 所有动态参数可日志化；
- 时间戳可关联Python；
- 场景切换不会造成数据时间轴中断；
- 资源预加载避免转场卡顿。
