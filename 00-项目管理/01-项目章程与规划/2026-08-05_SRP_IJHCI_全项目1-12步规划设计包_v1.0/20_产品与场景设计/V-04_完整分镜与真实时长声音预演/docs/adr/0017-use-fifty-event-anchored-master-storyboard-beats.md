# 使用五十条事件锚定主分镜节拍

V-04主Animatic使用两条全局示意保持和四个天气各十二条事件优先画面节拍，共五十条共享记录。节拍是连续长镜头中的状态快照，不是切镜头；两提示条件只在目标与实际表示覆盖字段中不同。每个天气模板覆盖第一目标周期、第二周期实际淡入、闭环累计的`0.45→0.58→0.51→0.66→0.60`非单调轨迹、结果锁定以及统一转场的`0.30/0.70/1.00`边界。参考秒数只用于定位默认预演，事件触发保持权威；模块可以按全部24种顺序重排，任一天气位于第一位置时由其`M01`记录`FIRST_POSITION_BOUNDARY`。
