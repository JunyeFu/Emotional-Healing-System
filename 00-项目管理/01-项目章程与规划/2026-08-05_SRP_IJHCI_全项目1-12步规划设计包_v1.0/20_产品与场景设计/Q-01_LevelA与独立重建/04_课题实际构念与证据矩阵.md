# Q-01 课题实际构念与证据矩阵 v1.0

> 用途：把十个审查项落到SRP当前权威设计，供专家判断内容完整性，不作为盲态设计者材料。

## 1. 权威顺序

发生冲突时按以下顺序解释Q-01材料：

1. `00_总控/protocol_authority_v1.2.json`：研究问题、条件和结果边界；
2. `R-01_四层候选语法与完整表示方案_v0.9-candidate.md`：四层职责、禁止耦合及两条件表示；
3. `00_参与者产品总规格.md`、`01_四场景实现总规范.md`：800秒旅程、固定镜头与参与方式；
4. `V-04_H3_Unity交接清单_v1.0.md`：当前四场景素材与核心机制交接；
5. `F-02_Gate2构念与测量深度研究包_v0.9-candidate.md`：构念和测量边界。

`01-需求与设计/情绪天气方案/四种天气设计.md`保留历史设计过程，但包含早期滚动方式和旧节律，不作为Q-01当前审查依据。

## 2. 本课题主张边界

阶段一比较`scene_native`与`abstract_pacer`两种完整提示表示方案在短时负性情绪调节中的收益、代价与适用边界。Q-01只检验候选四层语法是否内容完整、职责清楚并可迁移；不回答哪一条件更好，不回答单一天气或单一机制的独立作用。

## 3. 四层在两条件中的同源关系

| 层 | 权威输入 | 场景原生表示 | 抽象控件式表示 | 质量不足时 |
|---|---|---|---|---|
| Target | Python目标协议、当前阶段、下一转换 | 远景或引导性场景对象 | 外环 | 继续按协议运行 |
| Actual | 当前交互状态估计、进度、置信程度 | 近景或局部响应对象 | 内环 | 减弱或停止，不补零 |
| Cumulative | 模块内慢变量摘要 | 场景整体的缓慢恢复或稳定 | 与条件共享的场景慢变量 | 冻结，不继续累计 |
| Fallback | 输入可用性和显示策略 | 局部响应淡出或间断 | 内环淡出或停止 | 非评价地显示受限状态 |

两条件使用同一事件真值、时长、累计规则和降级规则。差异仅在提示如何被表示，不能额外增加奖励、信息量、镜头变化或教学时间。

## 4. 四场景实例

| 场景 | Target | Actual | Cumulative | Fallback |
|---|---|---|---|---|
| storm_field | 远景云层与雨带给出3-3-3-3节律 | 近景草木、衣物和局部雨线响应当前估计 | 地平线可见度与积水扰动缓慢改善 | 近景响应淡出并出现稀疏间断，远景目标保持 |
| thermal_flow | 热流和阴影给出4-6延长呼气节律 | 近景尘粒、布料和局部热流响应当前估计 | 阴影、地表冷却和远景稳定缓慢变化 | 局部热流减弱或间断，目标保持 |
| snow_drift | 远景雪道给出5-5等时节律 | 近景雪带、围巾和粒子响应当前估计 | 路径可见度、积雪稳定与远景轮廓缓慢变化 | 近景响应淡出或中断，目标保持 |
| chromatic_return | 色潮给出双吸与长呼的目标波次 | 局部纹理、轮廓和颜色响应当前估计 | 全局纹理、饱和度和轮廓缓慢恢复 | 实际色潮淡出并以点状不确定性表示受限，目标保持 |

四场景均为固定镜头，不使用横向滚动或视差推进。上述实例帮助专家判断课题适配，不提供给独立设计者。

## 5. 十项审查证据

| ID | 本课题证据 | 专家重点判断 |
|---|---|---|
| E01 | Python目标协议与Target独立 | 是否足以防止观测结果改写目标 |
| E02 | Actual只接收当前估计与置信程度 | 是否明确禁止模拟值、补零和复制Target |
| E03 | Cumulative为模块内慢变量 | 是否明确冻结条件及其与瞬时相位的区别 |
| E04 | Fallback只说明信息可用性 | 是否避免个人评价并保持Target连续 |
| E05 | 四层来源表 | 是否能逐项追溯到唯一权威输入 |
| E06 | 快速Target/Actual、慢速Cumulative、及时Fallback | 时间尺度是否足以区分职责 |
| E07 | 任意两层至少两个视觉维度可分 | 是否排除颜色唯一编码 |
| E08 | 两条件同源事件与同等信息量 | 是否形成公平比较而非额外功能比较 |
| E09 | 完整方案比较与候选四层知识 | 是否阻止单机制、单天气和胜负预设 |
| E10 | 专家包与盲态包分离 | 是否足以阻止设计者看到现有答案 |

## 6. 专家输出要求

专家应对每个ID分别给出相关性、完整性、表达清晰度和构念纯度评分，并在开放意见中指出具体误解路径。审查对象是材料能否约束设计，不是画面偏好或最终结果。
