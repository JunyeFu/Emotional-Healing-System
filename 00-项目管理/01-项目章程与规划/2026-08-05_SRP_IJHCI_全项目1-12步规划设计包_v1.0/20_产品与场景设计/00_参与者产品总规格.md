# 参与者产品总规格

## 产品目标

构建一套桌面端、无手部操作、推荐13分20秒核心流程、真实呼吸数据闭环的交互体验。参与者不进行选择或控制器操作，只跟随场景原生提示。

## 体验流程

```text
研究人员启动和设备检查
→ 参与者自然呼吸基线
→ 标准化训练
→ 四个推荐200秒模块
→ 自动结束
```

## 产品模式

| 模式 | 用途 |
|---|---|
| `development_mock` | 动画开发、故障注入；永久标记Mock |
| `pilot_scene_native` | Level B/C场景原生条件 |
| `pilot_abstract` | Level B/C抽象对照 |
| `formal_scene_native` | 正式场景原生 |
| `formal_abstract` | 正式抽象对照 |
| `demo_exhibition` | 展览演示，不产生正式数据 |

## 参与者界面原则

- 不出现实验员技术信息；
- 不出现中央统一呼吸圈（抽象对照除外）；
- 无高频闪烁；
- 目标、实际、累计、降级可感知但不过度堆叠；
- 失败或低质量不羞辱参与者；
- 不强制显示完全恢复；
- 不使用个体干预或个体健康判断语言。

## 构建完成门

- 推荐13分20秒自动流程，模块采用25秒示范、150秒闭环、25秒锁定转场；
- 四场景加载稳定；
- 两条件只改变提示载体；
- 真实设备断流可安全降级；
- 日志完整；
- Unity脱离TD；
- 同一构建可根据manifest加载条件。
- TD未启动时Unity仍可完成完整体验。
