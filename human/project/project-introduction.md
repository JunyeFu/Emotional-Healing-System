# SRP项目介绍

## 一句话介绍

SRP把呼吸练习融入天气场景，通过可穿戴输入与视听反馈探索更自然的情绪调节教育体验。

## 面向谁，研究什么

面向普通学习间隙愿意进行短时练习的人。相比固定呼吸引导圈，场景原生的受限适应能否改善体验与情绪收益，同时保持可理解、可执行的练习过程？这是项目要检验的问题，而不是已有结论。

## 体验与机制

四种天气各采用一个核心视觉机制。当前成员演示以溪边木屋、雨幕与波纹呈现Storm，以屏幕空间粒子双环呈现呼吸节奏。Python负责会话编排和记录，Unity负责画面，TouchDesigner负责操作台与监控。
