# SRP 当前项目概览

SRP面向普通学习间隙的自愿呼吸练习，将身体节奏反馈融入天气场景，探索情绪调节教育中的体验、执行表现和调整成本。

[成果展示](../deliverables/README.md) · [对外介绍](project-introduction.md) · [开发上手](../developers/README.md) · [任务导航](../tasks/README.md)

比较固定呼吸引导圈与预设场景变化（A），和数据驱动的场景原生自适应完整方案（B）。两组共享理想目标I；只有B根据实际呼吸X与场景状态受限调整实际引导G，再趋向I。[设计地基重构包](https://github.com/JunyeFu/Emotional-Healing-System/blob/f2fefece8e55c10c93c737a8b69bbeaa37a65be9/agent/design/design-foundation-20261008/README.md)含设计主稿、科学依据、决策影响与先行推理；[一体化设计规范](https://github.com/JunyeFu/Emotional-Healing-System/blob/f2fefece8e55c10c93c737a8b69bbeaa37a65be9/agent/design/项目质量与一体化交付规范.md)约束后续共同消费。

5人、半个月、100+仅作后续可行性分析。保留基线校正PANAS负性情绪后测为主终点候选，独立报告相对共同I的执行、跟随G的表现与调整成本；正式测量和规模仍待冻结。任务状态、签收及领取快照不变，比赛未定。

当前任务体系已按新基线覆盖71包：[迁移范围与验收](https://github.com/JunyeFu/Emotional-Healing-System/blob/f2fefece8e55c10c93c737a8b69bbeaa37a65be9/agent/work/2026-10-08_新基线任务包迁移.md)。旧业务状态/签收保持，新增运行与研究须真实取证。
