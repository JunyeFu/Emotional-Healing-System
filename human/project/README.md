# SRP 当前项目概览

本项目比较场景原生与抽象控件式呼吸提示的情绪收益、功能代价与适用边界，不预定哪一种方案获胜。阶段一支撑单篇IJHCI主论文，可选阶段三须独立具备支持、资源及真实准入条件。

## 当前入口

- [四场景最终画面描述](../../agent/design/情绪天气方案/四种天气设计.md)：选定底图、近中远景、呼吸机制、天气慢变化与双条件组织。

- [模块职责与交接](PROJECT_MODULES.md)：M00至M10及实际接口。
- [逐包审阅](../README.md)与[项目串联审阅](../project-review.docx)：71项任务的交付、验证和缺口。
- [Agent执行层](../../agent/README.md)：任务权威、输入、实现、证据和当前输出。
- [当前运行入口](../../agent/runtime/README.md)：Python、Unity与TD职责及正式运行缺口。
- [根目录迁移](../../agent/root-migration.md)：实际归属与未完成项，整理不等于业务完成。

Python掌握流程、时钟和记录；Unity独立完成参与者体验，TD承担操作台、监控及后续数据消费。四天气采用固定镜头，真实设备采集和参与者研究验收分别由对应任务交付。

业务状态以任务注册表为准，不能从整理数量推定完成。当前正式研究批准、真实系统全链、冻结参数和参与者结果仍有缺口；原已签收的软件底座保留原验收范围。
