# TD 工作台页面设计

打开 [逐页预览](index.html)，或在 diagrams.net 中打开 [十二页可编辑画布](t01-workbench-redesign-final.drawio)。PNG由同一绘图软件导出，附带绘图副本，不是AI生成图片。

画布按1280×720设计。部分PNG的图形边界带半像素描边，实际导出为1281×721，未做放大或裁切。

## 页面

| 页 | 内容 |
|---|---|
| 01 | 主页：系统就绪、设备可用、场次概况与准备入口 |
| 02 | 实验准备：双设备曲线预览、准备清单、缺项与禁用按钮 |
| 03 | 等待开始：Unity开始与Python启动确认分开，预览不计入实验记录 |
| 04 | 实验运行：独立记录状态、时间、设备、天气进度与I/G/X对照 |
| 05 | 暂停：有效计时冻结，采集记录保持连续 |
| 06 | 收尾待办：体验已结束，但封存与后测尚未齐全 |
| 07 | 历史选中：突出所查看的匿名编号、开始时间及导出对象 |
| 08 | 分组明细：先设备与质量，再记录与链路，原协议另行展开 |
| 09 | 收尾完成：封存及后测已确认，可以准备下一位 |
| 10 | 历史未选择：无选中场次时，导出按钮不可用 |
| 11 | 断流与记录故障：保留末次曲线、标记缺失区间，呼吸估计不可判定 |
| 12 | 中止确认：明确当前对象及结束后果，底层操作区被遮挡 |

## 阅读说明

保留A浅色主题和单窗口阶段切换。设备区域用标题带区分，标签左对齐，数值右对齐；运行页不保留已经通过的准备清单。呼吸使用蓝色，心电使用绿色，质量和异常另有文字标识。

六条曲线切换入口保留：呼吸、加速度、角速度、心电、RR间期、心率。本版默认画出呼吸与心电，其他四种曲线的专用展开图不在本版交付范围。

页面中的编号、波形、服务就绪、质量、置信度与时长均为合成设计示例，不代表当前专机或真实设备情况。固定呼吸量程只用于本稿示例，不作为实际设备校准范围；I/G步骤进度与X呼吸估计不能互相代填。

本版完成的是页面设计、绘图软件内审查与局部修订。按钮和状态尚未据此改写为TD运行实现。正式接线仍须分别消费Python编排、记录服务与设备的真实输入。
