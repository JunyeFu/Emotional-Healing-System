## 当前体验定义

每个模块推荐200秒：25秒原生示范、150秒闭环、25秒锁定和转场；四个模块共800秒。四种呼吸步骤以已冻结配置为准。两种完整提示条件为`scene_native`和`abstract_pacer`，目标、实际、累计与降级必须分开；实际缺失不能借用目标补齐。阶段一完整顺序预先均衡分配，体验中数据不改变该顺序。

Unity必须在TD缺席时提供完整体验，但正式模式仍依赖Python的manifest、时钟、控制和记录链。开发fixture只用于开发与故障验证，真实输入中断不能切换为模拟输入。
