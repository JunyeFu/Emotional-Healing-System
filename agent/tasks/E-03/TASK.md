# E-03【研究关闭】Level C汇总门与阈值冻结

注册BLOCKED_EXTERNAL，依赖Q-03|E-02|B-01，约5人日；领取人、分支及审核人为空。规范化不会生成真人结果或DONE。

## 目标与明确验收

汇总全部真实Level C批次、盲态技术测量和偏离，输出精确候选的技术关闭报告与配置，供A-03-CAL/U12-11/G-03消费。

- AC1全部真实B-01实例有完整QC；人数、分配与完成/退出分别说明，48人/每条件24锚点的实际覆盖或不足有真实处置，不能用预览或补造记录凑齐。
- AC2全部必需技术门有阈值来源、适用结构、分母、实测结果及判断；证据缺失为未评估，明确失败为NO_GO，不随两条件情绪效果方向调参。
- AC3报告、配置、算法/规则、测量与运行构建的身份一致，真实另一人审核精确对象；技术关闭不代替正式统计冻结、预注册或活动许可。

## 五段执行

1. 接收与范围：真实负责人收齐批次索引、批准范围、人员、材料/软件版本及停止/修订；核对B-01采集与E-03汇总都在Level C范围。
2. 原件与人数：只读验证P-02及六类证据，核对全部批次和每条件/天气覆盖、退出、未执行与缺失；保留原始数据，不根据完成者定向补人。
3. 盲态技术汇总：两独立标注者和第三裁定保留原标签/分歧；按结构、步骤和质量区间汇总检测、机会、边界、时钟、外部延迟、量表适用性和运行失败。
4. 候选关闭：逐项记录实际证据与阈值来源，必要修订须新版本/独立验证；证据未齐不写通过，明确技术失败输出NO_GO及责任人。形成精确报告和技术配置候选，不生成正式研究冻结回执。
5. 下游和签收：另一人审阅或复跑真实材料，记录范围；E-03交盲态材料给A-03-CAL，再由U12-11/G-03冻结研究数值，避免要求E-03先等待CAL。

Level C关闭负责人负责批次完整和决策；Q-03工具负责人供盲态QC；数据负责人验证原件；两标注者/第三裁定者负责Actual；S/I负责人负责事件及外部时钟/显示测量；测量/统计负责人解释SCCI和计分适用性，A-03校准者消费盲态参数；真实复核人审精确候选。目前待实名，Agent仅执行当前规范化核查。
