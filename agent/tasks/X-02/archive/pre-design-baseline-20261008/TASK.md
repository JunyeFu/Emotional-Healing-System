# X-02【策略实现】参与者分组策略学习OPE支持与重放

注册WAIT_DEP、未领取，约5人日，依赖整个A-03而非仅SPEC。当前只完成任务结构、输入要求和方法交接；没有训练器、OPE、ESS、图表、策略模型或签署。

## 验收和职责

- AC1：外层评价、内层调参、缩放、bootstrap和区间均按参与者分组，不能拆同人决策行。
- AC2：合法动作目标概率为正，按位置/候选历史报告行为支持、OPE与ESS，明确估计目标及可识别范围。
- AC3：价值不稳定、支持不足或状态低质量时用冻结均匀/更简策略；相同输入、候选排序、配置、模型和种子逐决策重放一致。
- 心电只作离线解释，不进正式策略。工具完成不等于E-05策略冻结或X-03部署通过；核心论文不等待可选扩展DONE。

## 五天过程

1. 输入对齐：A-01原件/L3、A-03测量与阶段一锁定资料，逐字段区分决策前状态、末测结果、行为概率来源和缺失。领取后指定实现负责人、统计复核人及集成人。
2. 分组训练：先实现参与者不交叉的嵌套折与折内缩放，逆向有限时域岭Q；超参数、方向和缺失处理由预设方法裁定，不从最终评价折调参。
3. 离线评价：明确价值/基准、行为支持、权重和ESS，执行参与者重采样区间及模型核查；不把决策行当样本量，不用样本均值最高顺序证明最优。
4. 回退和消融：比较均匀基准、有限预设特征消融、校准、熵、跨折稳定性；扩展选择标准须在核心揭盲前冻结，E-05核验来源并签署最终模型，当前null不补成fixture常数。
5. 重放交接：交训练产物、OPE/ESS/消融和逐决策重放证据，经独立复核与真实签收后转状态。X-03接收只读冻结策略，不在线学习。
