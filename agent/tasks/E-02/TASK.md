# E-02【研究执行】Level B认知预试执行与关闭

注册BLOCKED_EXTERNAL，依赖Q-02|E-01|U12-05，约5人日项目内工作；负责人、分支及审核人均未落实。本轮规范化与合成核查不作为真人活动或签收。

## 目标与明确验收

在实际获批范围内执行两条件认知预试，保留真实独立作答、误解、帮助、缺失与修订前后证据，向Level C交可用候选。AC1按实际冻结的人数/每条件/每轮计划完成目标及两条件四结构覆盖，不将空表或代码题库当真人覆盖；AC2关键误解逐项编码、双人分歧裁定并完成修订或有据保留，剩余关键项不得写已关闭；AC3关闭候选的实际Unity回归、片段/构建身份和真实审核签署对应一致。

注册交付写12至16人，历史F-02写每条件12至16人，当前研究未冻结人数。详见outputs/current-execution.md；三项不能任选其一冒充已批准方案。理解和需求特征不作为隐去有效PANAS比较的报告门。

## 五段过程

1. 范围与材料：真实负责人核对E-01真实关闭、Q-02材料可用、U12-05及相应活动资格；冻结人数、时序、材料、种子/片段和构建，落实执行及编码责任人。
2. 排练与招募：工作人员流程演练单列，取得实际批准和去重资格后招募；每人一条件、一次核心体验，新修订轮用新人。
3. 执行与记录：完整路径先前测再揭示和教学，800秒核心只平坐观看；后测后独立作答，再认知追问与目的猜测，最后说明。形成性教学检查单独标记。
4. 编码与修订：两编码者独立保留原话来源和分歧，问题关联题目、条件、结构、版本、严重度；Q-02/Unity负责人实施成对修订，不静默改变呼吸结构、主要结果或条件本质。
5. 复测与关闭：新参与者/新版本真实复测，实际Unity回归及完整表示检查；提交精确关闭候选给另一人审核，剩余条件和下游可用性写清，不自动解锁Level C。
