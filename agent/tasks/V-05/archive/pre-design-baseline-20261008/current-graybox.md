## 旅程及时间

当前实施要求：灰盒接收成员Storm和粒子双环，2022运行全旅程；区分本地预设与Python时钟、独立Actual接线，保存场景测试面板关闭。采用[统一实现标准](../../../design/情绪天气方案/2026-10-08_Storm与纯粒子双环实施标准.md)，截图与核查边界见[本包画面证据](current-implementation-evidence.md)。

完整节点从V-01的current-experience.json读取，不再仅依赖旧签收。中性准备 → PANAS前测 → 有共同预算的分条件教学 → 中性入口 → 四模块核心 → 中性结束 → PANAS后测 → 理解/操纵/努力等问卷 → 数据检查。核心里每模块demo、closed_loop、lock_transition各一次；J-05揭示和J-09转场是段内边界，不再额外加时。

核心推荐25/150/25秒×4=800秒，允许区间沿用V-01同版配置，两条件匹配。教学候选180秒但未正式冻结，不算入800秒；前后测外置且Unity不读取答案。参与者不操作核心界面，不等于禁止前后测填写。Python控制流程与单调时钟，Unity只镜像和呈现，TD缺席不阻止Unity体验。

首个分条件教学前必须完成暴露登记；当前P-01核心start登记不能覆盖此边界。教学运行接入由P-01/U12-06/X-01及U12-11冻结后完成。本包可做明确DEV-REPLAY的占位，但不能以占位登记替代正式接入。

## 画面及双条件

四天气固定镜头，遵循V-02/V-03/V-04已选设计；不再走旧横向卷轴或拆背景层路线。旧32个独立素材是历史美术来源，Storm当前改消费成员木屋及实际效果资产，灰盒先用色块和占位声音，不把素材导入等同最终许可通过。

目标、Actual、累计、降级信息使用同源v2.2 fixture。storm两次停顿、fade两次吸气必须保留不同step_id；Actual未知为空，不复制目标。累计在同模块换段时保持，下一模块/会话边界才重置，lock_transition不继续伪装实时成功。

fade整屏复色只随模块有效时间；水系呼吸提示随其呼吸步骤，累计轮廓/纹理独立。两条件背景、声量预算、目标时间及输入算法一致，原生不等于隐藏，也不把预演HUD作为参与者标识。
