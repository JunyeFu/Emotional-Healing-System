## 数据、QC和停止

使用同一个RecordingSessionCore供运行主机/控制服务消费，先耐久记录再发送控制；RecordingTelemetryPublisher先记录再发送遥测。每场只读校验P-02完整封存，异常保留全部原字节和原因码；中断恢复只作数据恢复，不作完成会话。双设备来源、算法/呼吸配置、构建与正式mode按同一冻结版本一致。

六类证据为device_streams、runtime_facts、questionnaires、allocations、annotations、configuration_build。RawEvidenceBundle的restricted_ref只检查声明，不能证明已经获准读取/实际核查；数据/QC负责人在授权环境核验真实原件。未知值null加原因，不能填零、mock或用Target替代Actual。必要标注、时钟质量和外部显示测量缺失单列，不将ACK/渲染回执当外部延迟测量。

分配、暴露、核心完成、暴露后停止、暴露前取消及待处理分别统计，同时报告PANAS前后缺失与各模块设备可评估性。操作记录的完成状态不是完整分析集；真实失败但信号可用的周期仍为不符合，不因表现差/情绪未改善排除。传感器失败不删有效PANAS，PF/SCCI失败不隐藏预设情绪比较。

批次QC不查看条件情绪效果来补人或删数据；停止使用预注册随机分配目标或事前盲态规则，不按p值、原生获胜方向或完成者24格补人。存储/来源/版本/正式入口失败按冻结现场路径停止，尽力中止及恢复数据，不静默补值。未完成标注的批次保持QC待补，不构成E-04锁库授权。
