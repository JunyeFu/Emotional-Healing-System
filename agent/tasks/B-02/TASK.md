# B-02【正式批次】阶段一会话批次模板

注册TEMPLATE/BLOCKED_EXTERNAL，依赖G-03，每实例最多12人、约5人日。没有真实实例，未领取未签收；本包规范化不生成正式manifest或招募许可。

## 目标与验收

按同一真实批准及预注册版本执行阶段一批次，保留全部分配、暴露、完成/退出、原始数据、问卷、偏离和QC，供E-04锁库、A-01重建与A-05锁定分析。

- AC1每次分配只取X-01已锁定清单，版本、分层、索引、条件及四天气顺序一致，不按PANAS后测或完成者情况改配。G-03正式回执及运行接线未关闭不实例化。
- AC2每人只一个阶段、一个提示条件、一次核心体验，使用真实设备和正确构建。首次条件教学暴露也登记，退出/中断不能用新session_id恢复资格或重做体验。
- AC3每批结束立即核查记录完整、原件身份、覆盖、偏离、备份、分配和剩余平衡；未标注/缺原件为待补，不假PASS。按冻结随机化N和停止规则推进，不为完成者缺格定向补人。

## 五段执行及责任

1. 真实批次负责人接收G-03同版本冻结及机构回执，安排现场操作者、数据/QC和复核人；核对设备、构建、运行准入、场地、数据权限及中止路径。
2. 清单保管者/揭示者按X-01职责分离和真实账号权限准备，只在前测完成及适用资格通过后揭示；记录真实事件，不把调用方role字符串当系统授权。
3. 现场人员按冻结时序完成中性准备、前测、揭示、等预算条件教学、四模块体验、先PANAS后测再其他体验测量。核心内参与者不操作；后测不作为在线输入。
4. 数据/QC人员先校验P-02封存链与六类原件，再记录实际分配/暴露/完成/退出、原因码与技术覆盖。尚缺标注时保持QC待补；按盲态规则复核，不查看两条件效果来筛选。
5. 批次负责人和另一人复核精确实例及偏离，交E-04全部实例/记录索引和冻结规则；受限原件在获批仓库外，变更另记录真实修订，不覆盖原始分配或回执。

真实角色目前待实名。每实例只留一名闭环负责人，操作者、清单保管/揭示、数据、标注/裁定、现场停止决策和复核职责明确；Agent本轮不执行真人活动或代签。
