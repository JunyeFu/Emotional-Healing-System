# 正反结果解释规则

这是作者决策规则，不是生成式论文正文或可直接投稿句式。所有结果目前NOT_RUN；真实作者写作必须结合锁定估计、CI、预设计划和实际范围。U12-10消费本规则后仍需真实分类，不从模板推断结果。

| 观测情形 | 可支持解释 | 不可改写为 |
|---|---|---|
| 有效主要比较CI全负且符合事前检验 | 所测原生完整方案较抽象方案PANAS负性情绪结果更低；是否有实际意义另看事前标准 | 全部原生表示优于全部显式表示；无项目对照的整项目因果效果 |
| 有效主要比较CI全正且符合事前检验 | 所测抽象完整方案优于原生完整方案，可作为主发现 | 原生未赢所以抽象赢；全部显式表示必然更好 |
| CI跨零或预设检验不支持方向 | 估计与不确定性、证据不足以支持相应方向 | 两方案等效；没有效果；抽象优势 |
| 确认性等效默认未启用 | 报告差异估计与CI；不作确认性等效主张 | 事后补界值获得等效 |
| 事前等效已另行冻结且实际检验支持 | 限于所冻结界值和方法的实际等效，披露分析范围与计划 | 任意指标/时长/参与者都等效 |
| 情绪优势但PF任一分析集失败 | 保留有效情绪结果，同时报告执行代价；不支持原生功能替代 | PF失败所以隐藏有效PANAS比较 |
| PF两集通过、情绪证据不足 | 有限的功能替代证据和不确定情绪差异 | 功能非劣证明情绪非劣或优效 |
| SCCI未支持预期 | 操纵分离证据不足，限定机制归因，报告预设有效结果 | 随机化比较自动无效或不许发表 |
| 理解/负担不利或关键错误增加 | 完整披露代价和具体任务边界 | 仅靠偏好/舒适提升证明收益抵消代价 |
| 总PF尚可但单模块关键错误严重 | 报告模块负例，按冻结规则限定整体替代 | 平均非劣证明所有模块安全有效 |
| 信号缺失但PANAS有效 | 分别报告信号缺失与情绪结果，按预设分析处理 | 将有效情绪记录一并丢弃或填零补传感器 |
| 情绪缺失/退出或只剩完成者 | 报告全分配流、缺失假设和敏感性；完成者分析不独占 | 只报完成者优势作全体结论 |
| 构建/教学/输入不公平或处理失效 | 逐项说明失效影响的估计/主张，披露全部事实和可解释结果 | 假称已通过公平性；所有预设结果自动删除 |
| 独立重建失败或没有实际重建 | 限于四场景实现与已观察负例，补明确迁移成本 | 宣称已形成通用设计框架 |
| 文献重叠或全文证据不足 | 定位为可识别的比较/边界贡献，补真实全文核查 | DOI存在即新颖性成立 |
| 无独立机制操纵 | 比较两个完整方案，天气/呼吸结构为绑定背景 | 拆出独立天气、呼吸法、显式性或单机制因果效应 |
| 扩展未启动 | 核心范围如实关闭，不等待阶段三 | 伪造阶段三DONE或结果 |
| 扩展已启动但失败/停止/仅部分运行 | 披露实际活动、预设可解释结果与限制 | Gate失败后把实际研究藏成未来工作 |
| 策略支持域不足/仅均匀回退 | 不支持策略优效，报告支持范围与实际部署比较 | 将实际序列的观察排名称为因果最优顺序 |

所有结论先限定本研究参与者、流程长度、设备/构建和完整方案。情绪比较、功能代价、过程解释、设计知识分开，不把软件完成或样片签收写作实证发现。后测不参与在线决策，分析只读不发送控制、揭示分配或再次登记暴露。
