# 正反结果解释规则

这是作者决策规则，不是生成式论文正文或可直接投稿句式。所有结果目前NOT_RUN；真实作者写作必须结合锁定估计、CI、预设计划和实际范围。U12-10消费本规则后仍需真实分类，不从模板推断结果。

| 观测情形 | 可支持解释 | 不可改写为 |
|---|---|---|
| 有效B-A主要比较CI全负且符合事前检验 | 所测原生受限适应B较固定开环A的NA较低；实际意义另看事前标准 | 单独自适应机制有效、全部原生优于全部显式、无休息对照的绝对收益 |
| 有效B-A主要比较CI全正且符合事前检验 | 所测固定开环A的NA较低，可以如实作为反向发现 | 从B未显著推A更优；全部显式表示必然更好 |
| CI跨零或预设检验不支持方向 | 估计与不确定性、证据不足以支持相应方向 | 两方案等效；没有效果；抽象优势 |
| 确认性等效默认未启用 | 报告差异估计与CI；不作确认性等效主张 | 事后补界值获得等效 |
| 事前等效已另行冻结且实际检验支持 | 限于所冻结界值和方法的实际等效，披露分析范围与计划 | 任意指标/时长/参与者都等效 |
| 情绪优势但I达成/G跟随/成本不利 | 保留有效情绪结果，分别报告目标达成、跟随与执行代价 | 用旧PF任一分析集失败隐藏有效PANAS比较 |
| G跟随较好但偏离共同I | 区分跟随有效提示与接近共同任务目标，不自动支持替代 | 将跟G好改写成训练更好或功能非劣 |

| 理解/负担不利或关键错误增加 | 完整披露代价和具体任务边界 | 仅靠偏好/舒适提升证明收益抵消代价 |

| 情绪缺失/退出或只剩完成者 | 报告全分配流、缺失假设和敏感性；完成者分析不独占 | 只报完成者优势作全体结论 |
| 构建/教学/输入不公平或处理失效 | 逐项说明失效影响的估计/主张，披露全部事实和可解释结果 | 假称已通过公平性；所有预设结果自动删除 |
| 独立重建失败或没有实际重建 | 限于四场景实现与已观察负例，补明确迁移成本 | 宣称已形成通用设计框架 |
| 文献重叠或全文证据不足 | 定位为可识别的比较/边界贡献，补真实全文核查 | DOI存在即新颖性成立 |
| 无独立机制操纵 | 比较两个完整方案，天气/呼吸结构为绑定背景 | 拆出独立天气、呼吸法、显式性或单机制因果效应 |
| 扩展未启动 | 核心范围如实关闭，不等待阶段三 | 伪造阶段三DONE或结果 |
