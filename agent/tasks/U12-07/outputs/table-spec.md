# 当前空表字段规格

本文件没有观测数据。每表保留结果状态、输入位置、分析代码及版本、样本/分析集、缺失原因和图表引用；空结果写NOT_RUN或null，不使用假数字、零值或破折号冒充观测。真实零值只有来自真实记录时才保留。发布时由作者填同一锁定版本，不把规格称为研究表格成品。

| 表ID | 目的 | 必需字段 | 消费者及来源 |
|---|---|---|---|
| T01 | 分配与样本流 | 筛选/资格/分配/教学暴露/核心启动/退出/完成/分析纳入，各条件人数及原因；分配序列与完成序列分开 | X-01、E-04、A-05；不按完成补填 |
| T02 | 实现与条件公平性 | 同构建、输入和目标、四层规则、教学预算和时序、实际显式性、视觉/音频差异、降级偏离 | U/V、I-01、U12-03；开发和真实取证分开 |
| T03 | PANAS主要比较 | 各组前/后分布、独立N与缺失、四顺序校正B_minus_A、HC3、95%CI、双侧p、原分配集、PMM/Rubin与偏离 | estimates.csv、analysis.json；独立于功能/SCCI报告 |
| T04 | I达成、G跟随与成本 | 固定T及C/K/U、上下界、覆盖、连续时长误差、适应/暂停/帮助/退出、逐模块与固定四模块汇总 | participant_modules.csv、events.csv；不沿用旧PF非劣门，不重加权缺模块 |
| T05 | SCCI操纵检查 | 量表版本、项目及汇总、N/缺失、效应和CI、解释限制 | F-02/U12-02；不屏蔽预设情绪结果 |
| T06 | 步骤理解与信息代价 | 步骤实例/题号/锁定答案版本、实际/累计/降级维度、错误类型、得分算法、每组N和CI | U12-02真实材料；八题数量不自动规定旧0–8计分 |
| T07 | 努力负担与次要结果 | 冻结量表、注意/负担/偏好/舒适/可访问指标、N/缺失、CI、预设多重比较、探索标记 | A-05、Q/E；偏好不等于执行或情绪优势 |
| T08 | 独立重建与设计边界 | 任务/输入、重建者、错误与修正、可复现/失败、成本、证据位置及适用范围 | Q-01/E-01；无真实重建不填可迁移结论 |
| T09 | 缺失与敏感性 | 情绪/信号缺失分开、退出、PMM k=5/50次/20轮、Rubin/HC3及小样本df、完全案例与分组delta、假设变化 | missingness_sensitivity.csv、imputations/；软件演练不是正式冻结 |
| T10 | 主张证据关系 | 主张、方向/不确定性、结果行与图、原件、代码、锁定身份、允许及不允许解释 | W-02、U12-10；不由空表输出发现 |
| T11 | 可选扩展实际范围 | 未启动/已启动/停止/部分运行、分配/暴露事实、冻结策略及支持域、两原生组结果/偏离 | A-04/A-06；未实施可注明不适用，实际部分运行不得隐藏 |

建议阅读顺序为样本和实现、PANAS主比较、独立功能/过程结果、敏感性及设计边界；不是强制功能门序。对应PNG/PDF图01至06由唯一分析入口生成；专家重建、正式公平性及扩展没有真实材料时保留NOT_RUN，不假称全部11张研究表已完成。

确认性等效表默认不生成。仅有事前冻结界值、方法、alpha和多主张计划且实际执行时，才由真实结果补等效表。旧192/240和0.075等候选不得填写为最终批准数值。
