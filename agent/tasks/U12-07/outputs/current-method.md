# 结果前中立方法规格

## 当前用途

当前修订候选，非论文正文、非预注册、非真实研究结果。历史DONE只代表原三件套验收。以下字段供真实作者组织方法；实际版本、人数、批准和结果须从冻结证据填写，不从模板推定。

## 主问题与比较对象

RQ1：两个完整呼吸提示表示方案在本研究参与者和短时流程下，基线校正的PANAS负性情绪结果有何差异？不保证原生胜出。

RQ2：两方案的机会PF、步骤理解、努力负担和关键错误呈现什么收益与代价？这些结果独立报告，用于功能和解释边界，不作情绪结果发表的前置门。

RQ3：相同输入下，目标、实际、累计恢复与降级的表示关系有哪些可复现的设计规则、错误类型和适用边界？真实独立重建与负例支撑规则，四个实现本身不证明普适框架。

可选扩展另比较两原生组的冻结策略部署与均衡随机；不是阶段一原生—抽象比较，也不是天气或呼吸法的独立效果。

## 设计与时序

阶段一为参与者间两个完整方案比较。一人一个阶段、一个条件、一次核心体验；按X-01分配而非完成数均衡24排列，禁止按结果停止或按完成补填。资格、招募、隐藏和停止规则由实际研究冻结记录提供。

中性说明 → PANAS前测 → 等预算分条件教学 → 四模块核心体验 → PANAS后测 → SCCI及步骤理解/负担测量。分条件教学纳入处理方案；前测必须在其之前。U12-03当前180秒为候选，不写成已批准预算；核心推荐800秒，实际段时与偏离从运行事实读取。参与者不操作核心界面。

四天气固定镜头，分别绑定呼吸结构，因此不能识别天气与呼吸结构的独立效应。原生不是隐藏，显式性未单独操纵。两条件共享目标结构、真实输入、恢复和降级规则；实际公平性、可访问性和真实理解由U/V及Q/E证据支持。

Python是流程和时钟权威，Unity独立于TD完成体验，TD只读监控及审计请求。研究1.2与运行合同2.2分别标识；真实设备、真实回执、耐久记录和正式入口接线要有实际证据，合成fixture只证明开发行为。

## 测量与估计

主要结果`panas_negative_affect_post_adjusted_for_pre`；对比`native_minus_abstract`，低为好、负值偏向原生、正值偏向抽象。候选双侧alpha0.05和95%CI；模型与HC3执行规格消费U12-04当前SAP及A-03接口，不引用旧人数/旧门序作权威。不把教学后的协变量塞入主要基线模型。

机会PF按S-02/A-02定义，以参与者而非遥测帧为推断单位；`all_randomized`和`complete_four_module`均需满足已冻结非劣条件才支持原生功能替代。完整四模块资格不等于四个完成事件，应依研究规则及质量/机会记录核验。0.075只为待论证候选；平均非劣不证明每天气非劣。

SCCI只作操纵检查；理解使用U12-02当前步骤实例、实际/累计/降级题与锁定答案，不复用旧粗相位八题0–8分描述。真实标注、构念有效性及双条件片段等效仍未完成。努力负担、错误、偏好和可访问结果依冻结量表和多重比较计划报告。

传感器缺失、情绪缺失、未分配/未暴露/退出分别记录。有效PANAS不因传感器缺失而丢弃；无机会、无有效信号不能填零。MI100是候选而非已实现或已冻结处理，正式模型/MNAR和分析集消费U12-04/A-02；不只报告完成者。
