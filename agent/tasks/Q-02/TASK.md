# Q-02【研究工具】Level B两条件认知可访问性与需求特征预试

注册状态WAIT_DEP，约5人日；依赖U-08、Q-01、U12-02、U12-03。尚未领取，无真实复核人或签收。Codex本轮只整理结构、当前交接和空白记录，不代替原任务完整实现或真人活动。

## 目标与明确验收

向E-02交付可执行的认知访谈与修订工具：两条件、四结构、八题步骤理解、SCCI候选、心智努力及目的猜测均可追踪到实际版本。每人只接触一个条件；核心体验不加入答题或思维出声。

- AC1：两条件四结构分别执行；SCCI和四层理解逐题覆盖。空白模板或合成题库不算实际覆盖。
- AC2：层级混淆、目的/条件猜测、可访问失败逐项记录，说明修订或保留理由；原始回答、分歧、帮助和技术缺失不丢弃。
- AC3：修订后完整表示方案审计及Unity自动回归通过，绑定实际构建和片段。当前均未完成。

## 五天推进

1. 核对Q-01真实内容审查、U12-02步骤材料、U12-03公平教学与U-08实际成品；冻结人数、分轮分臂方案、题库、版本和活动许可。旧人数建议不能直接当新方案。
2. 填充逐题提纲、片段索引、私有答案核对和可访问路径；两条件同事件、同题面、同答案，题面与答案分别发放。
3. 完成软件/工作人员流程演练；检查四天气和缺失字段、帮助记录及时间拆分，不将演练写成真人结果。
4. E-02在获准活动内执行分轮访谈与双人编码；本包接收问题，成对修订。新一轮使用新人，不能把同一人第二次暴露当独立验证。
5. 验证修订版本、实际渲染和Unity回归，冻结交接与审阅材料；真实第二人按明确候选签收后再按治理流程迁移状态。
