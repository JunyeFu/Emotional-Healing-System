# Level B逐题访谈与修订提纲

用途为Q-02材料交E-02执行；当前无真人记录，无冻结人数或最终构建。先确认活动许可、独立参与者和版本，再按批准方案分配；每人一条件、一次核心体验，拒绝跨组重复体验。

## 作答和追问顺序

完整流程先后测PANAS，再独立完成测量，之后访谈；专门教学检查另标FORMATIVE_TRAINING_ONLY。独立阶段不解释术语、不提示答案。先记录RESPONDED/SKIPPED/TIMEOUT/TECH_UNPRESENTED、作答选项和真实起止时间；后记录思维出声与追问、额外帮助的内容和时长，不混入独立作答时间。

1. SCCI每个候选：请用自己的话复述；你依据画面哪里作答；是否理解成容易、喜欢、有效或舒适。S4另问否定句如何理解。不要求场景原生得到更高分。
2. C-T1/C-T2：当前目标与下一目标在哪里；如何区分storm两次停留、fade两次吸气与跨周期。先让其回答，不教步骤答案。
3. C-A1/C-A2：实际信息来自哪里；如何区分目标与实际、同一轮与不同轮；信号受限能否读出实际。不可用不等于执行错误，未知不补零。
4. C-C1/C-C2：如何判断片段终点的累计区间与相对起点变化；是否误将本口呼吸或fade自动复色当累计改善。区间题必须有真实显示依据。
5. C-D1/C-D2：连接中断与输入受限怎样区分；哪些步骤信息仍可靠；保留旧几何是否被误读成当前真实值。
6. 心智努力：回答计入了什么费力；是否混入身体用力、喜欢或舒适。阶段错误另记录停留实例、吸气实例、周期混淆，步骤相同不代表执行质量合格。

每个条件按四结构检查，覆盖构建、片段、质量/未知事件及可见答案；代码题库覆盖不代替真人覆盖。理解低、学习慢和求助保留，不只留下学会者。

## 可访问路径

记录实际设备、分辨率、观看距离、声音配置与候选低运动/静音路径。检查颜色不是唯一信息、轮廓和对比、字幕阅读、目标/实际/累计保护区、断续降级以及固定镜头局部运动。记录无法看到、无法听到、误认与额外帮助，不让默认分辨率的截图代替所有路径。正式会话中不临时改变处理；必要停止优先并记录偏离。

## 末尾需求特征

先开放询问“你认为本次研究主要想比较什么？”、“你如何描述刚才看到的提示表达？”、“你觉得研究者希望看到怎样的结果？为什么？”；允许不知道、不确定和拒答。不展示未分配的条件或描述其优势，不问未见过的“第一种还是第二种”强制作答。之后才说明研究目的。

编码者不看正式主要结果，分别归类、保留原话来源引用和分歧；猜中或猜错仅作解释/预设敏感性资料，不删除有效情绪回答。

## 问题码及修订闭环

TERM_UNKNOWN、CONSTRUCT_CROSS、CONDITION_CUE、LAYER_CONFUSION、ANSWER_KEY_MISMATCH、NEGATION_BURDEN、EFFORT_SCOPE_DRIFT、TIME_BUDGET沿用历史定义；追加STEP_INSTANCE_CONFUSION、CYCLE_CONFUSION、ACCESSIBILITY_FAILURE、HELP_REQUEST、TECH_UNPRESENTED以定位当前步骤与路径。

revisions每项填发现条件/结构、问题码、原始引用、分母和严重度；两编码者意见、分歧与裁定；修订或保留理由、旧/新版本、两臂配对检查、复测来源和负责人。答案不匹配先停用片段，跨组题干泄漏先修改；百分比触发阈值未冻结，不因小样本零错误宣布PASS。

真人记录与受限引用留在获批仓库外；模板在仓库内始终为空。第二轮用新人并记新材料版本，原始记录不覆盖。完整表示方案审计、Unity回归和真实第二人签收均独立记录，不把Python通过当最终渲染验收。
