## 四段过程

1. 范围准备：真实负责人按[当前交接](outputs/current-admission.md)分别列Level A静态/回放、Level B拟用材料与设备，绑定实际版本和人员；暂缺字段保持待落实，不拿候选计划替代申请。
2. 外部取得：向适用机构提交当前材料，取得活动批准、同意、数据处理及素材使用范围；受限原件留在获批仓库外，仅允许公开的脱敏回执/索引进入仓库。
3. 对照复核：真人核对有效期、对象、材料、设备、采集、角色、退出和保留条件；按既有external_capability记录与资格矩阵登记相应范围。Level A批准不放行Level B或设备研究。
4. 交接关闭：E-01/E-02各自核对实际获准范围，记录接收人与版本；独立复核及真实第二人签收精确交付。其他活动仍阻断，不等待无关阶段三资格，也不把总监签收当机构授权。
