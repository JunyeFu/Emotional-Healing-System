# U-08 跨场景视听性能与可访问性成品

## 状态与责任

WAIT_DEP，依赖G-02、U-03至U-07，约5人日，P-INTEGRATION。领取人、分支和复核人均为空。本轮整理成品交接和旧工具，不代领、不签收Windows制品。

## 目标与验收

交付五适配器的统一音量、亮度、必要字幕及分辨率，非颜色唯一与对比度审计，减少运动和静音配置，目标设备性能预算、Windows构建候选、无TD运行手册和资产许可门报告。五适配器指四个原生天气加一个共享抽象方案，不是第五种天气；共享抽象必须覆盖四结构，至少检查四天气×双条件八种呈现。

- AC1完整自动旅程没有布局、音频、状态矛盾，无TD、无Spout运行。
- AC2目标设备帧率、内存、加载达到事前冻结预算，没有不安全快速闪烁。
- AC3非颜色唯一、关键对比度、不同分辨率、静音和减少运动路径可用，资产许可失败时不得发布。

必需完整录像、对比度与色觉模拟报告、运动闪烁清单、Profiler报告、构建日志、无TD运行记录和许可报告。通过研究U4可访问门及G-02资产门后交I-01/Z-01；U4是研究门，不是U-04任务。

## 五天过程及出口

1. 规格先行：落实目标电脑、显示器、观看距离、输出设备和实际负责人；填写current-product.json中的预算字段并经团队裁定冻结。向U-03至U-06先提供可判定预算，不等待本包整体DONE；当前null不是默认零或通过。
2. 视听整合：接收U-03公共模板、U-04至U-06三个明确天气和U-07完整抽象配置，统一显示环境、音轨、累计与转场，检查固定镜头及fade复色；不重写Python顺序、时钟或真实输入算法。
3. 可访问验证：四天气×双条件检查颜色非唯一、轮廓/几何可辨、保护ROI、分辨率、减少运动、静音及暂停冻结。formal_frozen参数在会话前固定、参与者不操作；demo_accessible只供启动前调整和演示，不生成正式证据。字幕仅用于已有教学和系统内容，核心阶段不新增条件特有文字。
4. 性能与构建：24顺序×双条件完整旅程、暂停中止、质量四态及存储/回执异常；采集目标设备Profiler和完整录像。使用明确实际场景清单和正式控制装配构建Windows候选，保留正式发布门和许可失败关闭；F-03/V03开发EXE不替代成品。
5. 复核交接：复查预算和实际报告、U4、32素材及所有实际发布依赖许可、无TD运行和可重开制品。申请独立复核与真实签收；交I-01集成、Z-01演示及后续活动资格责任人。工程制品签收不替代G-05正式活动资格。
