# U12-02 独立标注与材料核对计划

状态：SPECIFICATION_ONLY。此文件不填写真实标注结果或已达标数值。

## 一、输入隔离

S-02从真实设备归档提取原始呼吸流、质量、单调时间、同步不确定性和原件字节哈希。原件保存在受限库，不进入本仓库。标注人员看不到目标曲线、提示条件、情绪结果或算法预测，只看原始信号和必要质量信息；隐藏文件名中的条件标签。

目标日志另存独立来源。真实周期编号由原始呼吸事件及独立标注锚点建立，不能直接复制目标cycle_index。两个时间轴如何对齐、哪些片段不可对齐须在盲态规则中预先写清。

## 二、标注结构

每行记录：record_id、source_byte_sha256、source_interval、clock_domain_id、annotator_id、annotation_version、actual_cycle_index、actual_step_id、onset_ns、offset_ns、observability、unknown_reason。

actual不可观察时周期与步骤均为null，不使用0替代。storm分别标注吸气后停留和呼气后停留；fade分别标注第一次吸气、第二次吸气及缺失补吸。不能仅凭幅值不变确定停留实例，也不能依据预期顺序补造不可识别事件。

两名独立标注者先各自提交，再计算一致与争议；第三人按同一原始信号裁决。原始标签、裁决标签、理由与版本均保留。具体人员、规模、观测性准入阈值由真实负责人冻结，不自动使用合成结果作门槛。

## 三、逐结构验证

- 分天气、步骤、信号质量报告事件precision/recall/F1、混淆矩阵、未知率；不要把hold_1/hold_2或inhale_1/inhale_2合并后声称通过。
- 在可匹配事件上报告起止边界误差和覆盖率；漏检/多检保留在事件指标，不因无法算边界误差就丢弃。
- 固定同一原始波形，替换/移位目标轨迹：独立实际检测与标注必须不变。变化则登记目标泄漏，不用调参掩盖。
- 注入断流、低质量、同相位错步骤、跨周期混淆；实际未知时不得输出正确执行或零值信号。
- 真实测量未过门时，诚实缩小可识别步骤与论文主张；U12-02代码通过不关闭S-02。

## 四、逐片段材料审核

Q-01/Q-02与Unity任务为两个条件提供相同事件ID、片段长度、目标/实际来源、累计函数、质量与音频预算。保存各条件的真实视频字节哈希和渲染版本，核对片段结束时间与答案所用帧一致。

累计区间来自实际显示版本；previous_recovery_value取同片段起点同模块，同一时间轴。原生表示没有准确显示周期或累计区间时，不可直接采用要求该信息的题目；先修订双条件等值呈现和题库，并重新冻结版本。

第二人逐题核验答案，禁止按条件改键。记录同粗相位错实例、当前错误但累计升高、断流目标继续、终场累计未满等负例。未提供渲染视频时标记PENDING，不写PASS。

## 五、形成性检查与下游

理解题置于PANAS后测之后。设置无片段和替代片段检查以发现常识作答、文字泄漏与位置偏差；记录反应、跳过、超时、技术未呈现和用时。正式八题的材料选择、序列、预算及缺失规则由Q-02/U12-04盲态冻结；本候选题库不扩大体验操作。

U12-09消费代码复算、源哈希、双条件材料检查及未关闭项。U12-04消费候选响应字段与缺失状态；原A-03理解总分接口不是新材料已有效的证明。真实机构、人员和参与者工作继续由相应任务负责。
