# 第11步执行方案：离线处理、锁库、分析和论文 v1.1

## 1. 数据处理顺序

```text
L0 原始设备、控制、回执和manifest
-> L1 同步、SQI与机会时间线
-> L2 呼吸事件、机会分类与人工标注
-> L3 模块/会话摘要
-> 全部随机分配分析集与完整四模块分析集
-> L4 锁定分析数据
-> L5 模型、图表、论文表格和复现报告
```

## 2. 盲态锁库

- 阶段一条件以X/Y隐藏，阶段三分配另用独立编码；
- 事件算法、机会分类、重大偏离原因码和工具筛选先冻结；
- 锁库清单包含输入、代码、配置、构建和随机化哈希；
- 揭盲后不改主要规则，所有偏离逐项报告。

## 3. Gate 1

参与者级四模块等权PF使用带HC3稳健标准误的线性调整模型：

```text
PF_participant ~ cue_mode + centered_NA_pre + randomization_strata
```

24顺序不作为24水平固定效应进入主模型。完整顺序、位置和转换只进入预设敏感性或发现分析。全部随机分配分析集和完整四模块分析集均通过`-0.075`下界门才关闭Gate 1。

## 4. Gate 2

按顺序执行：SCCI优效操纵检查、四层理解非劣、心智努力非劣。任一失败即Gate 2失败。SCCI同时运行序数项目模型和条件间项目功能差异检查；量尺不稳定时只作描述。

## 5. Gate 3

```text
NA_post ~ NA_pre + assignment + randomization_strata
```

`assignment`比较冻结策略与均衡随机，策略回退保留在原分配。报告调整差、95%置信区间、执行质量护栏、支持、有效样本量、策略熵、回退、校准和重放结果。

## 6. 次要与模块分析

- 阶段错误、注意连续性、喜欢度和舒适度构成一个预设家族并控制FDR；
- 模块和相位只报告效应量、区间、预设图和失败案例；
- 不能从固定配对分离天气或呼吸结构作用；
- 设计原则必须区分数据支持、设计推断和未来假设。

## 7. 论文结构

正文按“理论缺口、候选四层语法、系统、阶段一比较、设计知识、部署扩展、限制”组织。策略完整审计、工程测试和复现细节进入补充材料。正式投稿前重新核对IJHCI实时作者说明与数据政策。
