## 尚不能据此判定的事项

真实设备BLE通知解析、真实Unity渲染、正式SessionCore/P-02接线、研究准入、正式SQI和B适应策略仍未由本轮验收。ECG与胸带未联合拟合跨信号耦合，不能用这套数据证明HRV或情绪效果。800秒为候选，未冻结新研究时长。

本轮修复了重复解压导致发送过慢、开发记录逐包刷盘导致界面阻塞、工作流I/G/X未入记录、导出按钮未接通及数值显示过长。普通开发数据最多100毫秒同步，生命周期事件立即同步；不改变正式存储合同。
