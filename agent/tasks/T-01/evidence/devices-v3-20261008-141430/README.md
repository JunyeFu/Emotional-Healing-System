- 81项T-01/F-04及验证器专项测试通过；包含800秒合成缓存测试、跨时钟域、缺值/零值、隐含非法SQI、版本/单位/非有限值、重复/倒序/重叠批次。

- 正常收流设备批次拒收0；2条重复批次与2条非法样本按预期拒收。另1条非法SQI遥测计入TD无效帧，不混入设备批次统计。
- 正常截图呼吸缓存11108点，ECG缓存724点；原生绘图TOP均640×160，实际曲线像素分别1521/1687。缓存按时间窗保留，不宣称这些是完整设备采集计数。
- 布局分别1280×720、1600×900、1920×1080；本机非商业TD实际截图全部1280×720，未放大伪装为较大像素截图。

## 接口与使用

打开本目录候选即可查看；模拟发送器已经停止，当前打开副本随后会显示历史值。候选不自动发送模拟数据。模拟流为400Hz呼吸批次、130Hz ECG批次，每0.1秒发送；HR68bpm/RR882ms为示意字段，运动状态未知。接收口仅本机UDP5005，界面刷新≤20Hz。

使用`py -3.14 -X utf8 agent/tasks/T-01/execution/capture_workbench.py --devices`可从源底片创建新隔离测试；为避免竞争，须先关闭已打开的测试副本。再用`verify_device_capture.py <新证据目录>`检查原生回执。

近似样本龄使用发送时年龄和TD接收后经过时间，不含传输延迟；不是设备到屏幕测量。记录/事件通道仍未接入；未连接真实胸带、不证明SDK、同步、交互状态估计或LIVE_E2E。完整显示消息说明见[双设备设计](../../design/workbench-devices-v3.md)。
