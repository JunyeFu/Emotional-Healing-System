# X-03【策略运行】阶段三同构建策略随机接入与防在线学习


## 验收

当前实施要求：安全重放及未来策略运行复用2022粒子适配器；目标步骤与独立Actual保持分离，装饰延迟不改变决策/事件时间。采用[统一实现标准](../../design/情绪天气方案/2026-10-08_Storm与纯粒子双环实施标准.md)，截图与核查边界见[本包画面证据](outputs/current-implementation-evidence.md)。

- AC1：策略版本、清单/分组或构建身份错误拒绝，两组相同scene_native制品；同构建不等于把原生和抽象合成一组。
- AC2：运行与回放不写模型/缩放器/参数；均匀回退参与者仍属策略分配组，不能移到均衡随机组。
- AC3：候选、行为/目标概率、实际前状态、真实采样、理由、回退和版本全部记录，同输入逐决策可重建。

## 四天过程与责任

1. 输入和接口：E-05真实冻结模型/配置/支持证据，X-01分配及预约，U-01/U-08同构建，G-05活动资格；P-01/P-02顺序和重放迁移先写版本化接口。指定Python集成人、Unity/记录集成人及真实研究冻结负责人。
2. 最小纵向链：开发fixture可走均衡固定路径；策略路径另做当前状态输入、冻结加载、动作选取、存储提交后控制发送。每天气一次，时长/段/暴露由P-01管理。
3. 故障和负例：版本错、动作重复、错误候选、低质量/缺失状态、只读写保护、记录失败、重发幂等、掉线及回退归组；不在线调参。
4. 重放与验收：比较所有决策和控制/回执、前状态/随机源；隔离离线重放副作用。另取两组真实制品身份、800秒全链与设备证据，经独立复核和真实签署再改状态。

本轮`py -3.14 agent/tasks/X-03/execution/verify.py`只验证当前接口限制、记录行为与交接，不实现冻结策略或解除正式门。当前能力和缺口见outputs/current-runtime.md。

国内资料沿用任务：[pytest中文文档](https://pytest.cn/en/stable/)用于幂等、版本与只读负例；[Apifox JSON Schema教程](https://json-schema.apifox.cn/)用于合同字段和条件。以项目实际Schema和公开接口为事实依据，不据教程宣称Unity接入或动态顺序已完成。
