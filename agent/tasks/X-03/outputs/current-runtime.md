# X-03当前策略运行与重放交接

## 当前能力

WAIT_DEP、未领取未签署，注册依赖X-01/X-02/U-01；完成条件还要求E-05真实冻结策略，不能因登记前置满足就跳过运行门。策略是条件式扩展，不阻断阶段一核心论文。

P-01已接F-05步骤v2.2，但v2.2仍拒绝frozen_policy并返回ADAPTIVE_SEQUENCE_REQUIRES_V2_2。原因码是历史命名，不表示改版本号即升级成功。FixedSequenceProvider.prepare需要manifest完整四天气及预先四条匹配决策，prepare控制明确sequence_mode=fixed；next忽略SessionSnapshot，不是状态自适应。

SessionSnapshot只有会话/段/时钟等信息，没有最近PF/SQI、前量表或状态数据接口。SequenceProvider预留类型不等于已接真实状态；X-01策略臂序列null也不能塞进当前完整顺序manifest。当前weather_sequence不能称回退顺序，更不能提前猜将来动作。

## 接口升级的最小完整范围

X-03与P-01集成人需另行裁定版本化策略manifest/分配、动态顺序计划、决策前状态输入、动作提交和控制关联，保持固定路径及F-05步骤合同语义。当前strategy_contract_version=null，本轮不新增未复核Schema字段或放宽正式拒绝。

状态必须只含截止时点之前的允许信息，包含前量表、位置/已完成/剩余、最近呼吸PF/SQI和累计降级；末测/未来模块/阶段三结果禁入，心电只离线解释。决策时点与转场/暂停有效时间由P-01冻结，不能由Unity或TD另启权威时钟。首次动作何时决定和暴露登记顺序须对齐U12-06/U12-11，不让策略选择绕过正式存储、prepare ACK和暴露门。

候选只含剩余天气，每个恰好一次，模块内部段/时长不因数据质量改变。顺序变更是模块边界的明确动作，不在已开始模块中随帧重新采样。重复tick、ACK重发和重连均复用已提交决策，不再次推进随机源或选天气。

每个动作持久化实际前状态及其身份、候选排序、完整概率分布来源、所选动作行为/目标概率、真实随机抽样、理由/回退和模型/配置版本，再允许控制发送。现有PolicyDecision只给所选动作概率与状态hash；完整状态/分布及随机源记录形式需版本合同裁定，不凭hash恢复缺失事实，不假定Schema已提供完整分布。

## 记录与离线重放

P-01 CoreUpdate可返回policy_decisions，P-02记录代理会持久化输出；这只是现有固定路径证据。P-02 SessionReplayer只允许既有SessionCore，自定义core_factory触发REPLAY_CORE_UNSAFE；不能把任意策略引擎注入来绕过无副作用边界。

核心dependencies.manifest_store与RecordingSessionCore必须绑定同一个DurableManifestStore；只把存储交给代理，核心仍用内存存储，会在后续记录返回MANIFEST_NOT_STORED。本轮测试实际复现并修正测试装配，不视为业务代码缺陷，也不将独立存储误称完整记录链。

真正策略重放需P-02与X-03共同支持受限、确定性读取冻结模型/记录前状态/随机源，并核对决策及控制输出。保留已提交调用配对、完整性检查和断电中断语义；不联网、发TCP/UDP、再登记暴露或恢复旧体验进度。不能只重放记录的已选动作就称模型决策重建通过。

存储先于可观察控制，存储失败时按正式中止规则处理，不发送未耐久提交的正常策略动作。模型/缩放器/特征表/温度/混合率运行期间只读，低质量/支持不足触发冻结的均匀/更简策略，不在线训练、再校准或选参数。

## 两组和回退

策略与balanced_random都使用同一scene_native制品、天气素材、模块呼吸合同与质量规则，唯一分配差异是顺序服务。必须实际核对构建身份；本轮没有两组Unity制品证明。Unity U-01只收控制和遥测、维持渲染镜像，TD只监控/发获准请求，不加载模型或选天气。

回退仍属原策略分配组，登记触发原因和暴露比例，估计包含回退的部署策略，不按实际走均匀重分组。未知策略、错清单/构建/模型身份和缺实际冻结证据拒绝启动；低质量回退不同于身份/正式门错误，不能用随机回退绕过后者。
