# B-03【正式批次】阶段三会话批次模板

TEMPLATE/BLOCKED_EXTERNAL，依赖G-04，每个真实实例最多12人、约5人日；未领取未签收，无真实实例。阶段三是条件式扩展，材料规范化不授权采集，也不把未开展模板标DONE。

## 目标及验收

按G-04真实批准及独立预注册版本执行新队列阶段三：两组都使用scene_native，比较frozen_policy与balanced_random，保留全部分配、暴露、决策、回退、退出及原始证据，交E-06/A-04/A-06。

- AC1分配来自同版锁定stage_3清单，索引、分层、组别与清单身份一致；随机组完整顺序不变，策略组null不补成预先固定顺序。
- AC2策略每次决策及真实状态/完整候选分布可按获准X-03路径离线核验，随机组按分配累计覆盖24排列。现动态运行/重放未交付，不拿固定回放冒充通过。
- AC3每人只一个阶段、一次核心体验；首次教学即登记暴露，同scene_native构建与共同配置/时序一致，真实设备及记录链可用。已暴露退出者不得重做或跨阶段。

## 五段执行和责任

1. 批次负责人接收G-04精确冻结、机构回执、预注册、最终N/停止及资源许可；明确操作者、分配保管/揭示、数据/QC、决策审计和独立复核人。
2. 按X-01同版stage_3清单预约新未暴露队列，真实去重/账号权限核验；完成前测后按冻结时序揭示，两组共同scene_native教学预算相同。
3. 同一Python记录代理驱动运行，四模块决策先耐久提交再控制发送；现场只观察和按获准路径暂停/停止，不人为改顺序或追求策略胜出。
4. 授权数据人员核查P-02封存及六类原件，分别统计分配、暴露、完成、退出、PANAS缺失、可评估模块、策略回退和决策审计状态；缺证据保持待补。
5. 负责人及另一人复核精确实例与偏离，交E-06全部实例和停止事实，A-04消费锁定分析，A-06判定实际范围；单批QC不授权锁库揭盲。

48完整块是X-01现实现及注册计划，不是12人批次均衡要求。提前停止/部分块仍完整披露，最终尾块规则交G-04事前冻结，不为完成者缺格定向补人。真实责任人均待实名，Agent只完成本轮规范化。

## 固定目录和验证

inputs列真实来源，outputs保存当前交接、空登记及QC提纲，evidence记录实际核查，archive引用已归档旧来源。受限填表留获批仓库外，不把个人身份放入仓库。

执行`py -3.14 agent/tasks/B-03/execution/verify.py`或execution/verify.ps1，只检查合成软件、既有接口与规范化；不会生成正式manifest、招募、真实QC或签名。
