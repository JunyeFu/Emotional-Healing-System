# V-01 当前研究体验与完整旅程

本入口与current-experience.json为当前设计交接候选。原V-01由傅钧烨签收的v1.0设计保持原样；当前v1.2研究口径及后续视觉选择已经改变部分旧开放项和时序，不把原签名转移到此新候选。

## 当前目标与权限

比较完整场景原生与抽象控件式呼吸提示的短时负性情绪收益、代价与边界。PANAS主要结果、SCCI操纵检查和机会PF护栏分别解释，不使用旧F-019及C-001/C-002的有序门隐去情绪比较。不预设原生获胜，阶段三不再是核心论文必经路线。

每人只进入一个阶段、一个条件、一次核心体验；不再沿用旧简报“两条件共享同一参与者”的字面描述。形成性片段可以同源输入，正式两组各自产生真实输入，但使用相同算法、目标、累计函数、时长、声音、场景和非提示背景。

Python负责流程、时钟、顺序、交互状态估计和记录；Unity只镜像、渲染、ACK与回执，不读取量表或自行选第一天气。TD负责只读监控，后续操作请求仍须由Python判定。无参与者手部操作约束用于核心观看阶段，前后量表在核心之外填写。

## 当前旅程

| 节点 | 参与者所见与操作 | 系统条件及计时 |
|---|---|---|
| J-01 现场准备 | 不展示核心或分条件材料，无操作 | 现场、去重、设备、分配与活动许可核对；正式条件未通过不启动 |
| J-02 中性准备 | 同版中性说明，只听取 | 不先教授某一条件，保留前测未受分条件教学影响 |
| J-03 PANAS前测 | 外部表单或纸面填写 | 前测不交Unity，不依据其答案在Unity选入口 |
| J-03T 分条件教学 | 在有限共同预算内观看、跟随 | 前测后揭示分配；首个分条件材料前登记暴露；候选180秒，不计入800秒，不要求达到掌握后无限延长 |
| J-04 中性入口 | 准备画面，无操作 | manifest追加落盘、Unity握手/prepare，研究时序及教学门满足后由外部请求start |
| J-05 模块揭示 | manifest指定环境自然进入 | demo首帧边界，不额外计时；模块四者各一次 |
| J-06 demo | 本模块目标与机制示范，无操作 | 推荐25秒；它不能替代J-03T条件教学 |
| J-07 closed_loop | 可区分的目标、真实实际、累计与降级 | 推荐150秒；Python下发具体周期/步骤身份，未知不补值 |
| J-08 lock_transition | 当前累计锁定、离场及中性走廊 | 推荐25秒；停止伪装实际更新，保持本模块锁定 |
| J-09 模块转场 | 自然过渡，没有选择界面 | 属于lock_transition内部；到下一模块才重置累计生命周期 |
| J-10 中性结束 | 完成画面，不宣告个人效果 | 第四模块后Python正常end与摘要封存；失败不能显示正常完成 |
| J-11 PANAS后测 | 核心之外先填情绪量表 | 不先进行理解考试或条件偏好讨论，答案不反馈给运行时 |
| J-11M 理解及其他测量 | 再做理解、操纵、努力等评估 | 使用当前步骤真值，缺失状态不补零；5分钟是候选问卷预算，不是整个活动总时长 |
| J-12 数据检查 | 不接触操作台，无操作 | 现场人员查缺失、回执与文件；后测原件按数据治理关联，不把已封存核心记录覆盖 |

J-05至J-09是可重复的模块旅程模板，不是仅执行一次；四个位置各执行demo、closed_loop、lock_transition。默认4×200=800秒，允许范围每模块184至220秒，四模块736至880秒；必须以统一冻结配置运行，两条件匹配。暂停冻结有效时间，因此墙钟时长可增加。前后测、教学、准备不包含在800秒内。

## 暴露、故障与视觉关系

旧D-016和M-012只考虑start前中性入口；现在教学已经展示处理材料，暴露门必须提前到首个分条件材料前。P-01当前只在核心start登记，教学接入尚未关闭；本设计不新增SessionCore状态或假称登记已实现，由U12-06/X-01连接G-02、P-02和教学运行记录。暴露后退出不能重新领取别的阶段。

暂停、不可用、断连和存储失败保留上游故障语义，不由Unity重排或猜测步骤。正式存储失败停止正常控制；降级不伪装成功。实际呈现回执和真实链仍需下游验证。

四天气固定镜头；V-02/V-03/V-04已选定的形态不能因旧O-001至O-015“开放”而重开。有效天气、双环、世界观和转场选择以各包当前合同为准。fade水系提示与整屏复色独立：复色只随模块有效时间，不代表recovery_value或呼吸步骤。
