# U12-10 主张检查规则

本表是结果审阅规则，不是论文第一稿或观测结论。所有允许项仍限于所测两套完整方案、参与者、教学预算和短时体验；实际分类须消费同版锁库及SAP。以下区间均指基线调整后的PANAS负性情绪native-minus-abstract的95%CI。

| 已有证据 | 可用解释 | 不可替代或扩大 |
|---|---|---|
| 上界<0 | 原生方案调整后的负性情绪更低；重要性另判 | 自动推每个天气或呼吸结构有效、所有原生均优 |
| 下界>0 | 抽象方案调整后的负性情绪更低；可作反向发现 | 从原生不显著推抽象更优 |
| 触0或跨0 | 当前区间未建立组间方向；报告估计与精度 | 两者相同、抽象优、确认性等效 |
| 严格越过事前关注差异 | 对应实际重要收益的区间支持 | 从测试delta或观察后选界值 |
| 严格位于事前实用界内 | 区间处于预设实用界限内；可并存统计方向 | 默认关闭的确认性等效检验成功 |
| 触±delta或区间跨重要界 | 重要效应未排除，不能裁成已越界/已在界内 | 凭点估计单独决定实际重要性 |
| 未冻结delta | 只给方向、区间和精度 | 补填重要性或事后等效界 |
| PF护栏FAIL或SCCI未形成预期 | 有效预设情绪比较仍报告，独立说明功能/操纵 | 删除情绪结果、靠护栏失败证明另一方案优势 |
| delivery_valid=false | 限定实现效度并报告运行事实 | 将无效实现比较推广到所有表示方式 |
| sensitivity=SENSITIVE | 披露结论随缺失假设等变化 | 挑最有利敏感性版本当唯一结果 |
| 情绪不可估计或输入非法 | 原因、缺失范围和可报告事实；不生成虚假数值 | 用0代表缺失或强制给赢家 |
| 有效比较与过程相关 | 比较证据、观察过程关联和负例边界分别报告 | 确认性机制归因、长期效果或整个系统总体因果效应 |

部署推荐需完整功能、错误、不适和适用边界判断，不由标签自动产生。小差异、反向优势和证据不足均有论文报告出口，不能保证原生获胜。
