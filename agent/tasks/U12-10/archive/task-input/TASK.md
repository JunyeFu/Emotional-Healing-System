# U12-10 【结果复核】阶段一结果分类与主张独立复核

候选任务，尚未进入活动注册表，不可领取。

依赖：A-05。工作量：2人日。

## 技能与资料

Python+统计复算+合同测试

| L-PYTEST | 单元测试、fixture和参数化 | [pytest中文文档](https://pytest.cn/en/stable/) | fixture、parametrize、临时目录、失败断言 |
| L-STAT | 统计学习、线性模型与验证 | [Datawhale统计学习方法解答](https://datawhalechina.github.io/statistical-learning-method-solutions-manual/) | 线性模型、正则化、交叉验证、评价 |

## 执行过程

1. 核对输入快照和前置回执，列出本任务对应字段或制品。
2. 逐项实现交付：beta方向;CI尺度;功能与效度标签;允许句子。
3. 对照验收条件执行复算、负例或真实回执核验：反向优势/不确定/小差异不混淆；不显著不能生成等效；CI边界和无效输入测试。
4. 绑定提交与证据，独立复查后交真实第二人签收。

## 验收与证据

新制品验收对象明确；不覆盖历史DONE；研究证据单独判断

版本与实际检查日志；外部项须真实回执

机器验证不能代签外部批准；旧DONE只覆盖原签收范围。资料链接继承现有教学索引，本轮未重新验证网页。
