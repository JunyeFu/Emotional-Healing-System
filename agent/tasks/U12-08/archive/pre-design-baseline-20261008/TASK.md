# U12-08 【扩展分析】可选阶段三独立分析附录

业务状态为 `WAIT_DEP`，依赖 A-04、E-05，工作量4人日；未领取、未指定复核者、未签收。规范化分支不替代实际实施候选。

## 目标与边界

将已锁定阶段三结果、策略支持与回退、偏离、缺失及停止事实整理为独立分析附录，供 A-06 关闭实际研究范围及 W-02/W-03 消费。策略冻结归 E-05，统计分析归 A-04；本包不训练模型、不重算在线事实、不替代研究冻结或揭盲授权。

当前交接见 [current-extension.md](outputs/current-extension.md)，附录规格见 [appendix-spec.md](outputs/appendix-spec.md)。真实附录未交付，不将空字段或合成测试记为业务 PASS。

## 执行过程

1. 输入及范围：核对 E-05 策略冻结、E-06 精确锁库与授权、A-04 独立 SAP/结果/复现及实际分配、暴露、批次台账；登记未取得的原件与真实责任人。
2. 附录填充：引用 A-04 锁定比较，分别整理支持、实际回退、偏离、缺失和停止；所有已分配、暴露及部分运行实例均进入范围核对。未开展扩展不虚构结果，已开展但无法估计写实际原因。
3. 复核交接：核对原分配组、分母、分析集与结论范围，形成可重跑入口和同版本证据；独立复核后交真实第二人，A-06据三台账选择路线，W-02只消费获准主张。

## 验收

- AC1：输入、实际研究范围及交付版本明确；四结果族可追溯到锁定结果或真实事实，不把支持不足、回退或未完成实例删掉。
- AC2：核心稿不依赖未开展扩展；已开展完整披露，未做不写 PASS。两组均为 scene_native，候选比较为 policy_minus_random；回退仍留原策略组，顺序排名不写因果结论。
- AC3：候选提交、必要复算、独立复核与真实第二人绑定。空台账不证明没有活动，元数据路线通过不替代真实签署；不继承阶段一数值或结果分类器为阶段三正式合同。
