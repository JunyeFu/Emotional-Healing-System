# 投稿与返修检查表 v1.1

## 提交前硬门

- 当前状态不再是`REJECT_AND_RESUBMIT_DESIGN`；
- 最近工作击穿测试、U1至U8、Level A/B/C和预注册状态可核验；
- Gate 1/2结果来自锁定数据；Gate 3只在条件满足时进入确认性主张；
- Unity/Python/TD真实链有LIVE_E2E、外部延迟和干净机复现；
- 每项主张绑定结果文件、版本和哈希。

## 研究报告完整性

- 参与者流程、资格、随机化单位、分层、可变块、隐藏和揭示时点；
- 估计目标表、分析集、偏离原因码、缺失、多重插补和敏感性；
- Gate 1机会分母及三个PF指标；
- Gate 2明确SCCI为操纵检查，并报告四层理解、心智努力和项目功能差异；
- RQ2次要家族FDR；RQ3只用效应量、区间和预设图；
- 策略报告行为概率、目标概率、支持、ESS、交叉拟合、校准、熵、回退和重放；
- 阶段三两组同一场景原生构建，估计目标包含回退。

SPIRIT/CONSORT 2025可作为方案和报告完整性清单，COSMIN可作为自建工具质量参考；两者不写成IJHCI强制要求。

## 主张边界

- 标题和摘要以完整提示表示方案为主；
- 独立重建未过时不用“跨结构框架”；
- Gate 3或U6未过时删除部署扩展优效表述；
- 不把固定配对拆成天气、呼吸结构或单一视觉机制作用；
- 不把整体前后变化归因为项目本身；
- 不把工程完成当作参与者结果。

## 投稿材料

- 正式提交当天重新核对[IJHCI期刊说明](https://www.tandfonline.com/journals/hihc20/about-this-journal)和实时作者说明；
- 匿名主稿、标题页、封面信、补充材料和CRediT；
- 伦理、预注册、偏离、利益冲突、资助和AI使用披露；
- 数据可用性声明符合[Taylor & Francis当前数据政策](https://authorservices.taylorandfrancis.com/data-sharing-policies/basic/)；
- 代码、环境锁、SBOM、许可、合成数据、图表源文件和持久化归档；
- 匿名扫描、链接检查、校验和和独立复现日志。

## 返修

- 逐条回复并引用页码和修改位置；
- 区分必须修复、可用现有证据回应和超出设计识别范围的请求；
- 新增参与者研究前重新检查外部批准与预注册；
- 保留原稿、每轮差异、回复信和制品哈希；
- 不以事后子组、替代终点或挑选顺序挽救失败主门。
