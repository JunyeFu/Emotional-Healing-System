# U-01 Unity可靠控制技术探针

U-01在独立程序集`SRP.U01.Runtime`中实现Python到Unity的可靠控制消费、会话镜像、UDP 5006遥测门、ACK、渲染回执和断线重连。旧v1.2脚本不属于本实现入口。

## 边界

- Python继续拥有会话、顺序、单调时钟、交互状态估计和记录权威。
- Unity只在收到合法控制事件后改变镜像状态；Unity帧和本地时间不会推进模块。
- v2.1只允许`dev_replay`；正式路径必须使用v2.2。
- 旧帧、乱序控制、改变内容的重复事件、错误握手和跨会话消息失败关闭。
- 场景适配器完成对应帧呈现后调用`ConfirmRendered(event_id, frame_seq)`；U-01不根据帧末事件自行宣称呈现成功。
- 已确认回执保留原事件、模块、段与帧身份；重连或控制重发时可重复发送同一回执，由Python幂等消费。
- TouchDesigner缺席不影响本组件。

## 运行入口

在参与者场景的常驻对象上挂载`SRP.U01.U01RuntimeBridge`。默认连接`127.0.0.1:5010`并监听`127.0.0.1:5006`。正式装配与构建仍由后续任务完成。

## 验证

EditMode覆盖19条P-01 golden控制轨迹、重复/乱序、v2.2步骤实例遥测、错误握手和真实loopback断线重连。PlayMode证明Unity帧不会自行推进镜像。
