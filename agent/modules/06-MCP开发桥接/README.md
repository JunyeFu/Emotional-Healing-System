# MCP开发桥：编辑器辅助

## 定位

Agent通过MCP辅助Unity或TouchDesigner编辑器搭建、修改、测试和导出。正式运行由Python会话权威、Unity参与者端和TD实验员端按冻结合同通信；MCP不替代TCP/UDP，不承担真实设备采集、随机化、正式控制或数据资格。

当前架构使用TCP本机5010传递关键控制及ACK/渲染回执，UDP 5005/5006最多20Hz传递自包含遥测。Unity不依赖TD或Spout提供参与者画面；旧10Hz链和TD统一提示只作历史参考。

## 开发规则

1. 先按根目录`AGENTS.md`运行`git status --short`，确认工程路径、候选提交、环境和修改范围。
2. 一个编辑器同一时间只有一个写入者；并行Agent使用独立工作树和可合并脚本，不同时覆盖二进制工程。
3. 修改前固定源文件身份，完成后保存真实工程、执行编译与重开验证并导出实际差异；截图不能替代场景文件。
4. 每个任务记录输入快照、实际执行、未执行检查和候选证据，再进入独立复核。

允许创建场景对象、编写Editor/C#工具、构造开发fixture、显示合成遥测、检查资产路径和执行已授权开发验证。禁止通过开发桥修改正式条件或阈值、上传受限数据、代签外部资格、用生成内容关闭研究门或把模拟回放写成`LIVE_E2E`。

正式构建必须关闭开发MCP服务、任意脚本编辑入口和无关网络依赖。配置文件存在不代表编辑器已连接或机器已授权。
