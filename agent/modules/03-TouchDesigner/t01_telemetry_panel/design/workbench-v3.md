## 字眼与数值规则

1. 标题用“SRP 实验工作台”；导航为“总览 / 链路与时钟 / 事件与审计”，不设置没有真实波形输入的“信号”曲线页。
2. “周期”改为“周期序号”，不是秒；“步骤”改为“步骤标识”，保留原始 ID；“相位”用“呼吸相位”；“进度”用“相位进度”。进度和置信度只在有效值存在时按 0-1 转为百分比显示。
3. `cue_mode` 展示“场景原生提示 (scene_native)”或“抽象呼吸提示 (abstract_pacer)”；`runtime_mode` 单独显示原枚举，开发回放不得显示为正式采集。
4. `module_id` 显示风雨 / 炎热 / 冰雪 / 褪色并保留 storm/heat/snow/fade 原值；位置使用合同原值，不在本轮猜测其索引基数。`segment` 对应示范段 / 闭环段 / 锁定过渡段并保留原枚举。
5. `actual_confidence` 标为“实际识别置信度”；`recovery_value` 标为“场景恢复值”，不是“情绪恢复率”或论文结论；`recovery_locked` 标为“恢复值锁定”。
6. 帧龄标为“TD 末帧年龄 (ms)”；来源到接收、接收到发送、来源到发送均为现有时间戳差值，不标为端到屏幕延迟。时钟偏移与同步不确定度保留 ns；漂移用 ppm。
7. “接收”改为“有效接收”，“丢帧”改为“序号缺口”；两者均为 TD 本地接收统计，不声称设备原始样本丢失。会话切换、来源重启、有效帧间隔在详情保留。
8. 无遥测时字段为破折号、设备状态为“未知”、质量条为空。已初始化的本地计数可以为 0。断流后标明“末帧历史值”，不显示绿色实时状态。
9. 不仅依赖颜色区分状态。无效、乱序、重复帧保留明确错误原因；字段详情可查看完整 ID、原因码和合同原值。

## 页面安排

- 顶栏：名称、遥测状态、导出菜单、截图、人工标记、中止请求。当前无请求或导出实现时按钮禁用，原因在固定状态行说明，不用遮挡式弹层。
- 会话栏分两行：会话 ID / 运行模式 / 协议；天气模块 / 模块位置 / 流程段 / 提示条件。无完整序列来源时不画四天气顺序时间线；无会话状态消息时不推断 RUNNING。
- 总览主体：左侧“设备与信号质量”；右侧“呼吸跟随对照”。下一行“交互状态估计与场景反馈”展示置信度、恢复值、锁定；常驻“降级与异常”保留原因与最近错误。
- 总览底部：六项链路摘要，以及“操作请求”当前通道状态；不把尚未接通的审计历史写成“暂无事件”。
- 链路与时钟：完整时间差、时间戳、质量指标、链路计数、身份字段和完整错误。时钟技术参数不占首页主体。
- 事件与审计：告警、人工标记、中止请求、ACK、记录结果；尚未接入时明确“审计通道未接入”。
- 导出菜单：遥测快照 / 会话归档 / 事件记录。后两者不从 TD 的有限 UDP 快照冒充完整 L0/L1。PNG 截图单独使用相机图标。

不纳入本轮：开始/暂停/恢复按钮、改天气/改顺序、阈值调节、前后量表输入、情绪分数、原始波形、Unity 直接控制、自动论文报告、未验证的设备品牌在线标识。
