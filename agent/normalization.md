# 任务包双层规范化

目标是将项目根目录内容归入 `human/` 与 `agent/`，根目录只保留 Git、编辑器及运行工具必需的入口配置。此迁移包含全部现有任务，不能仅完成当前可领取任务。

## 逐包过程

1. 从注册表读取名称、责任人、上下游、交付和验收要求，读取实际实现与签署证据。
2. 按统一结构整理 Agent 层，确定文件归属；共享代码归入模块，任务包引用它。过期文件有据清理，已签收原件有据归档。
3. 检查交付与当前主线，执行相关复测；从 Agent 产出修正事实和偏离。
4. 从结构化总结生成每包 Word 和项目串联 Word，检查每页显示、内容来源与上下游衔接。
5. 通过后登记规范化完成，继续注册表中的下一包。完成全部包后收拢旧根目录内容，修复运行命令、引用、生成器和冻结输入变更记录，再验证整个项目。

## 完成判据

每包必须有真实来源、当前验证与可读 Word；未完成任务的总结要明确未交付项。串联文档必须能追溯跨包输入、输出和未闭合关系。根目录旧业务目录全部迁出且运行引用修复后，才能关闭整体目标。
