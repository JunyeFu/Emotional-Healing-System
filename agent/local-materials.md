# 本机材料与媒体位置

`local/`保存制作工具、临时目录、测试缓存、渲染QA和本机工作目录；`archive/local/`保存原本机历史材料。两者默认被Git忽略，不随任务提交公开，不承载正式研究数据根目录。

48件此前已跟踪的V-04媒体位于`local/artifacts/V-04/`，保留Git LFS身份；通过仓库克隆并取回LFS即可获得这些已发布媒体。其他本机文件不因此变为公开交付。历史媒体合同中的旧路径由`tools/resolve_frozen_source.py`和V-04当前验证入口解析，不重写历史合同。

任务材料的权威入口仍是`tasks/<编号>/TASK.md`及其固定子目录；本机缓存不能代替任务交付。必要工具由执行脚本定位到`local/tools/`，具体字节版本依据原工具锁定文件。本机制作工具不会随仓库自动安装。

根目录保留`AGENTS.md`、`README.md`、`pytest.ini`、Git属性及编辑器配置；除此之外，业务、交付、历史和本机材料归入`human/`或`agent/`。外部Codex管理的工作树不在本项目根目录，保持原位置，不迁移也不删除。
