# 本机目录迁移的输入影响

本批只改变本机工具和材料的物理位置及当前消费者读取路径，不改变业务合同、任务状态、签署范围或领取身份。V-05已收到的U-02适配说明包含旧制作工具目录；其原始快照按字节保留在`agent/archive/root-migration/local-inputs/`，读取绑定登记在`agent/normalization-relocations.json`。当前执行说明指向`agent/local/`，受影响执行者应采用这一物理位置，不把路径更新当成新的功能验收。

原独立包、输入快照ID、manifest和哈希保持不变；未重新生成领取包。绑定脚本验证快照与本批开始提交的源文规范化内容一致，并核对既有manifest哈希。当前样片合同保持原字节，由读取工具解析旧路径，不在原文中改写。
