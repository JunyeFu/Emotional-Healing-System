# 共享研发目录迁移影响

共享实现由根目录 `02-技术研发/` 迁入 `agent/modules/`。当前运行脚本、仓库根目录计算、测试路径与人类文档链接随迁移修正；不变更业务状态或原验收范围。

已经发放的五个独立任务包及其输入快照保持原字节。与本次路径修复发生差异的上游输入，显式解析到 `agent/archive/root-migration/modules-inputs/` 中迁移前原件；正在领取的任务须依据当前实现核对影响，不能把原输入当成迁移后的实现。没有差异的输入直接消费迁移后的权威文件。

这份说明只记录路径迁移；当前运行验证结果另见本批证据，不替代真实设备链、正式准入或研究结论。

T-02收到的P-01 golden生成器也因模块导入路径变化而保留原件，位置为`agent/archive/root-migration/modules-inputs/p01-golden-generator.py`。原快照的规范化字节已与迁移前提交核对；执行时仍使用P-01当前生成器，不运行归档副本。
