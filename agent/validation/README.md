# M09 验证与证据

本模块归档模块测试、同机闭环复核、数据字典、运行记录和阶段证据。当前目录中的历史方案与数据说明处于用户工作区调整状态，不在本次整理中恢复。

完整双真机系统验收的当前入口为[I-01任务工作单](../tasks/I-01/TASK.md)和[装配与外部测量交接](../tasks/I-01/outputs/current-integration.md)。本包仍等待真实链和外部门，已有模块签署不代表LIVE_E2E；其当前软件复测保存在Agent任务evidence，不另建泛化测试结果目录。

## 证据分层

| 层级 | 验证对象 | 建议位置 |
|---|---|---|
| 自动测试 | Python 采集、交互状态估计、通信与压力测试 | 各研发模块的 `tests/` |
| 接口复核 | UDP 字段、帧率、CSV 列与错误记录 | `实验数据/` 或后续测试报告目录 |
| 画面复核 | TD只读数值、Unity四天气Play Mode及Unity无TD运行 | 后续测试报告目录 |
| 阶段证据 | 截图、日志、表格和结论 | 对应日期的证据包 |

证据记录必须包含日期、版本或提交号、执行环境、命令或步骤、实际结果和剩余风险。未经复核的计划不得标记为已完成。
