# M01 需求与体验设计

本模块把项目定位转换为四种天气的交互与视觉规则，为 TD、Unity 和交互状态估计提供设计输入。

最新入口为[设计地基重构包](design-foundation-20261008/README.md)：三份LaTeX/PDF及先行推理。比较固定呼吸引导圈与预设场景变化（A），和数据驱动的场景原生自适应完整方案（B）。两组共享理想目标I；只有B根据实际呼吸X与场景状态受限调整实际引导G，再趋向I。按[一体化设计规范](项目质量与一体化交付规范.md)执行；本轮只设计，新条件未替代现行协议。

| 文件 | 用途 |
|---|---|
| `情绪天气方案/四种天气设计.md` | 四天气、呼吸策略、环境提示和核心视觉机制 |
| `创新点研究与文献支撑.md` | 历史假设，仅用于追溯；不得作为当前新颖性证据 |
| [W-01当前论文交接](../tasks/W-01/outputs/current-paper.md) | 当前最近工作、新颖性反证与论文证据入口 |

模块输出应让下游明确：天气类型、目标节律、唯一核心视觉机制、环境提示形式和恢复变化。消费级设备数据仅用于交互状态估计，不改变天气主题的选择逻辑。

当前主线见[实验设计论证](研究主旨与实验设计论证_当前.md)和[原创性与贡献论证](原创性与贡献论证_当前.md)，时间依据见[逐包完成时序](../work/2026-10-08_任务完成时序与研究主旨.md)。
当前任务体系已按新基线覆盖71包：[迁移范围与验收](../work/2026-10-08_新基线任务包迁移.md)。旧业务状态/签收保持，新增运行与研究须真实取证。
