\reviewsection{一、项目沿革与本轮裁定}
项目起点是可穿戴数据、呼吸练习与天气场景的交互方案。现有工程形成溪边木屋Storm、粒子双环和独立Actual接口；工程实现事实与整项研究贡献分别成立。上一轮基石将问题转成两种同源信息表示、以关键状态阅读错误率为主要候选，偏离了用户希望比较固定与数据驱动完整方案的核心。


本轮用户明确三点：只有原生组依据实际数据调节；共同理想目标节奏与固定组一致；允许根据场景/\allowbreak{}被试状态受限调整实际引导时序，然后回到理想节奏。该澄清是本次设计重构的依据，不是从现有代码或文献推断用户意图。


本包覆盖上一版SRP-\allowbreak{}INTERACTION-\allowbreak{}DESIGN-\allowbreak{}20261008候选，原三份制品与导航在本地agent/\allowbreak{}local/\allowbreak{}artifacts/\allowbreak{}design-\allowbreak{}foundation-\allowbreak{}20261008/\allowbreak{}before-\allowbreak{}fixed-\allowbreak{}adaptive-\allowbreak{}correction保存，可恢复但不作为活动设计。正式v1.2研究权威与历史签收不因本包变更；新条件不得自动套用旧冻结。


\reviewsection{二、先想清楚的五项决定}
K1 选择两臂完整方案问题。保留固定圈加有品质的预设场景作为A；B同时引入原生形式、真实反馈与受限适应。它回答实际采用问题。全因子能拆分机制但增加条件/\allowbreak{}样本；纯表示比较已不符合当前目标。


K2 分离I/\allowbreak{}G/\allowbreak{}X。共同理想目标I不随被试被改写；实际下发G可受限调整；实际呼吸X独立测量。场景状态规定合法动作与反馈范围，被试状态先采用可靠可读的呼吸及质量信息，不假设设备直接估计情绪。


K3 公平评价共同目标。跟上G是过程，接近I才支持共同练习达成；B不能靠放宽要求、更少机会或额外时间提高分数。旧固定Target机会PF须重审，质量不可观测不改记为行为错误。


K4 恢复用途对应的主要效益候选。推荐前测校正PANAS-\allowbreak{}NA后测，执行、负担与舒适分轴；量表适用及精度在正式前确认。取消跨组Actual读取主终点，A没有该信息，不能以同题排名制造B优势。


K5 收缩创新表述。八篇近邻已覆盖自适应、自然反馈和固定/\allowbreak{}反馈比较；候选增量为多步骤原生闭环的具体设计，以及支持、目标偏移、情绪和负担的可信权衡。未获得结果之前称设计候选，不称已证新颖或优效。
