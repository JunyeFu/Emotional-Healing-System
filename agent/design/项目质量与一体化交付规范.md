# SRP科研、产品与实践一体化设计规范

当前设计以[基石包](design-foundation-20261008/README.md)为入口。仅重构设计，不开发、招募、实验、报名或投稿；5人、半个月、指定两设备、100+是后续可行性资源，取消15天产品交付与Day2/5/8要求。

## 一、共同设计主旨

比较固定呼吸引导圈与预设场景变化（A），和数据驱动的场景原生自适应完整方案（B）。两组共享理想目标I；只有B根据实际呼吸X与场景状态受限调整实际引导G，再趋向I。

允许B的时序受限调整，不允许直接用信号推断情绪已经改善。每项产品功能说明用户收益、额外负担与取消条件；天气实例不各自宣称独立效果。保留Polar H10、PLUX respiBAN BLE、Unity 2022.3.62f3及当前视觉资产，实际接入与验收由后续任务完成。

## 二、不可混淆的设计要求

| 对象 | 本轮要求 |
|---|---|
| A固定方案 | 实际数据只用于测量；引导与场景按预设；不显示伪Actual环 |
| B原生自适应 | 以可信实际呼吸和场景状态决定有限调整；说明触发、上限、退出、恢复及失败呈现 |
| 理想与引导 | I、G、X分别定义；不能以放松G证明X更接近I |
| 等待与低质量 | 缓冲明确为自然呼吸；不无限憋停、不强迫漏补吸；低质量暂停适应，恢复后重新确认状态 |
| 情绪与功能 | PANAS主终点候选；共同I执行、跟随G、努力和不适分别检验；理解题不代证情绪收益或长期学习 |
| 时长与分母 | 两组共同固定预算；调整消耗预算；可观测覆盖、执行失败与缺失分开 |
| 原创性 | 八篇近邻定向全文对照；自适应和自然反馈已有先例，贡献依赖新增证据 |
| 资源 | 前置阶段与正式样本分别计数；排列数不代替样本依据，阈值无依据则待校准 |

## 三、验收与维护

七份LaTeX/PDF必须互相一致，主稿每项RQ有构念、条件、测量、分析和结论边界；附录列支持、跨情境假设与反证；决策表映射消费者。用原生更差、情绪无差异、信号不可识别、迁移失败和表面跟随改善但偏离共同目标检查解释边界。

标题及分级标题居中加粗黑体，正文微软雅黑，采用一、二及1.1、2.1层级。直接维护LaTeX并导出PDF，不新增DOCX。展示、产品和论文消费同一设计；工程完成、真实数据、研究结果与投稿证据分别陈述。

## 四、正式迁移边界

设计候选不替换现行v1.2协议。主终点、控制参数、随机化、教学、阶段规模和SAP由[决策影响表](design-foundation-20261008/03-decisions.pdf)中的消费者随后修订与冻结。本轮不改运行API、消息结构、任务状态、历史签收和领取快照，也不把现有固定Target测量直接当作适应条件的公平评价。

## 审稿攻击与修复判断

[原创性、贡献、社会价值与14项审稿攻击](design-foundation-20261008/04-review-audit.pdf)已形成；共同I是任务参照而非普适最优，同佩戴实验不证明现实部署净收益，期待与剂量属整包解释范围。设计缺陷已按主稿1.3、3.5、5.5、5.6修订；真实新颖性、可辨识性、用户价值与高等级发表能力尚未证实。
