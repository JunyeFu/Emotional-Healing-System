# A-03-SPEC Gate2联合测量与合成可行性规格 v1.0

## 1. 范围

本里程碑把F-02已签收的构念边界转成可执行计分、估计目标和有序联合门，并用合成数据检查当前设计是否存在明显的数值不可行性。它不使用真实参与数据，不冻结正式非劣界限、关键层、缺失规则或样本量，也不关闭A-03-REAL与A-03-CAL。

## 2. 构念分工

| 构念 | 用途 | 禁止替代 |
|---|---|---|
| SCCI四个序数项目 | 检查两种完整提示表示是否被感知为不同 | 不证明理解、努力或项目整体效果 |
| 四层理解八个二元项目 | 目标、实际、累计、降级信息的功能底线 | 不评价偏好或画面质量 |
| 心智努力单题 | 检查理解和跟随提示所需努力是否恶化 | 不与SCCI合成总分 |
| 客观阶段错误 | 防止主观结果遮蔽阶段错误 | 不替代理解题 |

SCCI、理解、心智努力和阶段错误始终独立计分、独立建模。主要模型至少包含`cue_mode`、中心化前测负性情绪得分和随机化分层因素。

## 3. 作答与缺失

作答状态固定为`RESPONDED`、`SKIPPED`、`TIMEOUT`、`TECH_UNPRESENTED`。`TECH_UNPRESENTED`表示题目对应信息因技术原因未呈现，必须排除并单独报告，不得写成答错。`SKIPPED`和`TIMEOUT`的正式处理规则等待Level B及盲态冻结；代码要求调用方显式选择合成分析策略，不提供隐式默认值。

合成验证并行使用：

- `PRIMARY_CONSERVATIVE`：`SKIPPED/TIMEOUT`在理解题中按错误处理，`TECH_UNPRESENTED`排除。
- `OBSERVED_CASE`：所有未作答项目排除，`TECH_UNPRESENTED`仍单列。

以上只是敏感性路径，不是正式缺失规则。

## 4. 有序联合门

判定顺序固定为：工具适用性、SCCI方向、理解总分非劣、预设关键层非劣、心智努力非劣、阶段错误保护。任一步失败或不可判定即停止，后续结果不得补偿。当前正式参数均为`PENDING_LEVEL_B_AND_BLIND_CALIBRATION`，因此在未提供冻结依据时，执行器返回`NOT_EVALUABLE`。

项目功能差异按累计logit候选模型检查条件效应及条件交互；同一项目审计家族使用Benjamini-Hochberg FDR。项目停用、分条件报告或保留必须记录原因码，不能在查看正式条件效果后无记录修改。

## 5. 合成Monte Carlo

固定种子`20260906`。先以每条件24人的小规模敏感性点检查联合门，再分别检查总控既有的每组85个完整四模块结果规划锚点，以及每组96人的均衡完整结果目标。85不是“上限”，96也不是A-03新冻结的正式样本量；总招募上限240包含非完整结果，不能被模拟成120/组完整结果。所有生成量均被约束在原量尺或比例范围内。场景覆盖目标差异、操纵为空、理解上限、差异性缺失和单项目偏移；每次复制只生成一份数据，并在同一份数据上运行两种分析集。

模拟阈值仅用于检查代码与设计的合成敏感性，明确标记为`synthetic_sensitivity_thresholds`。输出按`sensitivity_point`、`existing_planning_anchor`或`complete_target`标记；联合判定要求同一复制中的两个分析集同时通过。输出不得外推为正式把握度、真实校准、正式样本量或可发表结果。

## 6. 交接

- X-01可消费本规格、`estimands_v1.0.csv`、`estimands_v1.0.json`和合成边界报告，设计均衡随机化工具。
- A-03-REAL在A-01可用后接入真实数据，但不得覆盖本次合成输出。
- A-03-CAL在Level C盲态材料形成后冻结正式参数并重新运行联合功效分析。

当前里程碑进入复核只表示规格与合成流水线完成，不表示Gate2通过或研究设计状态解除。
