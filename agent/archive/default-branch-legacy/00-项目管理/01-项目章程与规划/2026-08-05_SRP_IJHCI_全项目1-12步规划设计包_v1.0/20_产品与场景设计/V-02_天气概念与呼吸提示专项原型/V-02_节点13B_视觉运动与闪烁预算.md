# V-02 节点13B：视觉运动与闪烁预算

> 状态：ACCEPTED
> 配置目标：`formal_frozen`
> 参数定义与冻结：V-03提出边界；U-03与U-08形成运行冻结证据

## 1. 禁止项

- 故意闪烁、频闪、闪电硬切、红色闪光；
- 全屏明暗、饱和度、缩放或脉冲随呼吸周期变化；
- 相机晃动、缩放、旋转、上下漂浮；
- 卷轴速度随呼吸、实际偏差、累计状态或场景身份变化；
- 高频前景对象持续扫过屏幕中心或当前提示区域。

## 2. 允许运动

| 对象 | 正式预算 |
|---|---|
| 世界卷轴 | 模块内恒定基础速度；四场景同一冻结值 |
| 天空 | 静止或接近静止，不形成周期运动 |
| 远、中、近景 | 最多三个低幅运动视差速度带，速度随深度单调变化 |
| 场景原生呼吸提示 | 只在目标与实际安全区内按共同相位语法运动 |
| 抽象双环呼吸提示 | 固定屏幕中心，只改变环形局部几何与可用程度 |
| 累计天气反馈 | 低频、有界、非周期变化，不表达当前步骤 |
| 转场 | 使用同一基础卷轴速度和缓变包络 |

资产仍可拆为天空、远景、中景、地面、前景和效果等多个文件层。多个资产层可以映射到同一运动速度带，但不得因素材数量增加新的高幅速度带。

## 3. 暂停语义

操作员暂停后，Unity必须冻结所有视觉时间源，包括卷轴、视差、粒子、提示、累计环境变化和转场。暂停期间不得由Unity本地时间继续推进任何可见状态；恢复后只消费会话权威继续提供的状态与时间。

## 4. 下游参数冻结要求

V-02不填写任意精确速度。V-03定义测量字段，U-03与U-08至少需要记录并审核：

```text
scroll_speed_px_per_second
far_parallax_factor
mid_parallax_factor
near_parallax_factor
max_cue_displacement_px
max_particle_speed_px_per_second
ambient_light_envelope_seconds
visual_profile_hash
```

参数必须结合实机分辨率、刷新率、观看距离、连续录像和人工反馈冻结。截图只能证明构图，不能单独证明运动预算。

## 5. 验收

1. 代码和配置中不存在故意闪烁或呼吸驱动全屏效果路径。
2. 正式配置最多启用三个运动视差速度带，且提示层不参与世界视差。
3. 四场景和两条件使用相同基础卷轴速度。
4. 暂停后逐帧对比确认所有视觉时间源停止推进。
5. 正式配置中的速度、系数和幅度均有U-03或U-08运行证据，不依赖Unity默认值。
