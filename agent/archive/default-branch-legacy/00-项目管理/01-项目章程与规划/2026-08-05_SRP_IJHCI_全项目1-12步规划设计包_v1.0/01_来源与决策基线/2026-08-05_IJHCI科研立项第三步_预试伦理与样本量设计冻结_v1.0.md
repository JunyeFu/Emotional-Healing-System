# 0. 本步骤最终冻结结果

## 0.1 研究性质

本研究属于：

> **以成年人为研究参与者，主动实施短时呼吸节律指导，采集呼吸、心电、心理量表和行为数据的非严肃健康应用人机交互研究。**

根据现行《涉及人的生命科学和医学研究伦理审查办法》，高等学校内使用人的生理、心理、行为和健康相关信息开展研究属于伦理审查范围；学术期刊发表相关成果时，研究者应当提供伦理批准证明。由于本研究包含主动呼吸任务并处理生理与心理数据，**不得按“公开数据或匿名既有数据研究”主张免除伦理审查**。 `[L]`

本项目可以向伦理委员会申请按**不大于最小风险研究**评估，并由委员会决定是否适用简易程序；项目组不得自行宣布“免伦理”或“自动属于简易审查”。 `[E]`

## 0.2 正式样本量

功效敏感性分析形成以下规划：

- Gate 1：`protocol_fidelity` 非劣性，在抽象条件基础比例0.75–0.90、场景原生真实损失0至5个百分点的模拟范围内，约需24–64名有效配对参与者；
- Gate 2：SCCI优效性若把最小关注效应冻结为配对标准化效应 `d_z = 0.35`，90%功效需要88名有效配对参与者；
- 预留15%不可用或未完成会话，并按 `AB/BA × 4种Williams序列 = 8个分配单元` 向上取整。

**正式招募目标冻结为：**

```text
计划招募：104人
目标有效配对样本：88人
每个分配单元：13人
```

Gate 2决定当前正式样本量。104人不是期刊门槛，也不是文献给出的固定数字，而是本研究的设计显著性、功效目标和损耗规则共同产生的规划值。 `[D]`

## 0.3 三级预试

- **Level A：专家内容与风险审查，8人**
- **Level B：认知理解与舒适性预试，12人**
- **Level C：真实设备双实验日技术预试，24人**

Level B和Level C参与者不得进入正式104人样本。

## 0.4 正式招募门

只有在以下条件全部满足后，才能开放正式招募：

1. 获得机构伦理批准；
2. Level A–C全部通过；
3. 四种呼吸结构的设备检测达到技术门；
4. SCCI条目完成内容效度、认知访谈和预试可靠性；
5. 非劣界值、主要分析和样本量写入预注册；
6. Unity、Python、TD和问卷版本冻结；
7. 研究人员完成SOP和紧急处置演练；
8. OSF或等效平台形成带时间戳、只读的预注册记录。

# 1. 伦理与法规依据

## 1.1 伦理审查必要性

本研究涉及：

- 主动引导参与者改变呼吸节律；
- 呼吸胸带和心电设备；
- PANAS及体验量表；
- 个体健康筛查和不适记录；
- 访谈或录音；
- 可识别招募联系方式。

这些内容属于以人为研究参与者、使用生理与心理行为信息开展的研究，应提交伦理审查。现行办法要求风险最小化、科学方案、知情同意、公平纳排、隐私保护、合理补偿和研究人员胜任。 `[L]`

## 1.2 敏感个人信息

《中华人民共和国个人信息保护法》把生物识别、医疗健康等列为敏感个人信息，并要求具有特定目的、充分必要性、严格保护措施，并取得单独同意。 `[L]`

本项目按敏感信息处理：

- 原始呼吸波形；
- ECG/RR间期；
- PANAS和不适记录；
- 健康筛查；
- 访谈音频；
- 姓名、手机、学号等联系方式。

因此知情同意中必须单独设置：

> **敏感个人信息处理同意项**

并说明：

- 为什么必须采集；
- 采集哪些字段；
- 谁能访问；
- 保存多久；
- 是否匿名共享；
- 退出后如何处理已采集数据；
- 对个人权益可能产生的影响。

## 1.3 伦理材料必须包含

对照官方审查要求，本研究提交包至少包括：

1. 完整研究方案；
2. 文献综述和科学性论证；
3. 知情同意书；
4. 敏感个人信息单独同意页；
5. 招募广告；
6. 纳排筛查表；
7. 研究人员资质与培训记录；
8. 设备清单、使用说明和风险说明；
9. 风险—受益分析；
10. 不良事件和中止SOP；
11. 数据管理计划；
12. 补偿与退出补偿规则；
13. 问卷版本、许可和计分说明；
14. 访谈提纲与录音说明；
15. 利益冲突声明；
16. 结果发布、数据共享和二次使用说明；
17. 预注册与研究变更管理方案；
18. 参与者投诉、研究者和伦理委员会联系方式。

# 2. 目标人群与招募

## 2.1 目标人群

第一篇论文的人群冻结为：

> **18–30岁的在校大学生，普通研究人群。**

这样做的理由：

- 与项目“普通大学生短时体验”目标一致；
- 排除未成年人监护同意问题；
- 减少年龄跨度对呼吸执行和可穿戴数据的异质性；
- 不把研究包装成严肃健康干预。

## 2.2 纳入标准

参与者必须同时满足：

1. 年龄18–30岁；
2. 当前为高等学校在校学生；
3. 能够阅读和理解中文研究材料；
4. 能够独立签署书面知情同意；
5. 能够平坐观看屏幕并完成两次实验；
6. 自述当前身体状态允许进行轻柔、非用力的短时呼吸指导；
7. 同意佩戴研究指定呼吸胸带和心电设备；
8. 同意研究处理所需的敏感个人信息；
9. 能在第一次实验后48小时至7天内完成第二次实验。

## 2.3 排除标准

以下标准是研究安全筛查，不构成个体健康判断：

1. 当前存在胸痛、明显呼吸困难、持续头晕、发热或急性呼吸道感染；
2. 过去7天内出现明显呼吸系统急性发作；
3. 已知存在未稳定控制的心血管或呼吸系统健康状况；
4. 曾因控制呼吸、屏息或关注呼吸出现晕厥、近晕厥或强烈惊恐；
5. 医师曾明确建议避免节律呼吸、屏息或类似练习；
6. 自述存在会被呼吸关注明显触发的恐慌症状；
7. 对胸带、心电带材料存在已知严重皮肤过敏或当前接触部位皮肤破损；
8. 有光敏性癫痫史，或对闪光画面有明确不适史；
9. 当前处于研究人员判断无法安全完成实验的状态；
10. 伦理委员会要求排除的其他情况。

说明：

- 稳定、无症状且未被医师限制的轻微既往状况是否纳入，以伦理批准版本为准；
- 药物、咖啡因、睡眠等不默认作为排除条件，但应记录并用于稳健性描述；
- 不因参与者的性别、学院、成绩或心理量表高低进行歧视性排除。

## 2.4 招募方式

允许：

- 校内邮件、公告栏和合规群聊；
- 学院或实验室统一招募页面；
- 公开自愿报名。

禁止：

- 任课教师直接要求自己所授课程学生参加；
- 把实验参与与课程成绩、评奖、导师关系绑定；
- 以“缓解焦虑”“显著疗愈”作为招募宣传；
- 隐瞒设备、呼吸任务或潜在不适；
- 通过过高报酬形成不当诱导。

## 2.5 补偿原则

建议区间：

```text
每次实验30–50元
两次合计60–100元
```

最终金额由预算和伦理批准决定。 `[D][E]`

冻结规则：

- 按完成的访视次数发放；
- 参与者中途退出，已完成访视仍获得对应补偿；
- 补偿不与“数据是否好看”“是否完成全部呼吸周期”挂钩；
- 因设备故障重约，不让参与者承担额外成本；
- 访谈子样本如额外占用时间，可增加固定补偿。

# 3. 风险控制

## 3.1 主要可预见风险

| 风险 | 可能来源 | 控制 |
|---|---|---|
| 头晕、麻刺、气短或过度通气不适 | 呼吸过深、过快或用力 | 强调轻柔自然，不追求深呼吸 |
| 屏息不适 | 风暴模块停顿 | 使用轻柔暂停，不做用力闭气 |
| 焦虑或惊恐 | 对呼吸高度关注 | 预筛查、随时退出、立即恢复自然呼吸 |
| 视觉不适 | 闪电、粒子、运动 | 无高频闪烁，预试亮度和运动强度 |
| 设备压迫或皮肤刺激 | 胸带/心电带 | 合适松紧、清洁材料、随时摘除 |
| 隐私泄露 | 生理、量表和访谈数据 | 分离身份映射、加密、最小权限 |
| 疲劳和学习效应 | 两次实验 | 间隔48小时至7天、条件平衡 |
| 误认为个体干预 | 项目叙事 | 明确为研究体验，不提供个体健康判断或个体干预 |

## 3.2 标准防过度通气说明

每次训练前逐字说明：

> “请按提示轻柔、自然地呼吸，不需要把每一口气吸得很深，也不要用力呼气。停顿只是舒适的短暂停留，不要憋气或用力。如果出现头晕、麻刺、胸闷、明显气短、惊慌或任何不适，请立即恢复自然呼吸并告诉研究人员。你可以随时停止，不会影响补偿或其他权益。”

已有实验显示，在0.1 Hz节律呼吸中加入“避免过深、保持浅而自然”的说明，可以减少呼气末二氧化碳下降和过度通气症状。 `[L]`

## 3.3 模块安全表达

### 风暴 `3-3-3-3`

- 停顿写作“舒适暂停”，不用“憋住”；
- 禁止用力闭气或Valsalva样动作；
- 参与者可跳过任何停顿并恢复自然呼吸；
- 若Level C显示停顿不适率较高，允许缩短参数，但必须在正式实验前重新冻结。

### 炙烤 `4-6`

- 不要求超大潮气量；
- 只要求呼气持续更长，不要求呼尽；
- 出现气不足时恢复自然呼吸。

### 暴雪 `5-5`

- 保持轻柔等时；
- 不要求每周期都精确达到5秒；
- 以可执行范围判定协议，不要求强迫跟随。

### 褪色循环叹息

- 第二次吸气是较短补吸，不要求最大吸气；
- 不进行快速连续过度换气；
- 若双吸引发明显头晕或不适，立即停止该模块；
- Level C未达到舒适和检测门时，正式研究不得保留当前协议。

## 3.4 个体中止规则

出现以下任一情况，立即停止当前提示并切换为静态中性画面：

- 参与者口头或手势要求停止；
- 明显头晕、近晕厥或失去平衡；
- 胸痛或明显胸闷；
- 严重呼吸困难；
- 强烈惊恐或无法继续；
- 持续恶心、剧烈头痛或明显麻刺；
- 皮肤强烈不适；
- 研究人员认为继续不安全。

处置顺序：

1. 停止实验刺激；
2. 提示恢复自然呼吸；
3. 保持坐位或安全体位；
4. 询问症状并记录时间；
5. 必要时解除设备；
6. 症状轻微且完全缓解后，由参与者决定是否结束；
7. 严重、持续或有意识障碍时，按校园紧急医疗流程处理；
8. 不允许研究人员以“数据已经快完成”为由劝其继续。

## 3.5 研究级暂停规则

出现以下任一情况，暂停新增参与者，提交项目负责人和伦理委员会评估：

1. 任何严重不良事件；
2. 两名以上参与者出现相似的中度以上呼吸相关不适；
3. 任一Level C或正式阶段的呼吸不适退出率达到10%；
4. 循环叹息模块出现集中不适；
5. 设备或视觉刺激被发现存在未申报风险；
6. 敏感数据泄露或身份映射错误；
7. 正式版本偏离伦理批准版本；
8. 研究人员未按SOP执行中止流程。

## 3.6 研究人员要求

现场至少一人必须：

- 完成项目SOP培训；
- 能识别过度通气常见症状；
- 熟悉校园急救和紧急联系方式；
- 能执行设备解除和中止流程；
- 不把研究设备输出当成个体健康判断。

建议至少一名核心执行人员接受基础急救培训。

# 4. 两实验日标准操作程序

## 4.1 访视前说明

参与者在实验前收到：

- 避免在实验前2小时进行剧烈运动；
- 避免在实验前2小时大量摄入咖啡因或尼古丁；
- 避免实验前1小时大量进食；
- 按平时规律用药，不得因研究自行停药；
- 若出现急性不适，应联系研究人员改期；
- 两次实验尽量安排在相近时间段。

上述因素主要用于提高过程数据可比性；未完全遵守不自动排除，但必须记录。

## 4.2 Session A流程

预计总时长：约45–55分钟。

| 环节 | 时长 | 内容 |
|---|---:|---|
| 到场确认 | 3–5分钟 | 身份、预约、当前不适 |
| 知情同意 | 8–10分钟 | 逐项说明、问答、签署 |
| 安全筛查 | 3–5分钟 | 纳排和访视当日状态 |
| 前测 | 3–5分钟 | PANAS及状态记录 |
| 设备佩戴 | 5–8分钟 | 呼吸胸带、心电带、信号检查 |
| 静坐基线 | 5分钟 | 自然呼吸，不给节律提示 |
| 标准化训练 | 5–8分钟 | 四协议示范、反过度通气说明 |
| 主体验 | 8分钟 | 四个120秒模块 |
| 后测 | 8–12分钟 | PANAS、SCCI、UES-SF等 |
| 设备解除和观察 | 3–5分钟 | 询问不适、清洁设备 |
| 第二次预约 | 2分钟 | 48小时至7天内 |

## 4.3 Session B流程

与Session A相同，但：

- 不重复完整知情同意，先确认研究内容和健康状态未发生变化；
- 若研究内容或风险发生实质变化，必须重新获取知情同意；
- 使用另一提示条件；
- 使用与Session A相同的四模块顺序；
- 完成后进入访谈抽样判断。

预计时长：

- 普通参与者：40–50分钟；
- 访谈子样本：额外15–25分钟。

## 4.4 基线记录

每次实验日保留5分钟自然呼吸静坐基线，用于：

- 信号质量检查；
- 个体内归一化；
- 心电次要过程分析；
- 识别异常漂移。

基线不用于改变当天实验条件，也不用于实时选择模块顺序。

## 4.5 随机分配

正式研究有8个分配单元：

```text
条件顺序：AB / BA
×
四种Williams模块序列
```

随机化规则：

- 使用计算机生成的固定随机种子；
- 采用可变区组或预先排列的平衡列表；
- 招募人员在知情同意前不知道分配；
- 分配表由不直接执行实验的人保管；
- 技术失败的替补参与者补入同一分配单元；
- 不根据PANAS、性别、学院或现场表现人工挑选条件。

## 4.6 参与者和分析人员盲法

参与者无法完全不知道界面差异，但研究说明中使用中性表述：

> “本研究比较两种呼吸信息呈现方式。”

不得称其中一种为：

- 新方法；
- 更自然的方法；
- 主要实验组；
- 预期更好的方案。

初始数据分析使用中性标签 `Condition X / Condition Y`；主要数据清洗和模型脚本冻结后再揭示条件含义。

## 5.1 样本

- HCI/交互研究：2人；
- 视觉或数字媒体设计：2人；
- 软件、实时系统或可穿戴：2人；
- 心理测量、呼吸生理或研究伦理：2人。

## 5.2 材料

- 第一、二、三步立项文件；
- 两条件视频或交互原型；

- SCCI条目；
- 非劣界值说明；
- 安全SOP；
- 数据字段和分析结构。

## 5.3 审查任务

1. 两条件是否等信息量；
2. 是否存在除提示载体之外的明显混杂；
3. 四模块目标、实际和累计三层是否可区分；
4. 呼吸协议是否清楚、可执行；

6. SCCI条目是否真正测量一致性；
7. 风险和中止规则是否充分；
8. 招募文案是否存在个体干预暗示。

## 5.4 通过标准

- SCCI每项 `I-CVI ≥ 0.78`；
- `S-CVI/Ave ≥ 0.90`；
- 至少6/8专家判断两条件没有关键混杂；
- 至少6/8专家接受 `ΔNI = 0.10` 或要求更严格；

# 8. 呼吸事件人工标注手册

## 8.1 目的

人工标注不是把研究人员主观感觉当作真值，而是用于：

- 验证事件检测算法；
- 估计时间误差；
- 识别胸带无法解析的结构；
- 建立不确定事件规则。

## 8.2 标注对象

Level C：

- 所有24人的两个实验日；
- 每个模块随机抽取不少于3个完整周期；
- 对发生算法不确定、降级或结构错误的周期全部标注。

正式研究：

- 随机抽取至少10%的会话；
- 所有重大异常会话；
- 所有算法版本变更前后的验证样本。

## 8.3 标注人员

- 两名独立标注员；
- 不知道提示条件真实名称，只看到X/Y标签；
- 先使用独立训练集训练；
- 正式标注前完成一致性门；
- 分歧由第三人或共识会议解决。

## 8.4 基础事件定义

以去漂移、平滑后的胸带扩张波形为依据：

| 事件 | 操作定义 |
|---|---|
| 吸气开始 | 波形从局部低点进入持续上升 |
| 吸气结束 | 上升结束并进入峰值、平台或下降 |
| 呼气开始 | 波形从峰值进入持续下降 |
| 呼气结束 | 下降结束并进入谷值、平台或上升 |
| 吸后停顿 | 峰值附近变化率持续低于阈值的稳定平台 |
| 呼后停顿 | 谷值附近变化率持续低于阈值的稳定平台 |
| 补吸 | 第一吸气后未出现完整呼气，出现第二次明确扩张 |
| 不确定事件 | 运动伪迹、基线漂移或结构不足以判定 |

具体导数、幅度和最短持续时间阈值由Level C冻结。

## 8.5 一致性指标

事件存在性：

- F1；
- 阳性一致率；
- 混淆矩阵。

事件时间：

- MAE；
- 中位绝对误差；
- 95%误差区间。

周期结构：

- `structure_ok`一致率；
- Cohen’s `κ`或适合的分类一致性指标。

不允许只报告相关系数，因为高相关不代表事件时间足够准确。

# 9. 数据质量和分析集

## 9.1 模块可分析标准

一个模块进入主要周期分析，至少满足：

1. `closed_loop`窗口中有效信号时长≥60秒；
2. 至少4个可分析目标周期；
3. 无整段错误版本或条件污染；
4. 目标事件日志完整；
5. 实际信号与Unity事件可以时间对齐。

## 9.2 会话完整标准

完整会话要求：

- 四个模块均满足模块可分析标准；
- 总有效主要窗口时长≥四模块总窗口的80%；
- 没有重大协议偏离；
- 没有用Mock替代真实信号；
- 条件版本正确。

## 9.3 分析集

### Full Analysis Set，FAS

包含：

- 已随机分配；
- 两个条件均至少有一个可分析模块；
- 没有撤回数据授权。

周期级模型使用所有符合质量门的周期，并显式建模模块和参与者。

### Per-Protocol Set，PPS

要求：

- 两个实验日均完成；
- 两个会话均达到完整标准；
- 时间间隔48小时至7天；
- 使用冻结版本；
- 无重大协议偏离。

### Safety Set

包含所有实际开始训练或体验的参与者，用于报告：

- 不适；
- 退出；
- 设备问题；
- 不良事件。

## 9.4 非劣结论规则

Gate 1只有在：

> **FAS和PPS均支持非劣**

时才能作为确认性结论。

如果只有一个分析集通过：

- 结果标记为不确定；
- 不得宣布非劣；
- 解释缺失、偏离或敏感性差异。

## 9.5 替补招募

预先冻结：

- 计划招募104人；
- 若在不查看条件效应的前提下，有效配对样本少于88人，可按原分配单元招募替补；
- 总招募上限120人；
- 替补依据只能是完成与数据质量，不得依据效果方向；
- 达到88个有效配对样本后停止替补；
- 若120人后仍不足88个有效配对样本，标记研究执行失败或功效不足，不继续无限招募。

```text
104人 × 2次 = 208次访视
```

若每次平均50分钟，加上10分钟清洁和准备：

```text
约208小时现场机时
```

两台独立设备并行且人员充足时，可缩短日历时间；但必须确保两套设备、版本和环境等价。

## 15.3 补偿预算示例

若每次：

- 30元：正式访视补偿约6240元；
- 40元：约8320元；
- 50元：约10400元。

另需计入：

- Level B和Level C补偿；
- 专家审查；
- 设备耗材；
- 清洁用品；
- 可能的设备备份；
- 软件和存储；

# 16. Go / Revise / No-Go门

## 16.1 GO

进入正式招募必须同时满足：

- 伦理批准；
- Level A–C通过；
- 104人方案和8单元随机化冻结；
- 真实设备不使用Mock；
- 三层视觉可区分；
- 四模块检测达标；
- SCCI可靠；
- 不适率达标；
- 预注册完成；
- 数据和版本锁定。

## 16.2 REVISE

出现以下情况，返回第二或第三步修改：

- 原生条件比抽象条件低超过15个百分点；
- SCCI测到的是喜欢而非一致性；
- 双环和原生提示信息量不等；
- 循环叹息无法稳定识别；
- 过度通气或不适率接近10%；
- 设备降级过多；
- 样本量模拟超过120人；
- 伦理委员会要求改变核心协议；
- 两实验日完成率不足85%。

## 16.3 NO-GO

以下情况暂停第一篇当前设计：

- 严重不良事件与研究任务有合理关联；
- 无法获得伦理批准；
- 无法合法取得或使用量表；
- 真实设备无法支持主要结果；
- 两条件不能只隔离提示载体；
- 项目预算无法支持最小样本；
- 正式分析无法保持FAS和PPS；
- 研究团队不能提供安全、隐私和版本控制。
