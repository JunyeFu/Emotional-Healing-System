# G-05 【外部准入】正式环境机构路径许可与U8实地闭环

> 项目注册表中的第58项。状态权威为上级目录`05_可领取任务包.csv`。

## 任务定位

- 领域：外部准入
- 波次：W3
- 状态：`WAIT_DEP_EXTERNAL`
- 类型：固定任务
- 预计工作量：5人日的项目内整理与核验；外部等待时间不计入
- 前置依赖：G-01、G-02
- 上游：G-01研究治理材料与G-02数据治理实现
- 下游硬门：E-01、G-03、W-03

## 交付物

1. 机构执行路径与待冻结字段回执。
2. M-001量表授权证据。
3. 真实团队角色和培训记录。
4. 正式专机六项配置通过报告。
5. 机构批准的数据保留期限。
6. Unity发布资产许可清零或替换证明。
7. 两周U8实地演练报告及`PASS/NO_GO`。
8. 下游准入签署矩阵。

## 执行过程

1. 汇总G-01/G-02开放项，给每项指定真实责任人、截止时间和证据格式。
2. 完成机构路径、授权、保留期限、人员角色和培训的外部确认。
3. 在正式机器完成六项配置，复扫Unity发布资产并关闭阻断项。
4. 执行两周U8演练，形成漏斗、故障、恢复和产能结论。
5. 双人复核全部原始回执和机器报告，签署下游准入矩阵。

## 验收要求

- [ ] AC1 机构执行路径、M-001授权、补偿、联系人、渠道、期限和角色培训均由真实责任人签署。
- [ ] AC2 正式专机六项配置全部通过，Unity发布资产的未知、未跟踪和阻断项清零或有已验证替换。
- [ ] AC3 两周实地演练覆盖完整漏斗、故障与恢复，给出U8 `PASS/NO_GO`，下游准入矩阵可追溯。

## 完成限制

仓库内模拟检查、合成fixture、计划文档或团队总监单独签字均不能替代真实外部回执、正式机器报告和实地演练。证据未齐时保持`WAIT_DEP_EXTERNAL`。
