# 华南理工大学人体伦理申报路径核验说明

> **SUPERSEDED / NOT_FOR_RECRUITMENT / NOT_FOR_SUBMISSION**
> 本v1.0材料仅作迁移与审计证据；它仍含旧流程和待关闭字段。必须完成G-01、双人逐字段复核及外部门禁后，才能使用新的v1.1材料。


## 1. 已从学校公开信息确认的内容

学校公开的科研项目通知表明：

1. 涉及人体伦理的项目需要提交伦理审查证明；
2. 2025年发布的2026年度广东省自然科学基金校内通知要求申请人联系学院科研秘书，根据指引在伦理系统提交；
3. 通知还说明，合作研究单位为医院的项目，其人体伦理证明由合作医院提供；
4. 学校其他科研通知同样要求在涉及人体伦理时提交审批表。

## 2. 公开信息不能证明的内容

上述通知属于基金申报场景，不能单独证明：

- 当前SRP项目应由哪一个伦理委员会审查；
- 本科生能否作为项目负责人提交；
- 是否必须以导师为项目负责人；
- 是否由学校委员会、附属医院或受委托委员会审查；
- 当前系统网址、账号申请、模板版本和收费情况；
- 是否可以先做Level A专家审查；
- Level B/C是否需要单独修订或一次性覆盖。

因此，本材料包不擅自填写伦理机构名称或批准编号。

## 3. 建议核验顺序

### 第一步：导师确认

由指导老师确认：

- 是否愿意担任伦理申请项目负责人；
- 研究经费和责任归属；
- 是否涉及合作医院或校医院；
- 设备、场地和紧急处置资源。

### 第二步：学院科研秘书

向软件学院科研秘书提交以下摘要：

- 研究标题；
- 两实验日交叉设计；
- 主动呼吸任务；
- 呼吸胸带和心电数据；
- PANAS和访谈；
- Level B 12人、Level C 24人、正式104人；
- 普通研究人群；
- 预计最小风险；
- 本材料包目录。

需要书面确认：

1. 当前人体伦理申请渠道；
2. 项目负责人的资格；
3. 系统账号和模板；
4. 是否需要附属医院接收；
5. 是否需校医院提供安全支持；
6. 是否需要先完成校级科研立项。

### 第三步：伦理办公室预咨询

在正式提交前询问：

- 研究是否可按不大于最小风险评估；
- 是否允许简易审查由委员会判断；
- Level A–C与正式研究能否在同一申请内覆盖；
- 是否接受电子知情同意或必须纸质签字；
- 敏感个人信息单独同意格式；
- 数据保存期限；
- 不良事件报告时限；
- 对学生招募和补偿的要求。

## 4. 对外联系用摘要

> 本研究比较两种呼吸信息呈现方式。18–30岁在校大学生将在两个实验日分别体验场景原生提示和统一抽象提示。每次核心体验8分钟，参与者全程平坐、无手部操作，跟随轻柔呼吸提示。研究使用呼吸胸带和心电设备记录过程数据，并完成PANAS和用户体验问卷。研究不提供个体健康判断或个体干预，设有健康筛查、反过度通气说明、中止规则、敏感信息分离存储和不良事件流程。计划开展12人认知预试、24人技术预试及104人正式实验。请确认本项目应通过何种机构和系统申请人体研究伦理审查。
