# 正反结果与论文写作模板 v1.2

所有句子为结果填充框架，禁止复制其中的假设情形为已观测事实。数值只从锁库分析输出读取。[C2,C3]

## 1. 六类结果，不是“成功/失败”二分

| 类别 | 需要的证据 | 可用句式 |
|---|---|---|
| 原生优势 | 情绪差异CI支持原生；重要性另查 | 本研究指定实现与人群中，原生方案的基线校正后负性情绪更低；其实际意义为…… |
| 抽象优势 | 情绪差异CI支持抽象；重要性另查 | 本研究短时使用条件下，抽象方案更有利；不外推为全部显式提示优越 |
| 小差异/区间足够窄 | 事前关注界限与精度证据 | 差异区间落在预先关注的较小范围；若未启用等效，不称确认性等效 |
| 实用等效 | 事前设计的等效规则与相应区间 | 在预先定义的界限和方法下支持实际等效；不是普通p≥.05 |
| 不确定 | CI仍容许重要差异 | 当前精度不足以区分有价值的收益或损害；不能推荐某臂情绪更好 |
| 研究效度受损 | 构建、测量或交付证据指明局限 | 结果描述实际分配与交付，但不足以裁定理想原生设计方向 |

“统计显著但差异很小”可与“位于实用界限内”并存；分开报告统计方向与价值，不强行给出赢家。

## 2. 功能与情绪交叉

原生情绪占优、功能通过：可讨论有条件的原生采用收益。

原生情绪占优、功能受损：报告取舍，不宣称更好的呼吸指导工具；检查是否由任务弱化或理解失败形成不同实际体验。

抽象情绪占优、原生负担更高：可提出“短时部署应优先保障即时可理解”的有边界设计推论；过程关联不自动证明机制。

功能通过、情绪不确定：支持功能可替代性，不支持情绪额外收益。

两组共同前后下降、无可靠组差：只能报告观察到的变化和组间证据精度；不能据此证明整个系统的绝对因果作用。

## 3. 统一主稿结构

Introduction：短时情绪调节中的提示设计问题与竞争性预期。

Related Work：自然/呼吸反馈、表示组织与短时使用；逐项对比，区分摘要、全文和演示证据。

Design：两完整方案、四层与步骤身份、教学预算、形成性修订、替代解释。

Study：随机分配、隐藏、量表/设备分工、主要估计目标、功效、缺失与锁定。

Results：样本流与交付质量 → 主要情绪估计及区间 → 功能护栏 → 理解与负担 → 全部预设敏感性/失败 → 可选扩展。

Discussion：收益与代价、适用边界、设计知识与下一步问题。反向结果不改题，不事后添加“隐藏性”理论。

Limitations：一次使用、指定人群、完整方案混杂、量表敏感性、缺失与精度、无绝对作用对照、不能外推长期。

Transparency：伦理/同意、预注册及偏离、作者贡献、AI辅助用途、数据代码与许可。各项按真实证据填写。

## 4. 必须准备的表图（不是本包生成的实验图）

样本与缺失流图；两条件设计矩阵；主要beta与CI；四模块PF/关键错误；缺失与敏感性；设计规则与反例；可选策略支持与结果。

图表来自真实锁库脚本，禁止生成图替代研究截图或实验结果。示意图应明确标示示意，实际界面取已冻结构建。

## 5. 结果前与结果后写作

结果前完成题目候选、问题、相关工作、设计、方法、空表格规格与每类结论模板。结果后只填锁定结果与其允许的结论；不得以不显著为由更换主指标、挑选天气、调整入组或删除扩展。

独立复核人核对：每个主张→数据版本→分析脚本→表图→适用边界。AI可检查一致性与来源，不能代签真实作者、机构或外部专家。
