## 1. 为什么这一步不能由项目组自行跨过

当前研究主动引导呼吸，并采集呼吸、心电、心理量表和访谈数据。它需要机构伦理审查，但公开网页只能证明华南理工大学在具体科研项目申报中存在人体伦理办理路径，不能自动证明：

- 本科SRP研究由哪一个委员会受理；
- 本科生能否作为伦理申请负责人；
- 是否必须由导师担任项目负责人；
- 是否由附属第二医院、学校其他委员会或合作医院审查；
- 当前伦理系统链接、账号申请和模板版本；
- Level A、Level B、Level C与正式研究能否一次性覆盖。

因此，第六步不是继续推演实验，而是取得**书面或可审计的机构路由确认**。

## 3. 近期校级公开流程的意义

科学技术研究院2025年省市联合基金通知明确：

- 涉及人体伦理的项目应尽快联系学院科研秘书；
- 该次申报使用伦理系统；
- 该批次由附属二院统一审批；
- 合作医院项目可由合作医院提供伦理证明。

这证明“学院科研秘书是正确入口”，但这是**特定基金批次**流程，不能直接复制为本科SRP常规研究流程。

## 4. 本步唯一完成标准

取得以下五项确认：

1. 谁作为伦理申请项目负责人；
2. 哪个伦理委员会受理；
3. 使用哪个系统和哪套模板；
4. Level A/B/C/正式研究如何覆盖；
5. 伦理批准前允许开展哪些活动。

在此之前：

- 可继续软件开发、离线测试和Mock联调；
- 可准备专家审查材料；
- 不得招募Level B、Level C或正式参与者；
- 不得把未批准的专家/学生数据写入论文实证结果。
