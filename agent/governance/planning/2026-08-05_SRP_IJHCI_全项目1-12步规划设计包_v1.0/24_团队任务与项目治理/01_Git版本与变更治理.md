# Git、版本和变更治理

## 项目目录

唯一有效项目目录：`D:\Agent\03-SRP`。

## 每个任务

1. `git status --short`
2. 阅读`AGENTS.md`
3. 建分支或按项目规则工作
4. 实现
5. 测试
6. 更新文档
7. commit
8. push

## 版本对象

- 研究协议；
- Unity；
- Python；
- TD；
- 设备配置；
- 检测算法；
- 问卷；
- 数据Schema；
- 分析计划；
- 数据集。

## 变更等级

- MAJOR：改变构念、条件、风险或主要算法；
- MINOR：兼容新增；
- PATCH：不改变结果语义的修复。

正式采集中的MAJOR/MINOR变化需暂停并评估伦理和预注册修订。
