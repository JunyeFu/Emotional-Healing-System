# V-04 H3固定镜头高精度背景生图提示词 v1.0

## 用途

生成四天气统一美术方向的四联预览图。四联图只用于团队总监选择，不能直接切片或导入正式Unity构建。

## 共同提示词

```text
生成一张2x2四联环境概念图，左上storm、右上heat、左下snow、右下fade。四格采用统一的高精度3D游戏环境美术语言：高面数自然环境、精细PBR材质、清楚的前中远景、克制体积光、低刺激电影级调色。每格都是完整的16:9固定镜头，35mm等效视角，地平线约为画面高度59%，没有横向滚动、相机运动或速度暗示。

storm：风雨隘口，中右侧有自然雨幕廊道，左下低遮挡；不出现闪电。
heat：热浪盐原，细致盐壳和远山，中右侧有冷流路径，左下低遮挡；热霭轻微且非周期。
snow：雪雾松林，清楚树线和林间空地，中右侧有枝头与地表锚点，左下低遮挡；不得白化失去细节。
fade：雨后原生全彩湿地，主水道从中远景弯向右下并离开画面，左侧中景支流清楚汇入；水面连续开放。

目标安全区x=0.55-0.85、y=0.34-0.72，实际安全区x=0.20-0.45、y=0.18-0.52；两区不得被持续高对比物占据，但不要画出辅助线。

禁止人物、动物、建筑、桥、文字、标签、Logo、水印、UI、HUD、圆环、箭头、呼吸符号、发光提示路径、传送门、奖励特效、周期脉冲、霓虹、强暗角、恐怖氛围、运动模糊、速度线、横向卷轴构图。不得把目标、实际、累计状态或fade复色过程烘焙进背景。
```

## 三组风格变量

| 组 | 追加提示 |
|---|---|
| A | 写实电影级PBR与自然光照，接近高端写实游戏环境渲染，综合色彩克制，材质真实性优先 |
| B | 东方自然山水构图、明亮而丰富的自然色、略艺术化的高端3D写实，轮廓优雅且不照片化 |
| C | 面向实时Unity制作的高端3D关卡美术，模块化轮廓、清楚深度层、稳定中间调和可拆层锚点优先 |

## 选择后单图要求

选择完成后，每个天气单独生成一张16:9背景，不沿用四联图裁切。单图应保持所选组的材质、光照、镜头高度、地平线和综合色彩；目标、实际、累计状态与局部环境效果继续独立制作。
