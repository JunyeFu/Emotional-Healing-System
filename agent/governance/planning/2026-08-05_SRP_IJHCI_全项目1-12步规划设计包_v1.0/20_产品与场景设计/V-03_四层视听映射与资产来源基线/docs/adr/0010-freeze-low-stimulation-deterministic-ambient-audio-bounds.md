# 冻结低刺激确定性环境母带候选边界

每个天气只使用非节律环境母带，声音不得响应目标、实际、累计环境状态或降级类别。综合响度候选范围为`-24至-20 LUFS-I`，真实峰值不高于`-3 dBTP`，场景与中性雾廊之间使用`2–4 s`候选交叉淡化。优先制作覆盖完整模块的母带；必须循环时使用不少于`60 s`的无缝循环，循环点不得与呼吸周期对齐。声音从模块相对时间零确定性播放，不生成运行期随机事件；暂停冻结播放位置并停止输出，恢复后从冻结位置继续。同一天气的两种提示条件必须使用相同文件、哈希、起点、循环、响度和包络。精确值由U-03与U-08测量证据冻结。
