# V-02 节点15A：两级形成性评审结构

> 状态：SUPERSEDED
> 用途：已废止的设计修改与U-03切片评审候选
> 禁止用途：项目整体效果分析

> 历史说明：用户随后将V-02收口于场景确认。本规格不再执行，也不继续节点15B；详见`ADR-026_V-02收口于场景确认.md`。

## 1. 第一门：专家检查

| 检查角色 | 主要检查对象 |
|---|---|
| 视觉设计 | 场景身份、构图、提示显著度、遮挡、风格连续性 |
| Unity实现 | 分层、视差、动态效果、暂停、性能和证据可实现性 |
| 实验设计 | 两条件边界、事件真值匹配、额外线索和潜在混杂 |

输入至少包括四天气关键帧、两条件静态对照、提示共同语法、节点13预算和节点14资产路线。每条问题记录严重度、证据位置、责任人、处理结论和复核人。

P0或P1问题未关闭时，不得启动外部观看评审。

## 2. 第二门：未参与设计人员观看评审

输入原计划为U-03最高风险切片在相同Unity构建、视觉配置、音频配置和显示条件下录制的两种提示条件短片。顺序分配方法、人数、问题和阈值曾计划由节点15B冻结，但该节点现已移出V-02。

观看期间：

- 不显示按钮、选择题或设置；
- 不要求语言、手势或其他实时回应；
- 不暂停解释目标与真实实际；
- 不由评审人员改变音量、卷轴或提示参数；
- 技术故障由操作员中止并登记，不让观看者自行处理。

全部理解题、观看感受题和开放反馈在短片结束后完成。

## 3. 暴露流程

```text
跨阶段检查
  -> 形成性评审预约
  -> 首次展示前登记暴露
  -> 播放短片
  -> 观看后反馈
  -> 永久排除正式样本
```

只要首次展示已经发生，即使中途退出或技术故障，也不得释放并重新进入后续正式样本。

## 4. 输出

- 专家检查问题单和关闭记录；
- Unity构建、视觉配置、音频配置与短片哈希；
- 外部观看者暴露登记证明；
- 观看后回答与匿名开放反馈；
- 按问题类别形成的V-03设计或U-03实现返工清单；
- 继续、返工或停止扩展的门控结论。

## 5. 边界

形成性评审不得与正式实验数据合并，不填写前后情绪量表，不进行项目整体效果检验。其贡献是减少设计错误和条件混杂风险，而不是提供论文主要结果。
