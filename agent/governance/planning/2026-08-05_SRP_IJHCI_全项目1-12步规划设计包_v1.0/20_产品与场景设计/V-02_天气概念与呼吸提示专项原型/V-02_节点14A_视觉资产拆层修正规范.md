# V-02 节点14A：视觉资产拆层修正规范

> 状态：ACCEPTED_CONSTRAINT
> 操作参考：`$srp-unity-production-guide`
> 参数定义与冻结：V-03提出边界；U-03依据切片证据冻结

## 1. 从底稿到Unity候选资产

1. 建立场景分层源文件和完整合成预览。
2. 固定公共画布、坐标原点、地平线和全部提示安全区。
3. 修补被拆层对象后方原本被遮挡的像素，避免视差移动时出现空洞。
4. 扩展长卷轴左右重叠区，并制作拼接预览检查接缝。
5. 将前景遮挡、效果遮罩和语义视觉从背景中分离。
6. 在公共画布下独立导出PNG，禁止自动裁边。
7. 生成合成、接缝、遮挡和运动参考预览。
8. 填写资产清单并形成独立提交包；验收后才允许导入Unity权威工程。

## 2. 候选分层

| 深度或功能 | 建议标识 | 主要内容 |
|---|---|---|
| 天空 | `bg_sky` | 天空底色，不含周期提示 |
| 远层天气 | `bg_clouds_far` | 远云、远雾或远处天气轮廓 |
| 远景 | `bg_landscape_far` | 远山、林线、远岸 |
| 稀疏地标 | `bg_landmark_far` | 石门、驿亭、木桥、栈道或界碑单体 |
| 中景 | `mg_environment` | 主要地貌、植被和场景结构 |
| 地面 | `ground_strip` | 路径、水岸、盐原或雪地连续带 |
| 前景遮挡 | `fg_occluders` | 不穿越提示安全区的近景对象 |
| 效果遮罩 | `fx_masks` | 雾、热霭、雨、粉雪、色潮等独立遮罩 |
| 语义视觉 | `semantic_*` | 目标、真实实际、累计、降级分别管理 |

同一深度可以包含多个资产层，但运行时最多映射到节点13B允许的远、中、近三个运动视差速度带。深度分层和`target/actual/recovery/fallback/background`语义分类必须分别记录。

## 3. 预览要求

- `composite_preview`：全部层按公共原点合成；
- `seam_preview`：长卷轴尾部与下一段头部左右拼接；
- `safe_area_preview`：标出目标、真实实际、双环和前景遮挡禁区；
- `parallax_preview`：展示远、中、近三个候选速度带的实际位移；
- `motion_reference`：GIF或MP4展示局部提示、天气效果和暂停行为。

预览中的安全区线框、标签和调试标记不得烘焙进Unity运行资产。

## 4. 提交结构

```text
SRP_UnityAsset_<scene>_<version>/
  source/
  export/
  preview/
  asset_manifest.csv
```

提交包不能直接覆盖Unity `Assets`。Agent先检查文件、清单、来源、许可、原点、接缝和预览，再决定接受、退回或导入。

## 5. 拒收条件

- 层被自动裁边，无法按公共原点复原；
- 拆层后暴露透明空洞、重复边缘或明显补绘断层；
- 左右接缝在候选卷轴运动中可见；
- 目标、真实实际、累计或降级效果被烘焙进背景；
- 前景持续遮挡提示安全区；
- 缺少可编辑源文件、预览、作者、来源、许可、版本或哈希；
- 套用像素画历史参数而未经过F-03工程基线和U-03切片验证。
