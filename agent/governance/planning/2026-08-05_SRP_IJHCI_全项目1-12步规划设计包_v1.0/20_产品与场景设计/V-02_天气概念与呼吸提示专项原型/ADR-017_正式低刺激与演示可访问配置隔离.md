# ADR-017 正式低刺激与演示可访问配置隔离

- 状态：ACCEPTED
- 日期：2026-08-19 +08:00
- 决策人：傅钧烨
- 适用任务：V-02至V-05、F-01 v2.2、U-03至U-08及实验运行

## 决策

1. 正式实验统一使用`formal_frozen`低刺激配置，参与者不操作设置。
2. 正式会话中不得改变卷轴、视差、粒子、音量、亮度或提示尺寸；操作员只保留暂停和中止能力。
3. 独立的`demo_accessible`配置允许在展览或技术演示开始前降低运动和音量，但不得生成正式数据或证据。
4. 每次会话记录视觉配置ID、版本和哈希；正式条件间必须一致。
5. 配置缺失、未知或哈希不匹配时正式启动失败关闭。
6. v2.2或配套manifest升级需显式携带视觉配置身份，不以Unity本地默认值代替可审计配置。

## 结果

- 视觉与声音候选预算由节点13后续子决策及V-03/V-04设计材料提出，运行参数由U-03切片与U-08组合验证冻结。
- 演示配置的可调性不构成正式材料的经验依据。
