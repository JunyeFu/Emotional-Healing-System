# ADR-006 热浪盐原与冷流风道

- 状态：ACCEPTED
- 日期：2026-08-18 +08:00
- 决策人：傅钧烨
- 适用任务：V-02至V-05、U-03至U-08

## 决策

1. `heat`技术ID的可见环境采用“热浪盐原”。
2. 唯一核心机制采用“冷流风道”。
3. 场景原生条件以前方中远景冷流表达目标：4秒吸气阶段向上汇集、展开，6秒呼气阶段收窄、下降并贴地长距离推进。
4. 近场冷流痕迹独立表达实际相位、进度与可用程度，不吸附或修正目标。
5. 基础热浪保持非周期性；累计状态只缓慢改变全局热霭和远景清晰度。
6. 抽象条件关闭冷流的相位动画，目标与实际由双环表达，背景不得泄露4秒或6秒周期。
7. 具体输入、动画关系、降级和生图分层边界以`V-02_节点6_热浪盐原与冷流风道规格.md`为准。

## 结果

- 延长呼气由更长运动持续时间和前向行程表达，不依赖文字、亮度奖励、音效或卷轴加速。
- V-03必须定义4秒与6秒目标fixture及实际层不同步用例；U-03或对应天气实现包负责运行验证。
- V-04必须检查长呼气不会诱导用力，以及抽象条件不存在环境节律泄露。
- V-05及Unity任务必须证明暂停、恢复、重置和条件切换没有冷流残留。
