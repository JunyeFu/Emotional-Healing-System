# ADR-011 山雾长廊统一转场

- 状态：ACCEPTED
- 日期：2026-08-19 +08:00
- 决策人：傅钧烨
- 适用任务：V-02至V-05、P-01后续适配、U-02至U-08

## 决策

1. 任意两个环境之间统一使用“山雾长廊 + 无字界碑”，不制作12种两两专属转场。
2. 转场按约30%退出当前场景、40%中性山雾、30%显现下一场景中性基线组织，V-03给出参数候选，V-05灰盒验证后冻结。
3. 当前累计状态先锁定，目标和实际提示退场；下一模块开始前不得启动下一场景提示。
4. 下一场景只来自Python顺序权威和经验证的manifest，Unity不得自行选择或推断。
5. 两提示条件的转场视觉、声音、速度、时长和加载时点完全一致。
6. 最后模块复用相同退出和山雾段，随后进入统一结束基线。

## 结果

- 四个场景分别实现统一退出、重置和显现接口即可覆盖全部顺序。
- 转场不建立天气之间的因果故事，不继承前一模块的世界坐标、提示或累计状态。
- V-03必须形成12种有向组合和4种最终退出的设计矩阵；V-05和后续Unity任务以录像、事件日志和帧时间验证。
