# V-02 节点10：demo提示引入规格

> 状态：ACCEPTED
> 适用条件：`scene_native`与`abstract_pacer`
> 数据原则：真实实际数据始终记录，呈现按周期分阶段引入

## 1. 时间语法

1. 每个模块从目标周期起点进入`demo`。
2. 第一个完整目标周期只显示目标提示，实际提示保持不可见。
3. 当`target_cycle_index`进入第二周期时，真实实际提示以冻结短过渡淡入。
4. 第二周期起，目标与实际同时显示并持续到闭环结束或降级规则触发。
5. `demo -> closed_loop`不重置目标周期、步骤或进度，即使段边界落在周期中间也连续播放。
6. `demo`期间`RecoveryState`保持模块基线；进入`closed_loop`后才接受累计状态可见更新。

## 2. 数据与接口

- 真实实际数据从模块开始即采集、形成交互状态估计并写入日志；
- 第一周期只隐藏实际可见层，不停止采集、不填零、不改写为目标值；
- 禁止使用Mock、脚本化完美实际或目标复制作为演示；
- 实际层首次可见时直接使用当时的自包含实际步骤、周期、进度和置信信息，不回放第一周期；
- 输入不可用时按`FallbackState`呈现，不用合成实际填补；
- 两条件使用相同`target_cycle_index`边界和淡入配置。

## 3. 参与者可见内容

- 不显示阶段文字、数字倒计时、操作说明或条件身份；
- 不使用目标周期完成音、实际层出现音或奖励效果；
- 场景原生条件淡入近景实际层，抽象条件淡入内环；
- 第一周期结束不触发累计环境变化。

## 4. 验收

1. 四模块均从目标周期起点进入demo。
2. 第一完整周期录像中只有目标提示，实际数据日志仍连续存在。
3. 第二周期边界后实际层使用真实自包含帧淡入，无Mock或目标复制。
4. demo与closed_loop边界不造成目标步骤、周期或进度跳变。
5. 两条件实际首次可见时间、淡入长度和事件真值一致。
6. 输入不可用时实际层不出现，目标继续并记录降级原因。
