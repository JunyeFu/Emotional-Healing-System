# M00 项目管理

本模块维护项目范围、进度、风险、质量门禁和角色交接，不承载运行时代码。

| 子目录 | 职责 | 当前入口 |
|---|---|---|
| `项目规约/` | 项目说明、角色交接、文档基线 | `SRP项目规划书_李俊扬组_v2.1.docx` |
| `01-项目章程与规划/` | 阶段规划与交付范围 | `开发规划表.md` |
| `03-进度跟踪/` | 过程记录 | `开发进度打卡表.md` |
| `04-风险管理/` | 风险、影响、应对与状态 | `风险登记册.md` |
| `05-质量门禁/` | 各阶段验收标准 | `质量门禁体系.md` |
| `看板与进度/` | 当前状态、短期队列、整理记录 | `当前阶段看板.md` |

当前状态由任务注册表维护，看板与任务图消费同一份注册表；历史决策保留日期和依据，完成状态必须关联验证与真实签收范围。
