# 统计分析与结果分类合同 v1.2

**性质：可用于预注册准备的最终讨论稿，不是已注册SAP。** 空缺必须由盲态数据、测量证据和真实资源补齐。源自当前v1.1及第二、三轮讨论；新增算法细节标为本包操作化。[R2,C2,C3]

## 1. 估计目标

总体：符合事先冻结纳排条件、完成准备后进入随机分配的研究对象。目标人群具体界限与招募来源需机构确认，不用临时情绪筛选制造有利样本。

处理：`scene_native`相对`abstract_pacer`的完整表示方案分配。为避免把受条件影响的训练后得分当无干预基线，本包建议在PANAS前测之后才揭示并开始分条件教学；共同中立准备可在此前。这是封包交叉审计提出的显式时序修订，尚需X-01/UP-04/UP-11与机构材料冻结，不能称三轮已逐项确认。对应估计目标是相同预算教学加核心体验的短时部署包；不通过调整可能受条件影响的训练后量表来声称孤立核心体验的因果效应。[OP1]

结果：同版本中文版20项PANAS中10项负性情绪分量表的体验后得分。中文题项、计分范围、缺题规则与“此刻”框架须核对来源和许可；本包不分发未获授权的题项。

差值方向固定：

```text
beta = E[NA_post | native, baseline-adjusted]
     - E[NA_post | abstract, baseline-adjusted]
beta < 0：原生方案负性情绪更低
beta > 0：抽象方案负性情绪更低
描述性变化 Delta_NA = NA_pre - NA_post
```

拟定主要模型：

```text
NA_post ~ cue_mode + centered_NA_pre + prespecified_randomization_strata
```

参与者是主要分析单位；拟沿用线性ANCOVA与HC3稳健方差。实际模型应通过有界分布、地板效应、小样本行为和缺失模拟验证。24顺序不作为24水平主要处理；位置与转换仅作预设支持性或探索分析。[R2]

## 2. 唯一主要确认性检验与区间

主检验拟为双侧alpha=0.05，报告beta、标准误、95%置信区间、精确p值和分析人数。不比较两组各自显著性标签；“一组显著、另一组不显著”不是组间差证据。

功能非劣为单独护栏。情绪比较必须计算和完整报告，不因SCCI或PF失败而跳过。一次性能同时通过情绪价值与功能底线的联合部署主张，应单独模拟其成功概率；不能把多个单项90%相乘前假定独立或视为总体90%。

## 3. 实际意义与等效不是同一层结果

`minimum_important_affect_difference`目前为null。必须用量尺精度、情境价值、资源与专家/使用者判断在看正式条件差前冻结，不能由现有N倒推，也不能用未经核验的MCID。

默认只做主要双侧差异推断和区间精度分析。**确认性等效主张默认未启用。** 第三轮认可的是等效与未显著不同，并未冻结等效界或多重声明策略。

如需启用等效研究，须在正式数据前修订并冻结：上下界、界值依据、检验方法、alpha、区间对应关系、缺失敏感性、样本量与多重声明控制。标准TOST在每个单侧alpha=.05时对应90%CI；95%CI完全落入界限是更严格的充分证据条件，二者不得在代码中互换后仍报同一功效。[M2]

本包分类器输出两个正交标签，而不是一个强行互斥的“赢家”：

| 方向证据，基于95%CI[L,U] | 标签 |
|---|---|
| U < 0 | NATIVE_LOWER |
| L > 0 | ABSTRACT_LOWER |
| 其他 | NO_DIRECTION_ESTABLISHED |

| 实际尺度，delta已事前冻结 | 标签 |
|---|---|
| U < -delta | NATIVE_IMPORTANT_BENEFIT_SUPPORTED |
| L > delta | ABSTRACT_IMPORTANT_BENEFIT_SUPPORTED |
| -delta < L且U < delta | WITHIN_PRESPECIFIED_PRACTICAL_BOUNDS |
| 其他 | IMPORTANT_EFFECT_NOT_EXCLUDED |

当delta未冻结时，只报告方向与区间，不生成等效或重要性判断。“统计可辨的小差异”与“区间在实用界限内”可以同时出现。默认`formal_equivalence_claim_allowed=false`，即使区间位于界内也不能把描述性标签写成已预注册的确认性等效成功。边界相等按未跨越处理。

## 4. 分析集、退出、缺失与技术问题

主要情绪分析以全部随机分配对象为目标；执行偏离、学习困难或呼吸信号失效不自动删除其有效PANAS。设备过程缺失与量表缺失分开编码。

拟沿用100次有界多重插补作为候选实现，插补变量包括条件、基线、分层及预设缺失预测量；不把post-treatment PF放进主要因果结果模型作为“控制变量”。插补与Rubin合并、稳健方差、得分边界和MNAR偏移的完整实现仍属A-02/A-03任务。本包没有实现正式统计流水线。

退出后可按同意规则邀请填写即时结果，但不得强迫。撤回、无法提供、技术未呈现、跳过、超时分别编码；无获批使用依据的数据不得为了ITT而强行保留。处理顺序与时间窗口须预注册。

报告全体随机对象流图、分析人数、每条件缺失原因、完整案例敏感性、有界插补、MNAR偏移/tipping point；敏感性改变结论时明确“方向对假设敏感”，不选最有利版本。

## 5. 执行质量护栏

保留机会分母：COMPLIANT、NONCOMPLIANT、TECH_UNOBSERVABLE。技术不可观测不能从分母静默消失，也不能直接等价为生理失败。保留总体四模块等权PF及可观测PF、机会完成率、保守复合PF并列报告。[C1,R2]

原非劣界0.075作为继承候选，在v1.2中仍需确认合理性。比较差`PF_native-PF_abstract`，95%CI下界严格大于-0.075才满足对应非劣条件；两分析集要求及缺失处理须与正式SAP一致。

总体平均非劣不代表每个模块都非劣。预先定义步骤级关键错误与模块损害护栏；不为所有模块追加无依据的确认性检验，也不将总体通过写成逐模块通过。

非劣失败、严重错误或不适可以否定部署推荐，但不是隐去情绪结果的理由。逆向推荐抽象方案也不能仅依赖原生没有通过非劣；须有对应结果与完整风险解释。

## 6. 操纵、机制与研究效度

SCCI仅为操纵检查。小SCCI差或不显著不能自动作废整个随机比较；应描述实现对比与感知差异是否形成。技术链错误、两臂未按合同呈现、量表无效等可能限制概念解释，须由预先定义的证据判定，不能因为结果不合预期才宣告操纵失败。

注意、控制感、努力与执行是过程证据；事后相关或显著中介模型不自动证明因果机制。固定教学预算下得到的是部署包效果；训练到同等熟练再比较是另一估计目标。[C2,C3,M3]

## 7. 功效与停止

Level C锚点48、阶段一完整结果192/初始招募上限240均来自旧方案；不构成v1.2功效证明。按新的PANAS差异与功能护栏联合可行性重新模拟。[R2]

盲态预试用于估计方差、相关、缺失、地板、时长；最小关注效应来自独立论证，不拿预试最有利差异当真实效应。模拟必须覆盖零效应、原生有益、抽象有益、小而可辨差异、实用等效、较大不确定性和差异性缺失，报告Monte Carlo误差。

正式停止按冻结的随机分配数量或事前批准的盲态样本重估规则，不按p值、排名或“完整者刚好补齐”停止。平衡针对分配，不针对观察完整结果。不得裁剪完成者填满24顺序格。
