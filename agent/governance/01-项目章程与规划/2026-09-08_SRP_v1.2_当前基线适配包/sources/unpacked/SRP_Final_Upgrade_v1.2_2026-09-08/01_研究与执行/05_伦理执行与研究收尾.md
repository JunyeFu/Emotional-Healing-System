# 伦理、执行与收尾合同 v1.2

本文件是三轮讨论的执行要求汇总，不是新的法律意见或已获机构审批。第一轮提出的具体政策适用性问题留给G-05及机构核验；不凭“非医疗”命名自认豁免。[C1,R3]

## 1. 按活动范围准入

建议分别记录静态/回放专家活动、认知预试、真实设备预试、正式随机研究与公开发布的批准范围。已获某类范围不代表其他范围也获准；材料齐备不代表审批通过。

UP-05用于早期研究的真实准入；G-05保留正式机构路径、量表许可、环境、数据期限、资产许可与U8责任。该拆分让理论反证前移，但不降低真实参与者保护。

## 2. 参与者保护

无手部操作不是无退出权；保留口头退出、实验员中止和已批准的记录办法。具体不适与停止条件由研究负责人/适用专业人员批准，不由动画通过、Agent签字或本包自行推定。

补偿不绑定“跟对呼吸”“完成全部模块”或“产生有利结果”。说明两条件中立，不预告原生必然更放松。不得为了制造效果擅自加入情绪诱发、高强度呼吸或新的筛选门槛。

## 3. 隐私与权限

联系方式、身份映射、密钥、原始生理记录与公开派生数据分层管理。HMAC用于去重，不把它等同整套数据匿名化。保留期限、撤回/删除、备份恢复和对外共享须与真实同意及机构要求一致。

不可变L0是审计设计，不是无限保留的授权。对撤回/删除的合规处理需有受控日志、权限和可验证流程，不能手工删CSV后失去追踪，也不能无条件保留。

## 4. 采集执行

本包提出的待冻结时序：准备与设备质量检查 → 资格/同意与共同中立说明 → PANAS前测 → 隐藏规则下分配揭示 → 相同预算的分条件教学 → 四模块800秒 → PANAS后测 → SCCI、理解、努力等 → 条件/目的猜测 → 子样本访谈。

该修订明确回应封包交叉审计：条件特有教学不能在无说明情况下先于主要协变量测量，随后又把该协变量称作未受干预的基线。若坚持分条件教学在前，须重新论证估计目标与识别，不能仅靠术语修饰解决。[OP1]

上列为流程组成；分配产生、保管、揭示的精确时点由X-01与机构材料共同冻结。不得因本流程概括而覆盖具体隐藏合同。

按批次进行哈希、设备、构建、问卷、偏离与暴露状态QC；不读取组间效果决定继续。对技术缺失照常尽可能记录合规的量表结果。记录每人只参与一次与跨阶段去重。

## 5. 锁库与揭盲

冻结版本和原因码 → 样本/暴露去重 → 按预定义规则处理排除与缺失 → 盲态偏离签署 → 数据/脚本/构建哈希 → 揭盲授权 → 主要及全部预设分析 → 敏感性 → 独立复现 → 主张审计。

如果在完成正式分析之前因安全或资源停止：保留实际样本流与停止原因，不能补写成完整研究，也不能因结果方向不利而取消披露。

## 6. 核心与扩展收尾

CORE_ONLY：阶段一分析与设计证据支持一份完整核心稿；不依赖E-06。

CORE_PLUS_EXTENSION：须另有策略冻结、支持、独立确认与扩展分析；不把同一批数据同时用来选策略和确认优效。

EXTENSION_PARTIAL/STOPPED：披露已做部分、停止原因、样本和分析状态；不改成NOT_RUN。策略等于均匀回退且没有新的合理比较问题时，不为凑三阶段再做重复的大样本。

## 7. 最终成果与责任

交付制品、研究数据字典、代码、锁定分析、完整稿、许可/伦理/作者声明和可交接资料。论文录用、专利授权及外部批准属于外部结果，不纳入Agent可保证的完成条件。
