# 联系导师与科研秘书的正式询问稿

## 版本A：发给指导老师

**主题：申请确认SRP人体伦理负责人和校内申报路径**

老师您好：

我们正在将SRP项目按IJHCI人机交互实证论文标准重构。研究计划比较两种呼吸视觉提示方式，参与者为18–30岁在校大学生，每人完成两次实验；研究将采集呼吸胸带、心电、PANAS和体验问卷数据。

目前已经完成：

- 研究问题与对照条件；
- 三级预试和104人正式样本量规划；
- 风险筛查和中止规则；
- 知情同意、敏感信息同意和数据管理草案；
- Unity/Python/TD实施架构与数据契约。

由于研究涉及主动呼吸任务和敏感生理、心理数据，正式招募前必须获得人体研究伦理批准。想请您确认：

1. 您是否同意并具备资格担任伦理申请项目负责人？
2. 是否同意由我整理材料、您审核并承担项目负责人职责？
3. 是否同意我们联系软件学院科研秘书确认当前受理委员会和系统？
4. 设计学院成员应作为校内合作成员还是共同研究人员填写？
5. 在伦理批准前，是否仅开展软件开发、离线测试和Mock联调？

我已准备一页项目摘要和伦理材料目录，确认后即可向学院咨询。

谢谢老师。

## 版本B：发给学院科研秘书

**主题：咨询本科SRP人体研究伦理审查受理路径**

陈老师您好：

我是软件学院本科生，正在指导老师带领下开展SRP研究。项目拟形成IJHCI人机交互论文，研究内容为比较两种呼吸视觉提示方式。

研究概况：

- 参与者：18–30岁在校大学生，普通研究人群；
- 设计：两实验日、参与者内随机交叉；
- 任务：平坐观看8分钟天气场景并跟随轻柔呼吸提示；
- 数据：呼吸胸带、心电、PANAS和用户体验问卷；
- 阶段：12人认知预试、24人技术预试、计划104人正式实验；
- 风险：可能短暂头晕、气短或不适，已有筛查、中止和数据保护方案；
- 研究不提供个体健康判断或个体干预。

学校公开的2025年省市联合基金通知提到，通过学院科研秘书进入人体伦理系统，并由附属二院统一审批；但我们理解该流程可能只适用于该基金批次，因此希望确认本项目当前应走的正式路径。

烦请确认：

1. 本科SRP人体研究由哪个伦理委员会受理？
2. 项目负责人是否必须为校内教师或指导老师？
3. 当前伦理系统入口和申请账号如何获得？
4. 使用哪一版申请书、知情同意和数据材料模板？
5. Level A专家审查、Level B/C预试和正式研究能否在同一申请中覆盖？
6. 是否可以申请按不大于最小风险评估，具体审查类型由委员会决定？
7. 若附属二院不受理非医院场地、无医院合作的研究，应联系哪个机构？
8. 预计审查周期、会议频率和是否收费？
9. 设计学院共同研究成员在申请中如何填写？
10. 伦理批准前允许开展哪些非参与者活动？

我们已经准备完整草案，可按学院要求提交审阅。

感谢指导。
