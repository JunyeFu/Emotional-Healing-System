# 数据安全与权限

## 角色

| 角色 | 身份信息 | 原始生理 | 派生数据 | 揭盲 |
|---|---|---|---|---|
| 项目负责人 | 受控 | 受控 | 是 | 批准后 |
| 主实验员 | 最小 | 必要 | 否 | 否 |
| 数据管理员 | 映射表 | 是 | 是 | 否 |
| 设计成员 | 否 | 否 | 去标识化 | 否 |
| 分析人员 | 否 | 去标识化 | 是 | 锁库后 |
| 展示人员 | 否 | 否 | 汇总 | 否 |

## 规则

- 身份映射与研究数据分离；
- 磁盘加密；
- 不用公共网盘；
- 不通过聊天软件传原始数据；
- 不输入未经批准的外部AI；
- 下载和导出有审计；
- 公开前重识别风险评估。
