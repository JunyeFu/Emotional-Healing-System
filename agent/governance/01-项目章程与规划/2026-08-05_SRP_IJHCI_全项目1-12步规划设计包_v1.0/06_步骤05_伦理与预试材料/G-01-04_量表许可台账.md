### M-002：SCCI 场景融合操纵检查

| 项目 | 内容 |
| :--- | :--- |
| **量具名称** | Scene-Cue Congruence Index（场景—提示融合操纵检查） |
| **类型** | 自建工具（候选） |
| **题项数** | 4题（主候选：S1–S4） |
| **量尺** | 5点（1=非常不同意 至 5=非常同意） |

| **核验状态** | `CANDIDATE` |
| **备注** | 禁止加入“容易、清楚、有效、成功、喜欢、舒适”等评价表述；正式条件效果查看前冻结主计分 |

## 五、台账维护规则

1. **本台账是候选状态**，不代表任何量具已获得最终许可或已通过验证；
2. 任一量具的 `核验状态` 为 `PENDING` 时，**不得**将其用于正式数据采集；
3. M-001（PANAS）许可核验是 **U5 测量门的组成部分**，未完成时 **不启动阶段一**；
4. 自建工具（M-002 至 M-006）须在 **查看条件效果前** 完成全部验证和计分规则冻结；
5. 状态变更需记录日期、证据和责任人签名。
