# SRP任务拆分双向覆盖审计 v2

> 审计日期：2026-08-06；Unity流程订正：2026-08-18
> 结论：原37个固定任务包适合启动工程，但不足以组成规划中的项目完整体。v2先扩展为48个固定任务包和3个可重复批次模板；Unity从零设计复核后补入V-01至V-05五个必要前期门，V-02复核再补入F-05相位实例v2.2合同升级门，G-01/G-02签收后补入G-05外部准入闭环，审计升级再补入A-06研究范围关闭门，当前为56个固定包和3个模板。

## 1. 审计方法

### 正向审计

从每个无依赖任务出发，检查其输出是否经明确依赖进入纵向实现、集成候选、技术预试、正式阶段、锁定分析、论文和成果交接。没有下游消费者的任务视为孤立产出。

### 反向审计

从最终完整体反推以下不可缺少的成果，再确认每项都有任务、输入、过程、客观验收和证据：

1. Unity独立完成四场景与抽象条件的完整参与者体验；
2. 两台真实设备、Python权威会话、在线交互状态估计、不可变记录和重放；
3. TD只读操作台；
4. Level A/B/C、两个正式阶段、阶段二冻结策略和三重证据门；
5. 数据治理、许可、预注册、构建锁定和偏离记录；
6. 自动图表、完整分析报告、单篇IJHCI稿件、投稿包、复现包和成果交接。

| 学习入口缺失 | 新成员不知道补齐技能的最短路径 | 每包绑定已核验的国内中文学习资料编号 |

## 3. v2规模裁定

### 全部登记项按波次：59条

- W0基础合同：4个；
- W1公共骨架、治理与Unity前期设计：13个；
- W2全旅程灰盒与纵向实现：16个；

- W4外部门禁与技术预试关闭：5个；

其中固定任务包56个，可重复批次模板3个：

- `B-01`：Level C会话批次，每实例最多12人、1至5人日；
- `B-02`：阶段一正式会话批次，每实例最多12人、1至5人日；
- `B-03`：阶段三正式会话批次，每实例最多12人、1至5人日。

模板本身不因完成一个实例而标记`DONE`。关闭任务必须核对全部实例、目标样本、顺序/条件平衡、偏离与数据校验和。

## 5. 正向装配门

```text
W0 合同/测量/Unity工程与测试构建基线/TD骨架
 -> W1 Python会话/记录/传输/治理 + Unity体验/概念/映射/分镜 + 可靠通信/四层接口
 -> W2 设备/估计/全旅程灰盒/最高风险纵向切片/其余Unity适配/分析基础
 -> W3 无TD真机E2E/研究工具/随机化/策略工具/复现候选
 -> W4 Level A/B/C与阶段一预注册锁定
 -> W5 阶段一批次与Gate1/2/策略冻结/条件式阶段三/研究范围关闭
 -> W6 论文稿件/投稿复现包/成果交接
```

每一波必须消费上一波的版本化输出。`07_validate_task_packages.py`验证依赖无环、任务可达最终交接、标题领域、过程配置、学习资料、验收条款和证据字段；它不能替代真实设备、人工复核或外部阶段证据。

Unity内部采用“设计主线与技术支撑汇合”的装配门：`V-01 -> V-02 -> V-03 -> V-04 -> V-05 -> U-03 -> U-04/U-05/U-06/U-07 -> U-08 -> I-01`；F-03、U-01和U-02分别在V-05或U-03前提供工程、传输和场景接口。U-01显式等待P-01签收，I-01显式等待P-02签收；这两个依赖分别保证控制权威和不可覆盖记录进入全链路。阶段定义、证据和资产通道见[F-03 Unity场景设计与渐进制品任务协调计划](F-03_Unity场景设计与渐进制品任务协调计划_v2.0.md)。

## 7. 合理性结论

原37包的工程模块划分方向正确，Python、Unity、TD、设备和离线分析的主要职责边界也合理；第一轮问题是后半段被过度压缩，第二轮问题是Unity从工程迁移直接跳到场景生产。当前划分保留深模块接口，同时把跨角色交接、批次执行、最终成果、五个Unity前期设计门、相位实例v2.2迁移门以及研究范围关闭补成可验收任务。因此59条登记项比37个固定包更符合四人团队、短周期独立领取和最终项目完整体三个约束。固定包通常为1至5人日；P-01因会话权威、本机传输与正式门一体化，V-04因五十节拍、确定性中保真预演、完整声音、候选制品与双层复核一体化，均经专项复核设为6人日，不再拆成可独立签收但无法保持单一权威的浅层包。

升级后为56个固定包、3个模板。五个V包分别拥有体验旅程、概念与提示比较、映射合同、分镜声音预演和全旅程灰盒，不与U系列实现包重复；F-05独立关闭`storm`双停与`fade`双吸的步骤身份及消费者迁移缺口；G-05独立关闭正式环境、机构路径、资产许可和U8实地演练；A-06在阶段一主论文与条件式阶段三之间如实关闭研究范围。该划分减少后续返工，没有把正式场景生产提前。
