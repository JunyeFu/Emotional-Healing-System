# 离线处理总设计

## 目标

离线系统是正式科研制品：原件不可覆盖，派生结果可重建，人工标注可审计，分析总体可复验，图表数字来自冻结输出，异常与负结果不被隐藏。

## 重建根：完整原始证据束

正式重建输入不只是L0设备波形，必须包括：

| 原件 | 内容 |
|---|---|
| 设备原件 | P-02 L0字节包、缺包、样本计数、设备与主机时间、配置 |
| 运行事实 | P-02 L1控制、操作、策略、ACK、渲染回执、在线质量和时钟记录 |
| 问卷原件 | 量尺和题项版本、实际作答、时间框架、缺答和时间点 |
| 分配原件 | 随机化身份、清单、隐藏、揭示和暴露记录的不透明引用 |
| 标注原件 | 人工事件和周期标签、盲态、争议及裁定；无需标注也显式说明 |
| 协议与构建 | 冻结规则、算法、参数、模型、环境、构建和资产用途指纹 |

联系方式、HMAC密钥和身份映射不进入分析包。受限原件通过批准路径和不透明引用访问。

## 原始事实与派生层

P-02物理L0/L1保持不变。L1含不可再生的在线事实，不能宣称全部由L0和代码重算。

```text
完整原始证据束
  -> offline_derived/L1同步与SQI视图
  -> offline_derived/L2事件、周期和目标机会
  -> offline_derived/L3模块与参与者摘要
  -> L4冻结分析总体与数据
  -> L5模型、敏感性、表图和复现报告
```

离线重新估计值与当时运行记录使用不同命名空间；二者可比较，但不能互相覆盖。

## 处理顺序

1. 验证全部原件清单、字节哈希、访问资格、协议和代码版本。
2. 检查P-02完整性和封存；中断记录不冒充完整体验。
3. 读取设备流、事件、呈现、问卷与分配原件，建立统一时间轴及同步不确定性。
4. 计算冻结SQI、事件和周期，合并版本化人工标注，不修改原始流。
5. 从目标协议生成应有机会，处理段边界、部分周期、暂停和技术不可观测。
6. 计算模块PF及预设辅助指标，按冻结缺失规则保留随机化总体和完整四模块集。
7. 独立计分PANAS和Gate2工具，不与设备结果加权成一个总结果。
8. 构建L3/L4并锁定输入与排除原因，运行冻结分析。
9. 输出带`result_id`和`input_identity`的表图，供稿件读取。

## 重建承诺

只有取得指定完整原始证据束、合法依赖、冻结代码和环境后，才能重建声明范围内的派生结果。缺少问卷、回执、分配或标注时必须明确阻断，不能以默认值、模拟值或重新生成的分配补齐。

每个派生结果记录原件byte SHA-256、代码提交、配置、环境、随机种子、实际命令和输出哈希。规范化文本哈希可用于源码比较，不能冒充原件或二进制哈希。

A-01必须覆盖以下负测：相同波形但问卷、回执或分配不同产生不同输入指纹；缺问卷不生成完整NA；技术不可观测不从机会分母静默消失；重放不连接设备或重复登记暴露。

## 论文出口

A-05产生阶段一锁定结果。A-04保留已实施阶段三的最终分析。A-06依据分配、暴露、批次和结果事实关闭实际研究范围，使阶段一主论文可独立收尾，并确保已启动阶段三不能被省略。
