## 1. 裁定原则

V-04只解决进入Unity制作前必须看见的问题：四个天气的核心画面机制、两种提示方案、模块时序和通用转场是否可理解、可制作。论文所需证据来自正式Unity运行和实验数据，不来自一条800秒预演视频。

因此：

1. 保留V-03的目标、实际、累计、降级四类信息，不新增第五类协议字段。
2. 两条件共享事件真值、时长、天气背景、累计变化、声音和转场；目标与实际的可见组织允许不同。
3. V-04制作短样片和分镜，不重复实现最终Unity制品。
4. 只保留会改变实验处理或Unity实现的检查，不做与研究结论无关的媒体治理工程。

## 2. fade冲突裁定

| 冲突 | 裁定 |
|---|---|
| 整屏必须从完全褪色恢复到原生颜色，但`recovery_value`不能补到1 | 整屏复色归入共享背景时间动画，不表示累计结果；`recovery_value`继续只控制轮廓、纹理和能见度等慢变量 |
| 整屏变化若跟随呼吸步骤，会让abstract条件也获得场景阶段提示 | 整屏复色只随模块有效进度前进，不在步骤边界变速、回退或换色 |
| 网页报告建议新增`module_envelope_u` | 拒绝。V-04不修改F-01 Schema；预演按既有模块/段时间计算，Unity运行绑定由后续接口任务处理 |
| 网页报告建议CIELAB、PCHIP和多项色度阈值 | 拒绝。Unity采用一条全屏饱和度曲线，从完全褪色恢复到原生色板，以首帧、末帧和连续观看确认 |
| candidate-v7只在局部先褪色再恢复 | 拒绝candidate-v7。candidate-v8必须让scene_native和abstract_pacer两幅完整画面都从完全褪色开始并恢复 |
| 完全复色可能被理解为实际累计完成 | 复色不显示数值、奖励或完成提示；累计层仍按真实`recovery_value`独立变化 |

### 2.1 整屏复色

- fade首个参与者可见帧：整幅画面完全褪色，包括场景原生提示和抽象双环。
- 整屏复色进度：`color_u = SmoothStep(0, 1, min(module_progress / 0.95, 1))`。
- `module_progress`由现有段事件、段时长和有效单调时间换算，不新增协议字段，也不改变Python的会话时间权威；暂停时冻结。
- 模块最后约5%的有效时间保持原生颜色。
- 不使用红蓝阶段滤镜，不在`INHALE_1/INHALE_2/EXHALE_1`边界改变整屏复色速度。
- Unity实现优先使用一条全屏饱和度参数，从`-100`插值到`0`；不为V-04开发专用色彩空间算法。

### 2.2 呼吸提示

| 步骤 | `scene_native`目标提示 | `scene_native`实际提示 | `abstract_pacer` |
|---|---|---|---|
| `INHALE_1` | 中远景水道光流第一次汇集 | 近景色丝按实际步骤汇集 | 外环第一次扩张；内环显示实际 |
| `INHALE_2` | 从当前状态继续第二次短汇集，不回零 | 仅识别到实际补吸时出现第二段 | 外环继续短扩张；内环按实际显示 |
| `EXHALE_1` | 汇集结果沿水道缓慢释放 | 近景色丝按实际长呼展开 | 外环长收缩；内环按实际显示 |

上述提示主要依靠位置、方向、长度和轮廓变化识别。整屏复色只是两条件共享的场景进程，不承担当前步骤或实际表现。

## 4. 声音与工具

- 每个天气和长廊使用一条30-60秒可循环临时环境声，两条件复用同一文件和音量。
- 声音不随呼吸步骤、实际输入或累计值变化。
- H2/H3只检查循环接缝、突发峰值、条件一致和持续观看是否明显干扰；正式音量校准留给Unity预试。
- 继续使用现有Python/Pillow/FFmpeg生成短样片，不再扩建独立确定性媒体生产系统。
- 既有工具锁继续作为G-02开发工具许可证据保留，但不作为H2视觉结论或后续长媒体生产要求。

## 5. candidate-v8

candidate-v8是新的H2对象，十秒仅压缩展示设计关系：

| 时间 | 画面要求 |
|---:|---|
| `0.0 s` | 两条件整幅画面完全褪色，提示已经可通过轮廓辨认 |
| `0.0-2.5 s` | `INHALE_1`提示运行；整屏按统一曲线缓慢复色 |
| `2.5-4.0 s` | `INHALE_2`不回零；整屏曲线不在2.5秒变速 |
| `4.0-9.5 s` | `EXHALE_1`提示运行；整屏继续同一曲线 |
| `9.5-10.0 s` | 整幅画面保持原生颜色 |

H2只检查：

1. 第一帧是否完全褪色且无彩色闪现；
2. 最后0.5秒是否完整恢复原生颜色；
3. 整屏变化是否连续，没有红蓝滤镜或呼吸边界跳变；
4. 两条件除目标/实际提示组织外是否一致；
5. scene_native三步骤是否可辨，abstract双环是否可辨；
6. 卷动与声音是否平稳。
