# V-02 节点14B：Agent可执行视觉资产流水线

> 状态：ACCEPTED；职责边界由V02-D-014B2补充
> 运行时权威：独立PNG底板与组合清单
> 可选人工源：PSB

## 1. 流水线

```text
场景规格与风格锚点
  -> 关键帧候选
  -> 人工裁定关键帧
  -> 从后向前独立制作全画布底板
  -> 长卷轴逐层扩展
  -> 本地确定性标准化与预览
  -> AI局部编辑或重新生成
  -> 连续失败时人工问题修整门
  -> PNG与清单冻结
  -> Unity独立装配
  -> 截图、录像、接缝与性能验证
```

关键帧只回答“最终方向是什么”，不直接成为运行资产，也不自动切割为最终图层。

## 2. 每个天气的生成顺序

1. `keyframe_composite`：冻结地平线、主轮廓、稀疏地标、安全区和颜色关系；
2. `bg_sky`：完整无前景天空底板；
3. `bg_weather_far`：远云、远雾或远天气层；
4. `bg_landscape_far`：远山、林线、远岸和稀疏远地标；
5. `mg_environment`：中景地貌、植被与主要环境结构；
6. `ground_strip`：连续路径、水岸、盐原或雪地；
7. `fg_occluders`：受提示安全区约束的近景遮挡；
8. `fx_masks`：供Unity材质或粒子使用的中性透明遮罩。

每一步都以上一轮已接受参考图为输入，但不得把目标、真实实际、累计或降级状态画入底板。

## 3. Agent本地处理

Agent使用已提供的图像工具生成和编辑候选，使用Pillow与NumPy执行：

- RGBA与颜色模式统一；
- 公共画布、原点和导出尺寸检查；
- 透明边缘、全透明空洞和越界像素检查；
- 左右重叠区差异图和拼接预览；
- 全层合成预览与安全区叠加预览；
- 文件命名、SHA-256哈希和`asset_manifest.csv`生成；
- `composition.json`和可重建预览脚本验证。

自动检查只能发现技术问题，不能替代人工对透视、材质连续性和整体美术质量的审查。

AI负责常规拆层生产、返工和技术检查。人工不逐层参与，只裁定关键帧、验收最终Unity运动录像，并在AI连续返工仍失败时处理疑难区域。Krita不是必装工具。

## 4. 运行时交付结构

```text
SRP_UnityAsset_<scene>_<version>/
  source/
    layers/
    composition.json
    rebuild_preview.py
    optional_master.psb
  export/
    <full-canvas PNG layers>
  preview/
    keyframe.png
    composite.png
    seam.png
    safe-area.png
    parallax.mp4
  asset_manifest.csv
```

`optional_master.psb`不存在时不阻断Agent流水线，但`source/layers`、组合清单和重建脚本缺失时必须拒收。

## 5. Unity导入策略

- 默认导入冻结的独立PNG，不依赖PSB的混合模式、透明度或图层效果；
- 每个PNG按背景、语义角色和视差速度带显式挂载；
- 导入设置由U-03按目标显示与内存测量冻结，不沿用旧`.meta`不一致值；
- PSB Importer `13.0.3`只用于U-03对照验证和可选编辑预览；
- Unity截图必须与冻结合成预览比较，发现对位、颜色或透明差异时不得继续批量生产。

## 6. 首个切片

V-03不得把风险排序扩张为四天气实现；它只选择一个同时覆盖长卷轴、前景遮挡、局部效果和提示安全区的最高风险天气。U-03完成从关键帧到Unity录像的闭环，通过后才复制流水线。

## 7. 验收

1. 关键帧没有被直接当作运行时长卷轴。
2. 每个运行PNG都有源层、清单、版本、来源和哈希映射。
3. 全部底板可由`composition.json`重建为与冻结预览一致的静态合成。
4. 长卷轴逐层接缝、透明边缘和遮挡后区域通过技术检查与人工审查。
5. Unity内截图与冻结预览的差异可解释，且不存在导入器造成的未登记变化。
6. 语义视觉可独立关闭，天气底板不泄露当前呼吸步骤。
