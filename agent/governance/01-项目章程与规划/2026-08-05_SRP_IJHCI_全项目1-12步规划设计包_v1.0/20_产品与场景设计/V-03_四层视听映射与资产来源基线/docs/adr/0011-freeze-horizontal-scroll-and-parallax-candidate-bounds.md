# 冻结横向卷轴与视差候选边界

正式方向采用固定观察者构图下的相机横向自动前进：相机只改变横向位置，高度、旋转、正交尺寸、地平线和提示安全区保持固定。基础速度候选为`0.015–0.025屏宽/秒`，首选`0.02屏宽/秒`；按候选`1920×1080`换算为`28.8–48 px/s`，首选`38.4 px/s`，运行证据必须同时记录分辨率和像素速度。天空严格静止，其他背景层最多归入远、中、近三个表观卷轴速度带，因子依次为`0.30–0.45`、`0.60–0.80`和`1.00`。多个素材层可以共用速度带，提示层不参与世界视差。四种天气及两种提示条件共用同一基础速度，天气身份、目标、实际和累计环境状态均不得改变速度。暂停冻结所有视觉时间源。精确值由U-03的视差预览、接缝录像和暂停逐帧证据冻结，并由U-08联合验证；像素画候选默认值不进入本轮高分辨率分层插画方向。
