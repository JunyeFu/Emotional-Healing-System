# 采用确定性分段长卷轴资产

近景、地面和主要中景使用固定顺序的分段条带，不采用单张巨型运行纹理、短周期可见循环或运行期随机重排。按最大候选模块时长`220 s`、最大候选基础速度`0.025屏宽/秒`和一个首屏视口计算，净覆盖至少为`6.5屏宽`，加入接缝余量后的候选有效覆盖不得低于`6.75屏宽`。首版建议四段、每段原始宽度不超过`2屏宽`，相邻段保留`0.10–0.15屏宽`重叠；按候选`1920×1080`换算为`192–288 px`。天空保持静止，远景可使用较短的确定性无缝条带，但完整模块内不得出现容易识别的重复地标。所有段共用画布原点、地平线和提示安全区，拆层后补齐遮挡后方且禁止自动裁边。F-03冻结纹理与内存拆分，U-03以静态拼接预览和完整时长滚动录像冻结最终段数；可见接缝、透明空洞或明显重复均判为不通过。
