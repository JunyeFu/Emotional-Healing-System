# U12-02 步骤实例测量候选

## 边界

消费已签收F-05 v2.2与F-02四层构念，新增候选题与机器答案，不改写旧F-02、F-05、A-03-SPEC及其签收。研究主结果仍由v1.2权威规定，理解测量不是PANAS情绪结果的报告门。

本包是离线材料与接口，不是呼吸检测器、问卷前端或正式量表。真实标注由S-02完成；片段渲染由U-02/U-07提供，形成性检查由Q-01/Q-02完成。理解题在PANAS后测之后呈现，800秒体验中不增加操作。

## 接口

- `make_material(frame, evidence, seed=0)`：校验完整v2.2遥测，生成八题、私有答案键和输入/材料身份。
- `score_response(material, item_id, status, option_index)`：输出0/1或缺失null，保留作答状态和材料哈希；不替下游选择缺失分析策略。
- `build_evidence.py`：确定性生成15个合成案例、30份双条件私有材料及15份条件中性题面；`--check`复算字节哈希。

运行：

```powershell
py -3.14 02-技术研发/srp_step_measurement/build_evidence.py --check
py -3.14 -m pytest -q 02-技术研发/tests/step_measurement
```

## 字段与真值来源

输入`frame`直接通过P-01合同适配器，不接受v2.1。目标与实际分别携带周期/步骤，循环序号从0开始；步骤题识别具体步骤，C-A2另辨认同周期与不同周期。下一目标来自冻结的呼吸结构配置，不用于推断实际。

`evidence`提供event_id、source_kind、clip_duration_ns、actual_source_ref、actual_unknown_reason、cumulative_band、cumulative_annotation_ref、previous_recovery_value。

- 实际非空必须有独立来源引用；实际为空必须有未知原因，保持null。引用只提供追溯位置，不是自动验证真实设备或标注质量的证明。
- 断流或降级时保留原实际字段供审计，但题面不把陈旧字段作为可可靠读取的实际信息。
- 累计区间必须由冻结的显示映射/独立注释提供，本工具不发明高低阈值。previous_recovery_value是同一片段起点的累计值，不能来自别的模块；未知填null。
- 所有补充字段与帧均由片段复核人查验，绑定原始记录、时钟和片段哈希后才能进入真人材料。输入不可识别的“实际”不能凭目标或动画补写。

## 候选题迁移

| 项目 | 新语义 |
|---|---|
| C-T1 / C-T2 | 当前目标具体步骤 / 按协议的下一目标步骤，真值保留周期边界 |
| C-A1 / C-A2 | 可读取实际具体步骤 / 同周期同一步、同周期不同步、不同周期、未知 |
| C-C1 / C-C2 | 当前累计显示区间 / 从片段起点到终点的累计变化 |
| C-D1 / C-D2 | 当前输入可用情况 / 仍可读取的目标与实际信息 |

“同一步”只表示身份一致，不等于时间误差合格、呼吸执行正确或COMPLIANT。旧领先/接近/落后题需要可靠时序及界值，留给S-02/U12-04；本工具不从粗相位猜测。

累计题改为具体片段判断，减少旧题仅凭常识作答的机会；是否真正依赖片段仍需形成性无片段/替代片段测试，不能由生成器自证。两条件同一事件与种子具有相同题面、题序、选项和答案。

步骤题使用该结构所有合法步骤加“未知”，选项集合不根据正确答案裁剪：storm为5项、heat/snow为3项、fade为4项；其余题为4项。题数仍为8。此项候选修订消除旧四选一裁剪泄漏，不声称已冻结正式问卷。种子0至59的60个候选呈现形式中，每道题的正确位置均匀分配；这不是要求参与者回答60套题，正式选用与分配由Q-02冻结。

## 交接与证据

- `evidence/participant_items.json`仅题面；`private_answer_keys.json`含真值及答案，不交参与者端。
- 事件哈希区分补充真值和配置；材料哈希同时绑定题面、选项、答案与种子，评分入口复算校验。响应须保存材料哈希，不只保存题号；下游须与锁定材料清单核对，内容哈希本身不是来源签名。
- `RESPONDED/SKIPPED/TIMEOUT/TECH_UNPRESENTED`分别保留；非作答correct=null。由U12-04明确分析分母策略。
- `annotation_plan.md`给出独立标注与逐结构观测性计划；所有真实标注、片段及正式测量验证仍为PENDING。
- 合成fixture证明代码行为，不证明真实信号可分辨、心理测量有效或研究效应。
